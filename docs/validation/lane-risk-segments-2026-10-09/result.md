# 10/6·10/7 주행영역 출력의 연속 검수 후보

**판정: 후보 분석, HOLD.** 이 기록은 기존 전체 프레임 smoke 출력에서 사람 검수에 우선할 연속 구간을 고른다. 새로운 픽셀 정답, 차선 경계 ID, 벽 판정, 주행 허가는 만들지 않는다.

## 입력과 재현

- 출발 코드: 로컬 `main` `c7e391e73`. 기존 시험 모델 `lane-seg-20261007-b389d6a0`의 [10/6 기록](../drivable-smoke-1006-full-2026-10-08c/result.md)과 [10/7 기록](../drivable-smoke-1007-full-2026-10-08b/result.md)을 재집계했다. 모델 재추론이나 원본 영상 재판독은 하지 않았다.
- 10/6 `per_frame.jsonl` 3,129행 SHA-256 `6bca79ca720eb23677b283982a284e9e14ef7b9808aed30362f69da0c6293198`; 10/7 207행 SHA-256 `e99ec8773ea643c347ecf20199556d7dff67ebba90f6086b2236fe3c8b124320`.
- 저장소 루트에서 `python docs/validation/lane-risk-segments-2026-10-09/evidence/summarize.py`를 실행한다. [집계 코드](evidence/summarize.py)는 세션별 0부터 시작하는 연속 frame index를 확인하고 조건에 맞는 연속 구간을 길이순으로 출력한다. 구간 양끝은 포함한다.
- `near_drivable_fraction > 0.5`는 하단 40%에 칠해진 시험 모델의 **면적 기준 후보 필터**다. 정확도 문턱이나 안전 판단 기준이 아니다.

## 검수에 넘길 질문과 제한

원본 영상에서 위 구간의 시작·끝·중간 프레임을 먼저 확인해 각 프레임의 보이는 바닥, 벽/분기, 가림, 동일 물리 경계 ID를 사람이 판정해야 한다. 특히 10/6 `091340`의 449–616 구간에서 한쪽 선이 실제로 연속했는지, 10/7 STOP 구간에서 넓은 마스크가 벽·분기까지 침범했는지가 핵심이다. 현재 사용자가 선택한 범위는 후보 분석이므로 이 목록 자체를 승인 정답이나 학습 데이터로 승격하지 않는다.

기존 `adjacent_raw_iou`는 워프하지 않은 출력 마스크의 겹침일 뿐이다. 여기서 논문의 `R_F/R_M`, 사람 정답 IoU, 연속 miss, 조향 성능을 계산하지 않았다. 카메라 보정·Pi 추론·재생 안전·시뮬레이션·실물 수용은 여전히 별도 게이트이며, 불확실한 경계에서는 STOP, 최종 `/cmd_vel`은 CORE 단일 권한을 유지한다.
