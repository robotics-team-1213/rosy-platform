# 지도와 어긋난 한쪽 경계 후보의 중단

**판정: SOURCE/호스트 회귀와 ROS-SIM 저장 프레임 그림자 재생 통과. 주행 승격 HOLD.** 2026-10-09 KST. [B9 폐루프 반례](../lane-short-boundary-closed-loop-2026-10-09/result.md)의 영상을 이용했다. route_a는 Gazebo 전용 시제품이다. 출하 keep 모드와 CORE의 최종 cmd_vel 권한은 바꾸지 않았다.

## 발견

기준 run 두 건에서 keeper의 양쪽 경계가 사라진 시각은 SIM 95.500, 142.375초이고 다음 교차선은 99.125, 145.875초였다. 그 사이 no_boundary가 3.5, 3.375초 이어졌다. 기록 자세의 이동 합은 각각 약 14mm다. 긴 시간은 CORE의 3초 손실 한도를 넘지만, 정지와 복귀가 섞여 있어 0.40m 경계 기억 이동 한도가 원인이라고 할 수 없다.

같은 화소를 [기존 route_a 그림자 재생](evidence/replay.py)에 넣으면 이 구간에서 카메라 BOTH 후보를 냈다. [카메라 프레임](evidence/base1-95_500-camera.png)과 [BEV 후보](evidence/base1-95_500-bev.png)에 왼쪽 바닥선, 가로선, 오른쪽 벽 옆 흰 줄이 함께 보인다. BOTH는 시제품이 고른 두 성분이며 사람이 승인한 동일 물리 경계 정답이 아니다. 해당 시각은 near_node=false라서 경로 선택 게이트도 후보를 확인하지 않았다.

| 같은 영상의 단일 프레임 반사실 입력 | 기존 route_a | 변경 후 |
|---|---|---|
| 기록 자세, 경로 횡오차 16.5–17mm | BOTH 후보 | BOTH 후보 |
| 직전 자세 고정 | BOTH 후보 | BOTH 후보 |
| 경로 왼쪽으로 80mm 이동, 계산된 횡오차 96.5–97mm | **ONE 후보** | **STOP, 출력 없음** |
| odom 없음 | STOP | STOP |

80mm 오차에는 기록 자세의 화소를 그대로 사용했다. 로봇이 그 위치에서 실제로 찍었을 화면이라는 뜻은 아니다. 입력 NPZ SHA-256은 base1 a057affb32a3b0b400acfd64bec7f1217249a0026a2d44d9fd82fd90e557f307, base2 d2bfd614db8c50b1d6141f26e0a84f03a0bafb9748daa8b8ac4b3515024fd94c이다. 모델 PC의 격리 lane-closedloop-24756115/b9runs 아래 남겼다. [재생 코드](evidence/replay.py)는 격리 작업공간을 인자로 받아 그 안의 src/rosy-platform과 b9runs를 읽고 격리 루트에 디버그 PNG를 쓴다.

## 수정과 검증

RouteCameraFollower가 활성 경로와 자세의 횡방향 차이 >60mm를 보면 카메라 후보를 버리고 경계 기억과 잠금을 비운다. **그 경로 실행은 중단 상태로 유지**한다. 정상 자세가 다음 프레임에 다시 나타나도 자동 재잠금하지 않는다. 기동 중이면 기존 MANOEUVRE_ABORT, 그 외에는 STOP이다. 새 경로 실행에는 새 follower 인스턴스가 필요하다. 60mm는 정상 경로 재생 최대 46.6mm와 반례 최소 96.5mm를 분리한 실험값이며 실물 위치 오차의 수용 한도가 아니다.

실패 시험에서 같은 화소에 80mm 위치 오차를 주면 LaneObservation이 나왔다. 수정 뒤 test_route_camera.py 30개, 관련 혼합 추적기·전체 차선 순회 52개가 통과했고 후자 10개는 skip이었다. 회귀에는 이탈 다음 프레임에 정상 자세를 넣어도 STOP인 경우가 포함된다. 저장 프레임 두 건에서도 기록 자세 BOTH, 80mm 이탈 STOP, odom 없음 STOP을 확인했다.

드리프트 표의 선택 두 조건은 현재 main과 이 분기가 동일하게 각각 9/12, 6/12 통과였다. 이는 기존 목표 12/12, 8/12에 못 미치는 **미해결 오차**이며 이번 변경의 실기 안전성을 증명하지 않는다. 지도 시작점과 odom drift가 틀린 채 60mm 안으로 보이면 잘못된 물리 선을 계속 따를 수 있다. 10/6·10/7 원본의 사람 승인 경계 ID는 여전히 0건이므로 학습·주행 정답으로 쓰지 않는다.
