# 별도 라벨링 세션의 검수 반환 처리

2026-10-04, 사용자 요청에 따라 video_label_review 세션에서 구현했다.
사용자는 직접 검수 담당이며 assistant 검토 결과를 사람 승인으로 전환하지 않는다.

`learning/training/perception/dataset/review_return.py`는 source/human JSONL과
원본 이미지 bytes를 고정하고 이미지 hash, 실제 크기, index, 클래스, 박스 범위를
출력 작성 전에 확인한다. 명시적인 전체 프레임 승인만 기존 object_boxes exporter로
전달하며 실제 크기별로 나눈다. 입력 원본과 신호 상태 JSONL을 보존한다.
모든 그룹 처리 후 manifest와 COMPLETE를 작성한다. 이는 반환 처리 완료 표시이며
학습 데이터 자격이나 검수자 인증을 의미하지 않는다.

실제 브라우저 QA에서 복사한 pending 반환 자료를 root가 다시 처리했다.
`X:/DevTemp/rosy-learning-audit-20261004/review-return-root-verified`에
320×240 세 프레임과 640×480 한 프레임을 기록했다. 확정 라벨 0, 검수 대기 4이다.
사람 승인 자료는 아직 수신하지 않았다. 승인 export의 양성 증거는 합성 unit fixture다.

반환 처리기, 기존 객체 exporter와 편집기 관련 테스트 55개가 통과했다.
원본 입력 변경 후 고정 snapshot export, 후기 그룹 검증 실패 시 출력 없음,
두 번째 그룹 실패 시 outer manifest/COMPLETE 미발행을 포함한다.
실제 사용자 검수, 픽셀 마스크 검수, 새 모델 학습과 DEVICE/FIELD 수용은 미완료다.

## 사용자 지적과 후속 검증

사용자는 횡단보도 줄무늬의 차선 오분류, 어두운 교차로의 차선 누락,
회전교차로 구분·진입 판단의 미검증을 지적했다. 이번 반환 처리기의 통과가
이 세 항목을 해결했다는 의미는 아니다. 해당 영상의 장면·프레임과 정답을
연결하고, 같은 촬영 세션이 학습과 고정 평가에 섞이지 않도록 해야 한다.
사용자는 이어서 어두운 장면 대응을 이번 개선 범위에서 제외하고 후속 ADR로
다루도록 지정했다. 횡단보도와 차선 경계는 이번 사람 검수 대상으로 삼는다.
어두운 장면 문제는 미해결 상태로 남기며 원본 데이터 삭제나 기존 고정 평가·게이트
변경으로 이 결정을 확대하지 않는다. 후속 ADR에서 지원 조명 조건과 센서 보완,
어두운 장면에서의 주행 판단 제한을 결정해야 한다.
회전교차로는 인식 평가와 owner 주행 정책의 진입 판단·시뮬레이션 검증을
별도로 남긴다. 세 항목의 개선/수용 결과는 아직 없다.
