# Pinky Pro 공급사 부팅 카드 기록 (2026-09-24)

`boot-profile` 작업 트리에 보존돼 있던 공급사 SD 카드의 `system-boot` 파티션에서 읽은 `config.txt`와 `cmdline.txt` 사본이다. 두 파일은 공급사 구성의 과거 증거이며 현재 Rosy 이미지의 부팅 설정 정본이 아니다. 사용자 데이터, 네트워크 설정, 계정 파일은 포함하지 않았다.

| 파일 | SHA-256 |
|---|---|
| `config.txt` | `734af55d885ebd7b9b41a035f5e19be3e2509f6bfd8984f1cb22fb03d051f1da` |
| `cmdline.txt` | `03d2de5f6ca3a25c8c8f6bf6698828fd3b7553bd293542e6cdfd28bd9f570782` |

검증: 원본 작업 트리의 두 파일과 이 사본의 SHA-256을 비교한다. `.gitattributes`가 Git의 줄바꿈 변환을 막는다.

원본 작업 트리의 부팅 프로필 코드는 병합하지 않는다. 그 코드는 D-199를 부팅 결정으로 사용하지만 현재 D-199는 카메라 인식 계약이다. 또한 현재 이미지 경로는 D-247의 `configure-boot-overlay-pi5.sh`로 IMU·카메라·램프 오버레이를 구성하며, 원본 프로필의 `i2c_vc=on` 및 카메라 미확인 설명은 현재 구성·실기 카메라 기록과 맞지 않는다. 이 기록은 공급사 카드와 현재 이미지의 차이를 추적할 때만 사용한다.

이 사본과 호스트 검사는 ARM64 이미지, 장치 부팅 또는 센서 수용 증거가 아니다.
