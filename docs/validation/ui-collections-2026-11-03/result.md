# 표·정렬 공용 표현과 Cell 카탈로그 수명 검증

기존 공용 부품을 실제 표에 연결하고, 전체 화면의 탐색·계정 전환·긴 값에서 발견한 문제를 수정했다. 이 기록은 소스와 격리된 Chromium 검증이며 제품 전체 UI/UX GO나 실물·현장 수용이 아니다.

## 변경과 판단

- 카탈로그 문서의 `component-controls.css` 누락을 고치고 카탈로그·관측 좌표 표에 기존 `ui-data-table`을 적용했다. 좌표 표의 중복 표현 CSS를 제거했다.
- 공용 `createListToolbar`는 호출자가 정한 `sortLabel`·`sortOptions`를 받는다. 기본 이름 오름차순/내림차순과 선택 유지 동작은 보존했다. 비교·서버 쿼리·권한은 호출자가 소유한다.
- Cell 카탈로그는 저장된 문서 화면 그룹에 속한다. 다른 단계로 이동하면 카탈로그도 숨긴다.
- `createObjectCatalog`가 표와 요청 세대를 소유한다. 접속 갱신·계정 변경·로그아웃·pagehide에서 행을 비우고 이전 성공/실패 응답을 무시한다. 무게 포맷·운반 판정·서버 권한은 바꾸지 않았다.
- 긴 출처가 다른 열을 압축하지 않도록 카탈로그에 fixed 배치를 쓰고 값은 행 위쪽에 정렬한다. 다섯 열의 읽기 폭은 표면 배치의 최소 폭 `40rem`으로 확보한다. 이는 색·글자·조작 규격을 새로 만든 것이 아니며, 표면 너비는 표면이 소유한다는 기존 규칙을 따른다.
- 좁은 화면은 공용 감싸개 안에서만 가로 스크롤한다. 감싸개에는 기존 제목으로 연결한 이름·region 역할·키보드 포커스를 제공했다. 긴 출처는 잘라 버리지 않았다.
- 정적인 열 제목과 값의 현재 순서 불일치는 확인하지 못했다. 이를 없애려고 제목을 런타임 생성하거나 범용 표 엔진을 추가하지 않았다.

## 시험 자체에서 바로잡은 부분

공용 선택기는 접근성 트리의 역할·정확한 이름으로 찾는다. 새 스크롤 region과 section은 같은 제목을 공유하므로 단계 숨김 검사는 section으로 범위를 지정한다. CSP가 문자열 eval을 막으므로 브라우저 대기는 함수 표현식을 사용한다. 이 보완은 제품 CSP를 약화하거나 검증 단언을 제거하지 않는다.
