# BENCH 회차 체크리스트 — 2026-09-24 회차(공예 계약)의 실물 분량

2026-09-21 회차 1의 `bench-checklist.md`를 계승·대체한다. 그 이후 계약이
여덟으로 늘었다(D-201 적합 · D-202 채움+얼굴 번역 · D-203 척급 · D-214 바닥 ·
D-218 확인 · D-219 요약 큐 · D-220 정지 · D-221 얼굴 어휘) — 이 문서는 그
전부를 실물에서 여는 절차다.

판정 언어는 D-153: GO = G1 현재 트리 재실행 + 선언 셀 전부 캡처 + G3 위반 0.
BENCH 증거는 LOCAL을 승격하지 않는다(D-91).

## 0. 들고 갈 것

- 로봇 AP에 붙은 노트북(1366×768 최소 — D-201 선언), 사이트 PC(1920×1080),
  경기 노트북(1280×800), 휴대폰(로밍 뷰 확인용)

  `docs/validation/uiux-bench-<date>/`

## 1. 라이브 게이트 — 명령 하나 (신설, test_live_surface_gates.py)

로봇에서 CORE가 떠 있는 상태에서 같은 센서스가 실물 주소로 돈다:

```powershell
$env:ROSY_RUN_BROWSER_TESTS="1"
$env:ROSY_LIVE_DASHBOARD_URL="http://<robot>:8080/dashboard"
# 선택: $env:ROSY_LIVE_FLEET_URL, $env:ROSY_LIVE_GAMES_URL
python -m pytest test/test_live_surface_gates.py -q
```

임는 계약: 대비 바닥(D-214) · warm 글자(D-202) · 계산 척급(D-203) · 정지
(D-220). 변이 증명 완료(로컬 정적 미러 + 전이 주입 → 적색). 상태를 강제하는
게이트(분쇄·safe-stop)는 픽스처 묶음에만 산다 — 실물에서 위험 상태를
인위적으로 만들지 않는다.

## 2. 실물 뷰포트 적합 (D-201)

각 선언 뷰포트에서:

- [ ] 콘솔 1366×768 — 문서 스크롤 0, 조작 열 전부 보임, 모드 분절 44px
