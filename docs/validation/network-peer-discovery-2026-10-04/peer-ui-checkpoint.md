# 장비 찾기 화면과 연결 대상 선택 검증

D-452의 같은 망 검색과 다른 망 승인 directory를 같은 역할 목록으로 표시한다.
설치·보정 화면의 첫 작업은 장비 찾기이며 역할 필터, 다시 찾기, 대기·빈 목록·만료·
충돌·인증 실패 안내를 기존 공용 토큰과 컴포넌트로 표현한다. 검색된 주소를 링크로
만들지 않는다. 승인된 기존 로봇은 등록된 상태 카드로, 기존 Cam source는 카메라
보정 화면으로 이동한다. 로봇 deep link는 카드 표시와 포커스만 바꾸며 목표를 선택하거나
명령을 전송하지 않는다. 담당 화면이 없는 장비는 그 상태를 명시한다.

요청은 활성 화면에서만 실행하고 진행 중 요청을 합치며 각 요청에 10초 상한을 둔다.
응답은 최대 64행이다. 로그인 변경·dispose 후 늦은 응답은 표시하지 않는다.
이 예산은 실제 LAN airtime 측정이나 다른 망 연결 수락을 대신하지 않는다.

독립 Chromium fixture에서 390·800·1200 너비와 역할 필터·오류·만료·재시도·
세션 변경·늦은 응답을 검증한다. 모바일 오류 안내 overflow는 짧은 상태 배지와
상세 안내를 분리하여 수정했다. 정상 운영자 로그인·실제 장비 접속·배포는 별도다.
원시 화면과 source hash receipt는 X 드라이브에 보존한다.

Cell 화면의 관제 복귀는 /console native link이며 취소는 장비 정지와 구분한다.
실제 구동·정지 해제나 Cell G1/G2 수락을 수행한 기록이 아니다.

통합 검증: 구현 worker의 실제 install/console와 기존 5 workflow는 7 PASS,
최종 3너비 오류/만료 검사는 3 PASS, Node 18 PASS였다. 독립 reviewer는 10개
파일 해시와 실제 로그, 권한 및 포커스 동작을 대조하여 SPEC·Quality·Safety PASS했다.
통합 담당자가 실제 workflow를 별도로 실행해 7 PASS(33.86초), catalogue와
3너비 fixture는 23 PASS였다. 첫 workflow 실행에서 opt-in 환경 미설정으로 생긴
7 SKIP은 보존하고 ROSY_RUN_BROWSER_TESTS=1로 해당 7개를 실행했다. NEW 실패는 0이다.
이 결과는 source fixture 증거이며 실제 운영자·장비·원격 배포 수락으로 표시하지 않는다.
