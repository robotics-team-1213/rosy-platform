# D-835: 지도 도형 추출 AI 후보 측정

상태: **MEASURED · NOT SELECTED · NOT DEPLOYED**. 배포된 일반 추출 기능은 유지한다. 이번에 시험한 기존 SAM3 사본과 고정 프롬프트는 합성 품질 기준을 충족하지 못했다. SAM 전체 또는 실제 CAD에 대한 결론은 아니다.

## 비교 범위

기준 소스는 PR135의 `a724865c38daf7a056c6409fa312c160b913892c`다. [D-835](../../adr/D-835-generic-map-tracing-and-assisted-extraction.md)의 후속 측정이며, [앞선 소스 검증](source-verification.md)을 대체하지 않는다.

512×512 합성 도면 6종에 일반 윤곽 추출, SAM3 대화형 박스·점, 개념 탐지기 텍스트·박스 예시를 비교했다. 방식별 3회 반복으로 총 90회 관측했다. 독립 도면 90개가 아니며 실제 CAD·현장 사진·사람 정답 세트도 아니다.

첫 실험 전에 IoU ≥0.90, 양방향 경계 오차 p95 ≤2px, 정확한 구멍 수를 모두 만족하도록 품질 기준을 고정했다. 이후 추가한 개념 탐지기 실험에도 같은 기준을 적용했다. 정확도가 맞는 마스크를 사후 선택하거나 실패한 입력의 프롬프트를 조정하지 않았다.

- 일반 방식은 고정 소스의 `extract_geometry(method='contours')`를 모델 환경에서 호출했다. 후보 중 사전 지정한 사용자 점을 포함하는 최소 외곽선과 내부 구멍을 선택했다. 이 선택은 비교용 코드이며 운영 UI에 점 선택 기능이 있다는 뜻은 아니다.
- 모든 방식에 관심영역과 사용자 점·박스를 미리 지정했다. 위치는 합성 도형에서 얻었으므로 자동 대상 발견이나 사람의 입력 비용을 측정하지 않는다. 모델 출력은 모델 점수가 가장 높은 마스크를 택했다.
- 개념 탐지기 텍스트는 `black shape`, 낮은 명암에는 `gray shape`, 얇은 선에는 `black line`이다. 박스 예시는 고정 양성 박스이고 기본 confidence threshold는 0.5다. 채워진 영역이 정답인 입력에서 외곽선만 나온 결과도 그대로 채점했다.
- 다른 GPU 작업이 감지되면 적재 전에 거절했다. 추가 실험은 자원이 빈 뒤 실행했고, 라이브 AI PC를 평가 호스트로 쓰지 않았다.

## 정확도 결과

표는 각 입력의 첫 반복 IoU / 경계 p95(px)다. 반복 3회의 모델 마스크는 입력·방식별로 같은 해시였다. 빈 출력은 IoU 0, 경계 오차 없음으로 기록했으며 성공으로 세지 않았다.

| 도면 | 일반 추출 | 대화형 박스 | 대화형 점 | 텍스트 | 박스 예시 |
|---|---|---|---|---|---|
| 사각형 | 1.000 / 0 | 0.973 / 14 | 0.672 / 53 | 0 / 없음 | 0.024 / 4 |
| 회전 도형 | 0.996 / 1 | 0.996 / 1 | 0.993 / 1 | 0.991 / 1 | 0.994 / 1 |
| 구멍 있는 도형 | 0.997 / 1 | 0.927 / 31 | 0.704 / 51.89 | 0 / 없음 | 0.970 / 7 |
| 낮은 명암·문자 | 1.000 / 0 | 0.996 / 1 | 0.982 / 2.83 | 0.987 / 1 | 0.011 / 4 |
| 얇은 꺾인 선 | 0.956 / 1 | 0.920 / 1 | 0.603 / 6.71 | 0.459 / 224.28 | 0.858 / 1 |
| 잡음·문자 | 1.000 / 0 | 0.993 / 1.41 | 0.875 / 82 | 0 / 없음 | 0.995 / 1 |
| 전체 품질 기준 통과 | **6/6** | **4/6** | **1/6** | **2/6** | **2/6** |

면적 IoU가 높아도 위상 오류가 있었다. 사각형의 정답 구멍 수는 0인데 대화형 박스는 6개, 점은 61개였다. 정답 구멍 1개인 도형에서는 각각 26개·127개가 나왔다. 원본·정답·예측 비교 그림도 직접 확인했다.

마스크를 허용오차 1px의 다각형으로 바꾸는 탐색 코드에서는 작은 구멍과 퇴화 윤곽이 사라지기도 했다. 일부 점 결과의 변환 왕복 최대 경계 오차는 130px를 넘었다. 이 코드는 제품 어댑터가 아니며, 구멍·다중 영역 보존 또는 명시적 거절을 검증하기 전에 운영 후보 변환에 사용하지 않는다.

## 시간·자원

각 방식에서 입력별 첫 반복을 뺀 12회 관측이다. 모델 시간은 이미지 인코딩과 프롬프트 실행을 포함한다. p95는 이 작은 표본의 기술 통계이며 운영 지연 보증이 아니다.

| 방식 | 중앙값(ms) | p95(ms) |
|---|---:|---:|
| 일반 추출 | 1.19 | 1.27 |
| 대화형 박스 | 160.98 | 182.18 |
| 대화형 점 | 171.73 | 217.48 |
| 텍스트 | 195.51 | 223.32 |
| 박스 예시 | 204.59 | 236.76 |

대화형 모델 최초 적재는 7.87초, 첫 박스 요청은 2.715초였다. CUDA 최대 할당 3.936GiB, 프로세스 최대 RSS 7.409GiB였다. 개념 탐지기는 적재 7.63초, CUDA 할당 3.896GiB·reserved 4.215GiB, RSS 7.293GiB였다. 첫 실험은 reserved·드라이버 최고값을 수집하지 않았다. 이 자료는 AI PC 동시 적재 용량을 보장하지 않는다.

평가 환경은 RTX5080 Laptop 16GB, Torch 2.11.0+cu128, NumPy 1.26.4, OpenCV 5.0.0이다. 운영 Fleet의 NumPy 2.2.6/OpenCV 4.12.0과 다르므로, 동일 추출 소스를 호출한 이 결과를 운영 Fleet의 실행 시간이라고 부르지 않는다. 새 패키지·가중치를 설치하거나 내려받지 않았다.

## 다음 연결 조건

현재 고정 후보는 선정·승격·운영 연결하지 않는다. 허가된 실제 도면과 독립 정답, 추적 가능한 모델·소스 revision, 구멍·다중 영역 변환, 취소·시간·메모리 제한을 먼저 검증한다. 이후 별도 AI 실행 경계와 기존 후보 검토 화면을 연결하는 계획을 확정한다. 고정 프롬프트 몇 개의 실패를 모든 프롬프트나 모델의 실패로 일반화하지 않는다.

AI PC 적재 스모크·실제 CAD 교정·실기 주행·FIELD 인수는 **NOT_TESTED**다. 기존 사람 라벨, 운영 지도, 서비스 설정, CORE 권한과 로봇 명령은 변경하지 않았다.
