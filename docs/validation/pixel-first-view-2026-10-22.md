# 픽셀 검수 첫 화면 재검증 · 2026-10-22

픽셀 검수는 원본 사진을 먼저 보여 주고 AI 실행·참고 의견은 사진과 편집 도구 뒤에 둔다. D-542의 첫 화면 기준과 기존 짧은 화면 시험을 유지한다. 미검수 수는 클래스 선택 전에, 조작 설명은 편집 버튼 다음에 둬 휴대폰에서도 도구가 사진에서 멀어지지 않게 했다.

## 변경과 시험

- 기준 commit 33d8d3989d0a에서 명시 브라우저 4개 파일을 실행했다. 사진 표시 2건, 네 화면·두 휴대폰 크기의 메뉴 개수 8건, 클래스 미선택 상태의 AI 편집 시험 1건이 실패했다. 메뉴는 이미 모방학습을 포함한 다섯 화면인데 시험은 네 개를 기대했다. AI 시험에는 실제 편집 전에 필요한 클래스 선택이 빠져 있었다.
- 사진 위에 동적으로 삽입되던 AI 패널과 보기 상태를 아래로 옮겼다. 첫 화면·짧은 화면의 기존 기준은 바꾸지 않았다. 이전·다음·되돌리기는 사진 왼쪽의 보이는 영역에 있는지 함께 확인한다. 사진이 앞당겨져도 되돌리기를 사진보다 위로 밀어 올릴 필요는 없다.
- commit 36e4a7bb2dad의 원격 명시 브라우저 검사 8건이 통과했다. 사진 표시, 사진 전환, 데스크톱·휴대폰 편집 도구, 클래스 앞의 미검수 표시를 검사했다. 기존 실패 목록에서는 고친 사진 표시 2건만 제거했다.
- 메뉴 시험은 다섯 경로의 정확한 집합을 확인하고, AI 미저장 편집 시험은 클래스를 직접 선택한 뒤 기존 차단 조건을 검사한다. 클래스 선택 요구나 AI 승인 경계는 변경하지 않았다.

원본 증거는 작업 공간 `Rosy/artifacts/receipts/pixel-first-view-20261022/`에 보존한다. `pixel-walk.json`, 8개 PNG, 명시 원격 시험 로그와 최종 게시 기록을 함께 보관한다. 합성 자료 검증이며 실제 학습 효과·실물 파지 수용을 뜻하지 않는다.
