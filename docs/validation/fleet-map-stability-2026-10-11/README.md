# Fleet 지도 좌표와 위치 조회 검증

브랜치: `fix/fleet-map-pose-stability`

## 좌표 경로

- 카메라 보정은 이미지 픽셀과 현장 지도 미터 좌표를 연결한다. 화면 회전은 표시 변환이며 원점·축척을 새로 만들지 않는다.
- D-593 운영자 핀은 `(x, y, yaw)`를 최신 로봇 odom과 짝지어 D-494 지도 자세의 앵커로 둔다. 로봇마다 별도 앵커를 사용한다.
- 핀 이후 odom 이동량을 지도 좌표로 변환하고, 승인된 카메라 sighting이 앵커를 검사·갱신한다. odom이 없거나 오래되면 현재 위치를 확정하지 않는다.
- 저장된 시작점은 지도 기준점이다. 현재 로봇 위치 핀과 구분한다. 지도 좌표만으로 로봇 현재 위치가 자동 생성되지는 않는다.

## 확인한 문제와 수정

1. 로봇 이름 발견 실패가 `ValueError`로 HTTP transport 밖으로 나와 `GET /api/fleet/robots/{id}/map-pose`를 500으로 끝냈다. HTTP transport 경계에서 `ConnectError`/`ConnectTimeout`으로 바꿔 기존 위치 조회의 연결 실패 처리가 `UNKNOWN`을 반환하게 했다. 발견 충돌·TLS 검증·자격 증명 미전송 조건을 유지한다.
2. 관제 화면은 카메라 현장 지도와 로봇 SLAM 격자를 수신 상태에 따라 전환했다. 활성 지도의 ID가 카메라 현장 지도와 일치하면 그 현장 좌표 화면을 유지하고 로봇 격자로 대체하지 않는다. 활성 현장 지도와 대응하는 카메라 지도가 없을 때 기존 격자 조회는 유지한다.

## 현장 읽기 증거

2026-10-11 현장 서비스의 읽기 결과:

- 활성 지도 버전 5, `map_id: map_v2_fleet`. 카메라 설정과 승인된 교정도 같은 map_id다. 교정 revision은 `paint-7b220d432c2a`다.
- 활성화 이력은 버전 1~5이며 버전 5는 이 조사 전에 운영자 활성화로 만들어졌다. 현재 읽은 이력은 지도의 자동 재생성을 입증하지 않는다.
- 카메라 추적 입력은 새 프레임을 받았지만 등록 로봇 2대의 Fleet 상태는 offline이었다. 위치 조회에서 위 발견 실패의 500을 확인했다. 로봇 직접 SSH도 연결 시간 초과였다.
- 이 현재 상태만으로 사용자가 제공한 전날 `lane_lost` 사건의 위치 미확인 원인을 확정하지 않는다. 당시 odom 표본과 상태 연결을 재구성하지 못했다.

## 검증과 경계

- 수정 전 원격 재현: 발견 실패 3개가 미처리 예외로 실패. 화면 테스트도 활성 지도 중 로봇 격자를 조회함을 재현했다.
- 수정 후 AI PC 원격 시험: **205 passed**, exit 0. 발견·HTTP transport·등록 TLS·지도 자세·핀·현장 지도 API를 포함한다. API 시험 안에서 콘솔 Node 시험 **280개**도 통과했다.
- 기존 핀 시험은 `(1, 2, 90°)`에 놓인 로봇의 odom 전진 0.3 m가 지도 `(1, 2.3)`으로 표시되는 변환, 관측 불일치, odom 재시작·신선도 제한을 확인한다. 카메라 픽셀 역변환·화면 회전 시험도 포함됐다.
- 원격 로그는 X: 작업 세션에 보존한다. `known_failures` 비교와 harness lint는 별도 확인한다.
- SOURCE와 원격 계약 검증이다. main 착지·push·현장 배포·실물 위치 추종 수용은 수행하지 않았다. 지도 원본과 카메라 교정은 변경하지 않았다.

## D-631 표시 모드와 지도 프로필

- 관제에 기본 2D 좌표·차로 선, 승인 교정 영상 오버레이, 교정 전 원본 영상 선택을 추가했다. 같은 좌표 변환을 유지한다. 원본 영상은 회전하지 않는다.
- 카메라 원본과 교정 후 지도 평면 비교를 추가했다. 지도·카메라·원본 크기·렌즈·교정 revision·신선도가 맞지 않으면 교정 영상을 지운다. 교정은 설치 화면의 기존 승인을 따른다.
- 현장 지도 페이지에 이름 있는 프로필 저장·선택·초안 불러오기를 추가했다. 좌표와 차로 규칙 JSON을 작성하거나 `rosy.site_map/1` JSON 파일을 가져오면 기존 서버 검증 후 그린다. 프로필 저장·미리보기는 활성 지도를 바꾸지 않는다. 활성화는 기존 초안 활성화 버튼으로 한다.
- 프로필은 SQLite에 저장하고 재시작 후 복원한다. 운영자 쓰기·revision 충돌 거절·2 MiB 제한·100개 제한·감사 이벤트를 시험했다. 프로필 미리보기에는 로봇 위치·운행 경로·카메라 교정을 겹치지 않는다. 임의 이미지/STL/YAML을 차로로 자동 변환하는 기능은 추가하지 않았다.
