# 벽면 성분을 이전 차선 경계에 연결하는 실영상 반례

**판정: 오프라인 카메라 추종 반례. 주행 안전성이나 사람 승인 정답은 아님.** 2026-09-19 teleop 영상 part04의 492번 프레임에는 정면 벽과 파란 표식이 보인다. [기존 기준선](../perception-real-video/2026-09-24/baseline.md)은 이 프레임에서 `centre`가 `BOTH/confidence=1.0`을 냈다고 기록했다. 현재 `centre`와 실물용 `keep` 코드에서도 이 벽 정면 프레임에 추종 관측이 남는다.

## 재생 조건과 결과

저장소의 `data/teleop/learning/teleop_20260919_151213_part04.mp4` 및 part06을 사용했다. [재생 스크립트](evidence/audit.py)는 현재 `LaneBoundaryTracker`와 `LaneKeeper`, 기존 프로토타입의 벽 화소 휴리스틱과 영상 VO, [draft 실물 카메라 프로필](../perception-real-video/2026-09-24/camera_profile_draft.json)을 읽기 전용으로 호출한다. `centre`는 180 밝기 문턱, ROI 0.25–0.75, wash 0.75, 차선 반폭 0.0925m이다. `keep`은 기본 바닥 흰색 마스크와 `corner_turning=True`, 같은 반폭을 쓴다. CORE 명령은 재생하지 않는다. 출력이나 이미지 파일은 만들지 않는다.

```powershell
python docs/validation/lane-wall-memory-2026-10-09/evidence/audit.py
```

고정 자세 재생의 492번 좌 성분은 BEV 폭 0.101m, 우 성분은 0.052m이다. 같은 원본 프레임을 새 tracker에 단독으로 넣으면 STOP이므로 이전 경계 기억과 연결될 때 오인식이 발생한다는 가설이 강해졌다. 영상 VO 재생에서도 결과가 유지되지만 영상 자체에 로봇 odom은 없다. 벽 화소 비율도 밝은 세로 성분을 추적하는 프로토타입 휴리스틱의 **후보 수치**이며 화소 정답이 아니다. `confidence=1.0`은 [밝은 성분의 길이](../../../middleware/perception/control/sensing/perception/lane_bev.py)에서 포화되는 값이지 두 물리 차선의 신원 검증이 아니다.

## 논의한 해법과 판별 시험

1. **관측 충돌 게이트:** 신선한 LiDAR 벽/물체 위치가 카메라 목표 경로 또는 기억 경계와 충돌하면 그 경계를 무효화하고 STOP 후보를 낸다. 반대로 벽과 닮은 화소만으로 새 경계를 만들거나 이전 경계를 승인하지 않는다. part04 벽과 part06 곡선, 기존 SIM 직선·곡선·한쪽 소실을 같은 조건으로 재생해 false carry와 정상 miss를 함께 기록한다. 현재 벽 화소 휴리스틱을 곧바로 제품 게이트에 넣을 근거는 없다.
2. **기억 재연결 검증:** 새 프레임의 성분을 과거 경계에 연결하기 전에 실제 자세 이동, 경계 진행 방향, 보이는 바닥과 장애물 증거를 대조한다. 불일치는 STOP으로 내며 재등장 때 한 프레임만으로 해제하지 않는 가설을 시험한다. 10/6·10/7 영상은 후보 반례로 사용할 수 있지만 물리 경계 ID의 사람 승인은 아직 0건이므로 재획득 성공률을 계산하지 않는다.
3. **CORE와 실물 경로:** Pinky의 신선한 경로 기반 LiDAR가 벽을 몸 경로 안의 장애물로 확인하면 CORE가 `obstacle_ahead` HOLD한다. 이 영상의 동시 LiDAR·실제 명령·설치 설정은 없으므로 그 HOLD가 발생했다고 주장할 수 없다. LiDAR는 충돌 방지 근거일 뿐 차선 ID 정답은 아니다. `LaneBoundaryTracker`는 `centre`와 SIM 전용 `route_a/route_ab`에 쓰이고, 실물 `keep`은 별도 `LaneKeeper`다. `keep`도 이 프레임에서 한쪽 선을 택했으므로 두 경로를 각각 검증해야 한다. 영상 출력만으로 최종 주행 명령을 주장하지 않는다.

이 반례는 [B9 STL 바닥 도색 일치](../lane-route-wash-spatial-2026-10-09/result.md)와 모순되지 않는다. B9의 두 성분은 SIM 바닥 도색과 정렬됐고, 여기서는 실물 벽면이 바닥으로 투영되는 경우다. 다음 승인 조건은 사람 검수 경계 ID 및 가림/벽 구간, 같은 시각 LiDAR와 CORE readback, SIM과 실제 로봇의 독립 재생이다. 그 전에는 불확실한 관측에 STOP을 유지한다.
