# 최신 main 운행 문구와 추출 경계 통합

앞선 [검사 보완](2026-10-24-integration-contracts.md) 뒤 공식 통합 도구는 main `afb218aed1`과 표시 추출 후보 사이의 지도 모듈·크기 기록 충돌을 감지하고 병합을 중단했다. 도구의 중단 뒤 작업 브랜치에서 main을 다시 병합해 소유 경계를 맞췄다.

main에 새로 들어온 `TRIP_JOB_NOT_FOUND`의 한국어 문구를 그대로 `shared/trip-display.js`로 옮기고 반환 문구를 확인하는 Node 단언을 추가했다. 지도 모듈에는 중복 어휘표를 되살리지 않는다. main의 `fitView` 선언 정리는 유지한다. 지도 모듈은606줄, 표시 모듈은192줄이며 지도 ratchet을 같은 통합 커밋에서606으로 낮춘다. 다른 크기 기록과 양쪽 로그의 기존 항목은 보존하고 index는 다시 생성한다.

이 단계는 동료의 새 오류 코드·실행 계약을 바꾸지 않는다. 제품 소비자는 앞서 정한 표시 모듈을 사용한다. 전체 오류 어휘 검사·Node·소유 계약과8개 폭/테마 화면을 고정 커밋에서 다시 실행하며 최종 착지는 공식 도구로 검증한다. 실행 결과·최종 SHA·원시 근거는 Git 밖 같은 날짜의 최종 보고서에 연결한다. 이 기록은 통과·착지·배포·현장 수용 선언이 아니다.

CE: 해당 없음 — 병합 충돌의 소유 판단은 기존 추출 설계·보존된 문구·회귀 단언으로 설명된다. 앞선 부모 UTF-8 교훈과 Git 해시 표기 교훈은 유지한다.
