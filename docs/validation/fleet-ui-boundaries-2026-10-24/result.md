# Fleet UI 책임 경계 후속 검증

사용자는 기존 UI 감사의 남은 구조 정리와 회귀 검증을 우선하고 커밋·로컬 main 병합까지 진행하도록 요청했다. 이번 기록은 운행 표시·로스터 수명·스타일 소유의 세 경계와 집중 검증을 다룬다. 배포·push·실물·실제 사용자 과업 수용은 포함하지 않는다.

## 변경과 소유

| 과제 | 반영한 경계 | 크기 변화 |
|---|---|---|
| 지도·운행 어휘 혼합 | `shared/trip-display.js`가 표시 어휘표 6개와 설명 함수 5개를 소유한다. 지도 모듈에는 기하·편집·요청 도우미를 남기고 실제 소비자의 import를 갱신했다. 표시 모듈은 DOM·요청·지도 모듈을 import하지 않는다. | 지도 모듈 788→607줄, 표시 모듈191줄 |
| 셸의 로스터 내부 접근 | Console은 로스터의 `syncConvoy`, `closeTrip`, `openTrip`, `paintTrip`을 사용한다. 로스터가 폼 생성·철회와 선택기 초점을 관리하며 내부 trip 객체를 공개하지 않는다. 요약·라벨·DOM 표현은 `roster-presentation.js`로 추출했다. | 로스터709→593줄, 표현 모듈151줄 |
| 공통 스타일의 로스터 규칙 | `roster.css`가 목록·선택 작업 공간·운행 폼의 규칙과 반응형/초점을 소유한다. 명시 자산 registry와 Console HTML을 연결했다. 패키지의 기존 CSS/JS glob이 새 파일도 포함한다. | 공통 스타일834→735줄, 기능 스타일110줄 |

표시 어휘를 쓰는 제품 소비자 5개(`card-trip`, `queues`, `sitemap/site-map`, `trip-replan`, `work/work-view`)와 Node 시험 4개를 갱신했다. 기존 지도 전용 소비자는 지도 모듈에 남는다. 시험의 동적 import 세 곳도 새 표시 모듈로 연결했다. 기존 한국어 문구·미터→정수 cm 표시·원시 값 fallback·요청 경로와 권한·신선도 조건을 유지한다.

`robot-head`는 설치·신호·여러 패널에서, `robot-actions`는 대형과 로봇에서 재사용한다. 이를 로스터 파일로 옮기면 설치/공통 기능이 기능 CSS에 의존하므로 공통 규칙에 남겼다. `robot-filter`도 대형 필터다. 전체 CSS 선택자 이름 변경이나 새 UI 프레임워크는 도입하지 않았다.

## 화면·소스 근거와 착지 판정

기준은 320·390·1366·1920px × light/dark의 8개 조합이다. 전후 6선택자×10속성의 계산된 스타일이 모두 같았다. PNG 8쌍 중 바이트 동일은3쌍이고, 나머지의 전체 픽셀 동일성이나 차이 원인은 판정하지 않았다. 320dark·1920light와390light 전후는 직접 확인했다. 모든 화면을 육안으로 전수 검토했다고 확대하지 않는다.

Git 밖 작업 기록 `Rosy/docs/workspace-records/2026-10-24/fleet-ui-boundaries-evidence/`의 `preparation-manifest.json`은 준비 commit의 변경 소스·시험24개와 원시 로그·캡처66파일을 해시로 연결한다. manifest sha256은 `994652d6c7b9526cf745864ecd26ef2e54984a5e626a0d30c5d5f7b4aa3c8be8`이다. 회수한 화면/스타일 자료56개는 원격 원본과 SHA-256이 일치했다. 캡처의 API는 합성 자료이며 실제 Vision 서비스나 장치 수용을 뜻하지 않는다.

중간 RED·추출 커밋을 다시 쓰거나 main에 그대로 착지하지 않는다. D-766은 각 커밋의 크기와 동시 ratchet 하향을 검사하므로, 최종 소유 변경을 최신 main 기반의 완결 커밋으로 구성하고 그 SHA를 공식 착지 도구에서 다시 검증한다. 이 기록 자체는 착지·GitHub CI 통과 선언이 아니다. 실제 착지 SHA·원격 검사·화면/소스 일치와 영수증은 같은 날짜의 로컬 최종 보고서·완료 manifest에서 확인한다.

CE: 새 교훈 기록 — 원격 로그를 회수한 뒤 부모 stdout의 cp1252 인코딩으로 실패 보고가 중단되는 조건과 UTF-8 실행 복구를 검증했다. 일반 UI 추출과 시험 기대 수정은 코드·회귀로 설명되므로 별도 교훈으로 늘리지 않았다. 과거 작업 공간 제거 사건의 원인은 이번 작업에서 해결한 것으로 계산하지 않는다.
