# 역할 표면 테마×뷰포트 캡처 회차 — 2026-10-04 (D-359 §7.8)

**판정: LOCAL HOLD.** FastAPI TestClient + Pinky Pro 프로파일 + 개발 인증 오버레이를
Playwright 경로 차단으로 서빙한 합성 캡처다. 개발용 관리자 토큰은 실제 운영자 인증,
실물 로봇·브라우저 기기·현장 조명 증거가 아니다. 사람 G3 시트도 없다.

## 최초 증거 정정

최초 캡처 도구는 브라우저 세션 토큰을 설정하지 않아 로그인 대기 화면을 찍었다.
테마 속성과 응답 상태만 검사했던 성공 보고는 인증 후 역할 표면 검증으로 사용할 수 없다.
이 폴더의 이미지와 report.json은 수정 도구로 다시 찍은 아래 회차를 담는다.

## 수정 회차 (18 = 표면 3 × 테마 2 × 뷰포트 3)

- 표면: `/console` `/setup` `/device`; 개발용 관리자 세션을 먼저 설정한다.
- 테마: `dark`, `light`; 테마마다 독립 브라우저 컨텍스트를 만들고 초기 스크립트로 지정한다.
- 뷰포트: 1280×800, 390×844, 320×568.
- 18개 모두 관리자 역할, 패널 조립 완료, 로그인 안내 없음, 지정 테마 일치,
  가로 넘침 0, 패널 조립 실패 0을 확인했다.
- Console의 `/api/v1/map` 및 `/api/v1/map/costmap?scope=global`은 합성 환경에서
  지도 데이터가 없어 404를 반환한다. 이를 숨기지 않아 전체 실행은 exit 1이며 **HOLD**다.
  지도 표시·실물 영상·운전 가능 상태는 이 회차로 입증되지 않는다.

파일명: `robot-<surface>-<theme>-<W>x<H>.png`. report.json에 콘텐츠 준비 여부,
인증 안내·역할·패널·넘침 계측과 실패 응답을 함께 기록한다.

## 재현

```bash
python tools/capture_surface_round.py --out-dir X:/DevTemp/rosy-theme-round
```

임시 산출물은 X:에만 둔다. 검토를 통과한 증거만 날짜별 저장소 폴더로 승격한다.
합성 지도 부재가 유지되면 exit 1/HOLD가 정상 결과이며 성공으로 바꾸지 않는다.
유효하지 않은 개발 토큰의 별도 반례에서는 401·콘텐츠 준비 실패를 탐지하고 exit 1을 확인했다.
요청 메서드·쿼리·본문·브라우저 API 인증을 보존하며 HTML 이동에만 개발용 자격을 보탠다.

## D-329 관계와 남는 검증

이 회차는 `matrix.json`을 남기지 않는다. `rosy.g2-matrix/1`의 셀은
표면×상태×뷰포트이며 테마 차원의 정식 수용은 다음 스키마 개정에서 판단한다.
Fleet 콘솔·게임 보드는 별도 서버 회차가 필요하다. 밝은 테마 운용 권장 판단은
사람 G3와 현장 조명 관측 뒤다(D-359 Consequences).
