  계정은 기존 상단 로그인·계정에 남아 있다. 기존 shell의 다섯 영역과 정답 하위 메뉴는 유지했다.

## 원격 실행 증거

새 경로가 없는 `486be4d558`에서 첫 새 Chromium 검사를 실패로 재현했다.
`98ab6f8aa5`의 영향 선택은 2,870 passed / 382 skipped / 공통 메뉴 parser 1 failed였다.
VLM 경로 줄의 새 돌아가기 링크를 기존 정답 메뉴 탐색 regex가 인식하지 못했다.
regex에 정확한 고정 링크만 선택형 title action으로 허용했고 하위 메뉴·현재 영역의 모든 검사는 유지했다.

같은 소스의 공개·SIM·VLM·기존 검수·인식 학습 브라우저 5파일은 3건 실패를 찾았다.
SIM 미설정 응답에서 networkidle을 기다리던 새 시험은 실제 돌아가기 링크를 기준으로 바꿨다.
기존 픽셀 검수 시험 두 viewport는 같은 URL의 새 일반 바로가기와 기존 상태별 검수 동작을 구분하도록
`#pixel-review-link`를 선택했다. 원래 사진·승인·다음 대기 assertion은 유지했다.
