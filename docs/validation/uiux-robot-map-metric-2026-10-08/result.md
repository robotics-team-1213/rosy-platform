# Robot Console 지도 축척 검증 (2026-10-08)

## 발견과 변경

기존 지도 캔버스는 격자 폭과 높이를 각각 캔버스 전체에 맞춰 늘렸다. 100×80 셀 지도를 세로에 가까운 모바일 캔버스에 그리면 같은 1m가 가로·세로에서 다른 픽셀 길이가 된다. 계획 경로의 굽음, 로봇 방향과 주변 장애물 간격이 왜곡될 수 있다.

점유 지도·비용 지도·계획 경로·로봇·선택 십자선에 같은 정사각 셀 축척을 적용하고 지도를 캔버스 가운데에 맞췄다. 남는 여백은 지도 밖으로 취급한다. 여백을 누르거나 키보드 십자선이 격자 밖에 있으면 좌표와 요청을 만들지 않는다. 지도 패널의 기존 크기와 조작 권한, CORE API는 그대로다.
