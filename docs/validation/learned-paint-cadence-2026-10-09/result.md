# Pinky learned paint의 추론 지연과 마스크 수명 충돌

**판정: DEVICE 읽기 전용 재현, 주행 HOLD.** 2026-10-09 KST, Pinky 9dfk의 설치본 `2026.10.08-055`(source `e8efc5cb510c9a5c454b333d436a60857fb22a0e`)에서 ROS 영상·odom을 구독하고, 설치된 모델과 `LearnedPaintWorker`를 별도 프로세스로 실행했다. 명령 발행, 설정 변경, 녹화, E-Stop 조작은 하지 않았다. 이 기록은 [앞선 운영 `keep_debug` 25/25 fallback](../learned-paint-live-2026-10-09/result.md)의 원인 가설을 좁힌다. 운영 노드 내부 상태를 직접 읽은 증거는 아니다.

## 재현

설치본 ROS 환경과 같은 domain/RMW에서 [읽기 전용 probe](evidence/probe.py)를 표준입력으로 실행했다. 인수는 `--namespace /rosy_26 --pointer /var/lib/rosy/models/shadow --threads 2 --frames 50`이었다. `ModelSlot`을 먼저 로드하고, 실제 `camera/front`·`odom` header stamp로 `mask_for`를 호출했다. 운영 노드와 같은 `wz` 신선도·0.15 rad/s 게이트를 사용했다. 별도 프로세스의 모델 추론이므로 운영 노드와 CPU를 공유하는 순간의 측정이며, 운영 콜백 스케줄을 그대로 재현한 것은 아니다.

| 측정 | 값 |
|---|---:|
| 설치 모델 revision | `lane-seg-20261006-28e8454d` |
| 수신 영상 / 유효 odom | 50 / 50 |
| 회전·odom 부재로 `every_n=1`이 된 영상 | 0 |
| 영상 간격 중앙값 | 124.8 ms |
| learned mask / fallback | **0 / 50** |
| 마지막 완료 추론 지연 / worker 오류 | 354.2 ms / 없음 |

같은 방식의 앞선 예비 실행에서는 50장 중 learned 4장, fallback 46장이었고 영상 간격 중앙값 128.1 ms, 마지막 추론 386.8 ms였다. 표본 변동이 있어 "항상 0"이라고 일반화하지 않는다. 두 실행 모두 학습 페인트의 안정적인 사용률을 보이지 못했다.

## 원인과 반례 논의

현재 `mask_for`는 결과가 원본 영상보다 `every_n=2`프레임 넘게 오래되면 거절한다. 약 8 Hz에서는 제출 뒤 약 250 ms 안에 결과가 나와야 이 게이트를 통과할 기회가 생긴다. 별도 추론 327.7–337.4 ms와 이번 worker 완료 354.2 ms는 이 창보다 길다. fresh odom 50/50과 `every_n=1` 0/50은 회전 게이트가 이번 재현의 원인이라는 가설을 배제한다. 모델 로드·추론 오류도 없었다. 운영 노드의 모든 fallback에 같은 이유가 적용된다고 확정하려면 해당 노드의 실제 결과 나이·reset 원인 계측이 더 필요하다.

| 대응 가설 | 얻는 것 | 반례·현재 판정 |
|---|---|---|
| `every_n` 또는 `stale_s`만 확대 | 결과 사용률 증가 가능 | 로봇이 0.35초 동안 이동·회전하거나 벽/분기가 나타나면 과거 이미지 좌표의 선이 현재 선이 아니다. 주행용으로 채택하지 않는다. |
| 빠른 모델로 추론 시간을 줄임 | 현재 수명·불확실성 게이트 유지 | Pi 동시 부하에서 지연 분포와 실제 사용률을 재측정하고, 사람 검수 정답에서 false carry·벽 진입을 비교해야 한다. 후보 실험으로 채택한다. |
| 직전 마스크를 odom으로 워프 | 한쪽 선 가림의 위치 추정 후보 | odom은 같은 물리 경계 ID나 새 장애물의 부재를 보증하지 않는다. [10/7 시간 결합 점검](../lane-boundary-identity-2026-10-09/result.md)의 반례 재생에서 모순 탐지용 shadow 후보로만 둔다. |
| 넓은 `drivable` 면적 또는 지도 경로로 계속 진행 | 관측 공백을 채운 듯 보임 | 10/7 STOP 구간에도 하단 바닥 면적이 넓었다. [위험 구간 기록](../lane-risk-segments-2026-10-09/result.md)에 따라 진행 승인으로 쓰지 않는다. |

다음 실험의 합격 조건은 같은 설치 장치·동시 부하에서 새 모델의 추론 p95가 **카메라 한 주기 이내**이고 `mask_for` learned 사용률이 충분히 높으면서, 검수된 10/6·10/7 경계 ID·벽/분기 평가에서 false carry와 위험 진행이 증가하지 않는 것이다. 한 주기 목표는 이번 125 ms 관측에서 도출한 **후보 기준**이며 ADR 승인 기준은 아니다. 사람 정답이 없는 현재는 정확도 합격을 선언할 수 없다. D-475의 승인 평가와 D-205 재생·SIM·실물 수용 전에는 learned paint와 odom prior를 주행 권한으로 승격하지 않는다. CORE 단일 최종 `/cmd_vel`과 불확실 시 STOP은 유지한다.
