# Pilot 휴대폰 주행 조작 배치 · LOCAL

판정: **부분 개선 / Pilot 전체 HOLD**. 이 회차는 휴대폰 주행 화면의 조작 접근성과 영상 면적을 평가한다. 로봇의 실제 이동이나 영상 연결 품질을 수용한 결과는 아니다.

## 평가와 선택

- 기준 화면 390×844에서 HUD의 모델·차선 인식·영상 보기 설정이 두 줄을 차지해 좌우 회전 버튼이 첫 화면 아래로 밀렸다. 첫 화면에는 영상, 비상 정지, 전진·후진, 스틱이 보였고 회전은 스크롤이 필요했다. 320×568은 제한된 높이 때문에 기존의 조작부 내부 스크롤과 안내를 유지한다.
- 조작부 높이만 늘리면 영상 면적이 기존 브라우저 기준인 화면의 20% 아래로 떨어진다. 회전 버튼을 전진·후진보다 위로 옮기면 주행의 주 조작이 밀린다. 따라서 보조 설정을 기존 도구 패널로 옮겨 HUD를 줄이고, 긴 휴대폰에서만 조작부 높이를 늘렸다.
- 390×844 후보 캡처에서 영상은 비율을 유지하고 HUD·상단 바·조작부와 겹치지 않는다. 전진·후진·좌우 회전 및 스틱이 첫 화면에 들어오며, 비상 정지와 도구·종료는 상단에 남는다. 320×568의 회전 스크롤 안내는 계속 표시한다.
- 390×844에서 설정을 펼치면 도구 패널의 긴 내용이 영상 칸 끝에서 잘렸다. 휴대폰 폭의 기존 패널 내부 스크롤 규칙을 공통으로 적용하고, 패널 아래의 닫기까지 스크롤해 확인했다.
