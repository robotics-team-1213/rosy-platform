# 천장 카메라 직사각형 보정 실측 — 2026-10-07

현장 천장 Rosy Cam 실프레임에서 두 가지 보정 경로가 위에서 본 직사각형을 만드는지 잰 회차다. 코드는 바꾸지 않았다. D-515(관제 조감도)의 근거다.

## 방법

- 사이트 PC의 site Caddy LAN 카메라 경로(사설 주소에서 `/api/fleet/vision/sources`·`/lease`, 토큰 없음, 읽기 전용 리스)로 `ceiling_north` 프레임을 받았다. 계정·설정은 만들거나 바꾸지 않았고, 사이트 PC 임시 파일은 지웠다.
- 받은 것: 원본 프레임, `mode: auto` 리스 프레임, `field-proposal` 결과.
- 수락된 추적 보정(`paint-f81a872f5cd8`, `use: display-only`)의 `map_to_image`로 사이트 사각형(`corner_world_m`, ±1.405 × ±0.63 m)을 영상에 투영하고, 그 역으로 원본을 2 mm/px 위에서 본 직사각형으로 폈다.

## 관찰

| 항목 | 값 |
|---|---|
| 프레임 | 1280×720, `rotation_deg` 90, 나이 243 ms, 렌즈 `standard` 5.4 mm hfov 67.8° |
| D-484 자동 보정 (`mode: auto`) | 돌지 않음. `field-proposal`은 `proposal: null`, 사유 "field runs past the frame". 리스 프레임은 원본, `X-Frame-State: field-unavailable` |
| 경기장 오른쪽 아래 모서리 | 영상 밖 — (1.405, −0.63) m → (1229, 772) px |
| 자동 보정 출력 비율(픽셀 변 길이 평균, `output_aspect` 0) | 1.951 — 실제 2.230보다 12.5% 납작 |
| 교정 기반 직사각형 | 1405×630 px, 비율 2.230(실제와 같음), 영상 밖 영역 0.6% |
| 원형 교차로 원의 진원도(타원 단축/장축) | 원본 0.81 → 교정 기반 0.98 |
| `site-cameras.yaml` | `corner_markers`(ArUco 30–33)인데 프레임에 마커가 없다 |

렌즈 왜곡은 이 렌즈에서 작다(직사각형 결과의 차선이 곧고 원이 둥글다). 렌즈 계수 없이 원근만으로 충분했다.
