# 안전 검토 기록의 이력 참조 복구

전체 CI [38939987985](https://github.com/robotics-team-1213/rosy-platform/actions/runs/38939987985)의 root-test-3of3에서 안전 검토 예외 95개의 이전 SHA가 현재 이력의 조상이 아니어서 실패했다.

- 기준 commit: `origin/main`의 `303d7d66de7e3011a0a6e446b6faad189c1d1630`.
- 대조: 각 원본과 후보의 tree, 순서를 유지한 부모 tree 목록, 작성·커밋 시각을 비교했다. 95개 모두 유일한 후보를 찾았고 현재 기준의 조상이다.
- 메시지: 92개는 전체 메시지가 같다. 나머지 3개는 메시지 안의 커밋 참조만 바뀌었다. 7~40자리 참조가 해석되는 경우 해당 tree로 치환했을 때 전체 메시지가 같다.
- 결과: 행 수·순서·기존 검토 사유를 유지하고 `original_commit`으로 이전 SHA를 보존했다. 새 예외나 장치 수용은 추가하지 않았다. 검사 로직은 변경하지 않았다.
- BASELINE commit도 `46b8720c297db5729297de4442051a0265f097ea`에서 동일 tree·부모 tree·메시지·시각의 `5496c22dc81e1efd20a14d05419bb8d4e25658bd`로 연결했다. 이전 참조는 PR CI 38941477584의 scope 검사를 막았다. 현재 참조는 위 기준의 조상이며 안전 검토를 시작한 기존 경계를 유지한다.

행별 대조 결과는 [JSONL](evidence/exempt-history-map.jsonl)에 있다. 각 행은 커밋·tree·메시지 SHA-256·시각을 이름이 붙은 필드로 기록한다. 원본 객체는 로컬에 남아 있어 비교할 수 있었지만 GitHub에서 다시 가져올 수 있다고 가정하지 않는다. 이 기록은 기존 SOURCE 검토와 현재 이력의 연결을 복구하며, 원래 검토의 전제·미수용 범위를 유지한다. 최종 커밋의 시험과 독립 검토 결과는 PR #69에 기록한다.
