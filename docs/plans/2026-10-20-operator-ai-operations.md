# 관제 AI 운영 배포·실행 연결 계획

> 기존 조회 버전의 후속 실행이다. `superpowers:executing-plans`로 현재 세션에서 직접 구현한다.

**Goal:** 기존 통합관제·Discord 구성을 보존하면서 보호된 운영 설치, 명시적 이동 작업 접수, 한국어·영어 평가를 시험할 수 있게 한다.

**Architecture:** 대화 의미 해석은 조회 권한을 유지한다. 기명 운영자의 별도 구조화된 이동 요청만 기존 `IntentExecution` → `FleetTaskService`에 연결한다. 새 장치 worker나 Discord 신원 위장은 만들지 않는다. AI PC의 기존 동일 SHA 보호 설치 뒤 독립 operator 평가 증거를 추가 설치한다. 언어/모델 후보 선정은 승인 모델 변경과 분리한다.

**Spec:** D-810 설계의 실행·배포 후속 범위. 추가 계약은 D-821/API v1.290이다. 사용자 요청은 구조 구현·시험과 기존 Discord 점검이며 실제 배포·움직임·외부 메시지 성공을 소스 시험으로 대신하지 않는다. [검증 결과](../validation/operator-ai-operations-2026-10-20/result.md)에 실제 모델 19/19 통과와 미해결 FULL 실패 두 건을 구분했다.

## 구현 단위와 완료 조건

- [x] `assistant/execution.py`: 기존 대화의 소유자·CONTROL 답변·선택 로봇·30초 유효성과 현재 권한/승인 확인. 운영자가 지정한 유한 좌표로 이동 Task 하나 접수. 원문의 요청 ID와 principal에서 기존 Task 멱등 키를 만들고 반복/변경 본문 충돌·권한 철회·실행 비활성·재시작을 시험했다. 기존 Discord 실행 owner는 보존한다. 연결은 기본 OFF이며 별도 설정으로 켠다.
- [x] 다국어: 한국어/영어 locale 계약·브라우저 음성 언어 선택·고정 응답과 관측 문구를 분리했다. 언어 변경은 진행 중 녹음을 취소한다. 실제 고정 모델에서 두 언어·부정·인용·안전 우회 19개 사례를 통과했다. 추가 언어는 후보 조사와 평가 절차로 남기고 지원하지 않는 locale을 추측하지 않는다.
- [x] `deploy/site/install_operator_broker.py`: 기존 보호 설치의 source SHA·wrapper·venv를 재사용하고 독립 평가 증거를 hash 검증한다. source/profile/전체 사례/시각을 설치 전 검증하고 operator 설정만 원자적으로 설치·readback·실패 rollback한다. 기존 Discord·SSH·spend marker를 변경하지 않는다. `--check` 무변경과 실패 복원을 모의 시험했다.
- [x] 한국어·영어 오픈소스 후보의 공식 모델 카드/라이선스·실행 엔진·실측 항목을 운영 안내에 기록했다. 추천은 실제 정확도·지연·메모리 측정으로 승격하기 전의 후보다.
- [x] 기존 Discord 구성·설치 기록을 찾고 Bot/채널 API 200과 설정 일치를 읽기 전용 확인했다. 통합관제와 Discord의 공존 회귀 263개를 통과했다. 실제 메시지 송수신/실기 작업을 수행한 것으로 표시하지 않았다. 토큰·주소·실제 사용자/채널 ID를 공개 문서에 기록하지 않는다.
- [x] 원격 RED → 구현 커밋 → 해당 GREEN을 기록했다. FULL 22개 실행과 실제 Chromium/실제 모델을 구분하고 source SHA·실패·건너뜀·수행 범위를 남겼다. 자기 변경의 실패는 수정했으며 전체 통과로 합산하지 않았다.
- [x] 최신 통합 SHA의 FULL·실제 Chromium 회귀와 소스 착지 관문 통과. [후속 검증](../validation/operator-ai-landing-2026-10-20/result.md)에 30,196 FULL 통과·1,953 skip과 브라우저 532 통과, 같은 SHA의 실제 모델 19/19 및 로컬 main 병합을 기록했다.
- [ ] 과거 프로세스 종료 실패 두 건의 원인 확정. 이번 FULL에서도 재현되지 않았으며 진단을 추가했다. flake·기존 실패로 등록하거나 원인을 고친 것으로 표시하지 않는다.
- [ ] 같은 SHA의 Discord/AI 보호 설치·서명된 사이트 배포·실제 채널 멘션/결과 통지·승인된 장치 동작·관제 PC 실제 발화 수용. 소스/모의 검증으로 대신하지 않는다.

모든 product 변경은 기존 본인 worktree `feat/operator-ai`에서 한다. 로컬 pytest·모델 자동 승격·운영 설정 임의 생성·UNKNOWN 자동 재전송을 하지 않는다. 기존 작업 화면은 실제 목적지 입력과 Task 상태 표시 경로로 유지한다. 본 API는 기존 목적지/작업 UI와 통합 시험에서 사용할 실행 접수 경계이며 모델 출력의 실행 권한이 아니다.
