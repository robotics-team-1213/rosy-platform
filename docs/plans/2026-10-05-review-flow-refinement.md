# 사진 검수 반복 작업 개선

사용자 추가 개선·즉시 로컬 머지 요청에 따라 D-459/D-461의 기존 검수 계약을 보완한다.
필터는 사진 목록·현재 선택·이전/다음·URL 모두에 동일하게 적용한다. 해당 사진이 없으면
편집기를 숨기고 전체 보기로 복귀할 행동을 제공한다. 상태가 바뀌어 필터에서 빠진 사진은
전체 보기로 전환해 방금 저장한 결과를 계속 보여준다.

실수 복구는 현재 사진의 마지막 라벨 저장 한 번만 되돌린다. 원본 초안 전체 복원이나
서버 이력 rollback 대신 기존 save API와 현재 version CAS로 직전 박스를 저장한다.
승인은 복원하지 않고 검수 대기를 유지한다. 승인·제외·사진 이동·새로고침 시 복구 기억을
비운다. 저장 실패·409에서는 복구할 내용을 유지하고 최신 읽기 전 추가 저장을 막는다.
새 API, 학습 실행, 모델 활성화, segmentation 승인은 추가하지 않는다.

실제 Chromium에서 필터·빈 상태·URL·편집·삭제/되돌리기·실패·stale tab을 별도 state로
검증하고 PC/모바일 dark/light 배치를 확인한다. 관련 pytest와 known_failures 비교,
main 동기화 후 재검증, 사용자 승인 범위의 local fast-forward 착지를 수행한다.
