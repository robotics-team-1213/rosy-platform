# OMX 파지 구간 화면 실행 검증

목표는 실제 브라우저에서 원본 프레임 확인 → 파지 구간 선택 → 저장 → 새로고침 복원 → JSON 다운로드 → 실제 LeRobot 구간 내보내기를 완료하는 것이다. 사용자 승인 범위는 수정·검증·커밋·로컬 main 병합까지이며 원격 push·장치 실행은 포함하지 않는다.

## 완료 기준

- [x] 깨진 이미지가 보이는 현재 화면을 재현하고 이미지 실제 디코딩 실패를 브라우저 회귀 시험으로 확인한다.
- [ ] 기존 CSP를 유지하면서 프레임을 표시한다. 보이는 요소만으로 이미지 성공을 판정하지 않는다.
- [ ] 실제 Edge에서 desktop 1440×1000, phone 390×844 화면을 확인한다.
- [ ] 미판정/train 저장 거부와 성공 구간의 독립 session별 train/eval/test 저장·복원을 확인한다.
- [ ] 내려받은 JSON을 실제 exporter에 입력해 원본 bytes·int64 clocks·대응 프레임 보존을 확인한다.
- [ ] 데이터 출처·화면·실행 결과·한계를 validation 기록에 남기고 원격 시험 및 독립 검토 후 로컬 main에 병합한다.

## 확인된 원인과 범위

`70c295c398`의 원본 프레임 API는 JPEG를 정상 반환하지만, OMX JS의 `URL.createObjectURL`이 만든 `blob:` URL을 기존 `img-src 'self' data:` 정책이 차단한다. 원격 Chromium 회귀 시험은 `to_be_visible`만 검사해 깨진 이미지 요소도 통과했다. 실제 Edge의 `naturalWidth=0`과 CSP console 오류로 재현했다.

수정 범위는 OMX 이미지 렌더링과 해당 회귀 시험, D-833 부록, 실행 증거다. 새 보안 허용 출처·데이터 변환·실물 실행·가짜 사람 승인 기능은 추가하지 않는다. 실물 촬영 OMX 자료는 제공되지 않았으므로 합성이라고 표시한 실제 LeRobot 0.4.4 파일과 격리 작업대만 사용한다. 합성 성공 선택은 시험용이며 학습 정답으로 사용하지 않는다.
