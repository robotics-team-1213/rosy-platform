# Rosy Account 공통 프로필 연결

기존 D-757 구현과 프로필·운영 감사에서 남은 연결을 완료한다. 계정 정본은 기존 Fleet 원장,
편집 화면은 `/console/profile`로 유지한다. 프로필 표시 실패를 권한 허용으로 처리하지 않는다.

1. 현재 access token에 결속된 userinfo, 공통 Python receiver, CORE/Games/학습 session을 연결한다.
2. Fleet 프로필에 역할과 실제 자원별 권한을 구분해 표시한다. Robot/Pilot/학습/Games에서
   동일 표시 이름과 내 계정 진입점을 제공한다. 기존 입력·작업은 새 탭 진입으로 보존한다.
3. Cam/Pilot 네이티브도 같은 userinfo 계약과 브라우저 프로필 진입을 사용한다.
   프로필 통신은 정지·장치 명령 경로와 분리하며 계정 전환 후 이전 이름을 버린다.
4. 유효/정지/회수/타 계정/장애, 프로필 저장 후 앱 재조회, 좁은 화면·키보드,
   정확한 grant 표시를 원격 API·Chromium과 native 빌드로 확인한다.
5. 배포·TLS·client 등록·실계정 이관 준비를 확인하고 가능한 운영 연결을 진행한다.
   관리 권한·인증서·접속 장치가 없는 항목은 구체적 증거를 남긴다. 키/계정 원문은 공개 문서에 넣지 않는다.

구현·원격 시험·native·local main·CI·배포·실사용 수용을 각각 기록한다.
사용자는 구현과 커밋·로컬 병합을 승인했다. 원격 push는 이번 요청으로 추정하지 않는다.
