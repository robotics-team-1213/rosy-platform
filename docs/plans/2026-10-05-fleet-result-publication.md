# Fleet 학습 결과 export의 완전한 게시

기존 D-449 공통 Episode와 D-18 receipt의 오프라인 연결 계약을 유지한다.
최종 JSON 경로에 직접 쓰다 중단되면 부분 파일이 남아 재시도를 막으므로,
같은 디렉터리의 고유 임시 파일에 완전히 쓰고 fsync한 후 배타적 hard link로 게시한다.
저장 후 원본 Episode/profile/receipt를 재검증하며, 덮어쓰기와 권한 승격은 하지 않는다.

검증은 저장 동기화 실패 후 최종 경로 부재와 재시도, 경쟁 게시자의 결과 보존,
저장 중 receipt 변경 거절 및 기존 정확한 상관 키/출처 회귀를 포함한다.
일반 예외에서는 자기 임시 파일만 지우고, 강제 종료로 남은 임시 파일은 자동
수거하거나 기존 결과로 취급하지 않는다. hard link 미지원 시 fail closed한다.
전원 손실 뒤 디렉터리 내구성, 실제 Fleet 수신, 독립 과제 성공은 별도 증거다.

다음 전체 목표 작업은 같은 정책 owner session의 실제 journal을 원본 실행 키가
보존된 D-18 receipt와 Episode에 연결하고 Fleet 결과를 다시 읽는 것이다.
기존 작성 fixture의 일치는 같은 실행 고리의 증거가 아니며, 이 파일 게시 수정이
정책 승격·새 issuer/lease·장치 배포·동작 허가를 만들지 않는다. 실제 주행의
모든 로봇·시도 합계 0.20m 제한과 정지 여유 및 현장 승인 경계는 유지한다.
