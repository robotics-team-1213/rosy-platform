# 검수 AI 실행과 버전 조회 구현 계획

브랜치: `feat/review-ai-run-b03f29`. 계약: D-764, D-755, D-663.

## 범위

기존 검수 앱의 객체/픽셀 화면, HTTP 서버, 협업 권한, SQLite 후보·피드백·이력,
고정 모델 adapter, 관련 시험과 운영 설명을 함께 연결한다. 새 의존성을 추가하지 않는다.
운영 자료와 사람 라벨은 보존하며 시험은 격리된 자료 또는 복사본에서 수행한다.

1. 기존 모델 adapter를 호출하는 단일 사진 실행·취소와 영속 결과를 구현한다.
2. 인증된 요청자·현재 revision·입력 해시를 묶고 취소·변경·권한 철회 시 등록을 차단한다.
3. 기존 화면에 실행 상태·요청자·모델·결과 조회를 연결하고 미저장 편집을 보존한다.
4. 전체 이력 페이지와 읽기 전용 이전 버전을 연결한다. 미보존 스냅샷은 명시한다.
5. 명시 경로 커밋 후 원격 pytest와 known_failures 비교, Chromium 실제 UI 검증을 수행한다.
6. 독립 명세/코드 리뷰를 반영하고 `tools/land.py --tests auto --no-prune`으로 로컬 main에 착지한다.

## 완료 판정

AI 요청→종료 상태→후보/의견 재조회가 연결되고 기존 라벨·승인은 자동 변경되지 않는다.
실패·권한 철회·취소·입력 변경에서 결과 등록이 차단된다. 전체 이력과 선택 버전이 조회되고
화면 전환 시 이전 사진의 결과가 잔류하지 않는다. 새 기능은 기존 Ctrl+K와 키보드로 접근한다.

실제 OAuth 앱 등록, 운영 모델 설정·배포, 사람 승인 정답 기반 학습 품질 시험은 별도 증거가
필요하다. 영역별 지적 편집·담당자 배정은 이번 실행/이력 연결의 완료 조건에 포함하지 않는다.

## 구현과 검증 기록

- AI 작업·취소·권한 철회·입력 변경 검사, 후보/의견 저장, 전체 이력과 저장 버전 조회를 연결했다.
- 독립 명세·코드 리뷰를 수행했다. 차선 의미 체계 검사, 비소유 실행기 취소 차단, 객체 클래스
  해시 고정, 사진 전환 시 과거 정보 제거를 반영했다.
- 합성 자료의 실제 Chromium에서 키보드 요청→완료→후보 조회, 취소, 미저장 픽셀 보존,
  24개 이력 페이지와 과거 마스크 조회를 확인했다. 운영 자료는 변경하지 않았다.
- 357장 복사 자료의 데스크톱/모바일 10화면에서 가로 넘침·페이지 오류가 없었다.
- 원격 첫 관련 시험에서 서버 fixture 2건 실패를 고쳤다. 첫 착지 시험은 2725 passed,
  270 skipped와 새 canvas 등록 누락 1건이었다. 등록과 공용 palette 사용을 수정했다.
  사진 조회 실패의 이전 캔버스 잔류도 추가로 수정했다. 최종 재시험·착지 결과는
  `tools/land.py`의 해당 브랜치 로그와 최종 사용자 보고에 남긴다.
- 실제 모델 실행·운영 배포·학습 정확도를 증명하지 않는다. 기존 6클래스 객체 자료와
  road_surface/1 픽셀 자료는 현재 고정 모델의 의미 체계와 달라 실행을 차단한다.
