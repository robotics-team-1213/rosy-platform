# 무마커 시작점 지정

사용자가 승인한 방식: 경기장 사각형·차선으로 보정하고 시작점 자체에는 마커를 요구하지 않는다. 기존 map 좌표를 유지한다. UI/UX 리팩터링은 하지 않는다.

- Fleet가 승인된 paint-fit 보정의 source/map/revision에 묶인 시작 위치 x/y(m), 방향 yaw(rad)를 저장한다. 마커는 필요하지 않다.
- 관제 화면은 지도 선택 또는 좌표 입력과 방향 입력으로 초안을 만들고 명시적으로 저장한다. 저장은 주행·initialpose·로봇 신원 연결을 실행하지 않는다.
- viewer는 읽기, operator는 저장·삭제한다. 예상 revision으로 동시 편집을 거절한다. SQLite 저장은 보정 DB와 같은 writable 데이터 디렉터리에 둔다.
- 보정 철회·변경 또는 map 변경은 저장된 시작점을 유효하지 않은 것으로 표시한다. 이전 숫자를 실제 로봇 위치로 재사용하지 않는다.
- 지도에 시작점과 방향을 표시한다. 익명 무마커 관측만으로 로봇 이름 또는 방향 확인을 주장하지 않는다.
- 검증: 권한, 범위, 동시 편집, 재시작 지속성, 보정 변경, 지도 클릭 좌표/여백, 클릭이 주행으로 전달되지 않는 브라우저 시나리오를 확인한다. 현장 보정·두 로봇 신원 연결은 별도 검증한다.
