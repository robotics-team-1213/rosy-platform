# /dashboard 브리지 퇴역 기준 (비평 P1의 남은 절반)

**목적:** 임페커블 비평(2026-09-26) P1이 요구한 두 가지 — 목적지 명시와 퇴역 기준 — 중 목적지는
브리지 회차(31e08eea, `#surface-bridge`)로 열렸다. 이 계획은 나머지 퇴역 기준을 검증 가능한
조건으로 못 박아, 다음 회차들이 판단 근거 없이 홈을 고치거나 늘리지 않게 한다.

**구조:** 운용·설치·장비 화면의 소유지는 역할 화면이다(`src/hmi/dashboard/panels.yaml`이 단일
출처). `/dashboard`는 인증(페어링 드로어)과 목적지 브리지를 소유하고, D-204 이행이 끝날 때까지
레거시 조작 화면(운용/점검 뷰)을 임시로 함께 싣는다.

---

## 퇴역 기준

홈의 운용/점검 뷰를 제거하려면 아래 다섯 조건이 모두 충족돼야 한다. 각 조건은 회차 기록
(`docs/validation/`)이나 브라우저 회귀로 증명한다.

### C1 — 패널 동등성 (대조표가 단일 증거)

홈이 소유한 패널마다 역할 화면 대응 패널이 존재하고 통과해야 한다. 2026-09-29 기준 대조:

| 홈 패널 | 역할 화면 대응 | 상태 |
|---|---|---|
| 수동 운전(텔레옵 패드) | `console.teleop` | 이관됨 |
| 운전 모드·정지/해제 | `console.mode` + 셸 E-stop | 이관됨 |
| 현장 지도(초기 위치·목표) | `console.map` | 이관됨 |
| 전방 카메라 | `console.camera` | 이관됨 |
| 차선 추종 | `console.line_follow` | 이관됨 |
| 도킹 | `console.docking` · `setup.docking` | 이관됨 |
| 텔레메트리·요약 | `console.overview` | 이관됨 |
| 웨이포인트 / SLAM·위치 | `setup.waypoints` · `setup.localization` | 이관됨 |
| 도크 관리 / 교통 정책 | `setup.dock_admin` · `setup.traffic_policy` | 이관됨 |
| 이벤트 / 보안·안전 정책 | `system.events` · `system.security` | 이관됨 |
| 보드·호스트·네트워크·릴리스 | `host.*` / `host.operations` | 이관됨 |
| API 토큰 관리(현장 설정) | 미배치 | **남음** |
| 로봇 신원 표시 이름 폼 | `/device`에서 다루는 중(2026-09-28 후속) | **확인 필요** |
| ROS 반응성·충돌 표(점검) | 미배치 | **남음** |

"남음" 행이 모두 배치되고 표가 닫혀야 C1이 충족된다. 이 표는 이관 회차마다 같은 커밋에서
갱신한다.

### C2 — 새 패널 단일 규칙

새 조작·점검 패널은 역할 화면에만 등록한다(비평 P1 지시). 홈에 패널을 추가하는 커밋은
이 계획 위반이다. `panels.yaml` 밖에서 홈에 기능을 다는 것도 같은 위반이다.

### C3 — 수용

- 이관 패널별 브라우저 회귀(G2) 통과 기록.
- 역할 화면 표면 단위 G3 사람 평가(D-153)에서 운용자가 "홈으로 돌아갈 이유"를 찾지 못한다.

### C4 — 안전 보존

역할 화면 셸 E-stop과 홈의 즉시 정지가 동등하게 도달 가능함을 브라우저 회귀가 증명한다.
홈의 운용 뷰를 제거하는 회차는 E-stop 가시 회귀를 반드시 포함한다.

### C5 — 인증 복귀 보존

`/dashboard?return_to=` 인증 복귀 경로(`surface-navigation.js`)는 퇴역 후에도 유지된다.
퇴역은 조작 화면의 축소이지 로그인 브리지의 축소가 아니다.

## 퇴역 회차가 하는 일 (기준 충족 후 별도 회차)

1. 홈에서 운용/점검 뷰 전환과 해당 DOM·JS를 제거한다. 남는 것: 상단 바(브랜드 홈 링크·
   브리지·접속 키), 인증 드로어, 연결 상태.
2. 텔레메트리·상태 요약이 필요한 자리는 `console.overview`가 소유한다.
3. 브랜드 홈 링크(D-335)와 `#surface-bridge`가 홈의 안내를 이어받는다.

## 지금 정하지 않는 것

- 이행 일정과 패널별 설계는 D-204 ADR(예약: `tools/harness/harness.yaml` adr_gaps,
  `feat/role-surfaces-s1`)과 각 이관 회차가 소관이다.
- 홈의 퇴역이 Fleet·경기 보드에 미치는 영향은 없다(별도 호스트, D-275).
