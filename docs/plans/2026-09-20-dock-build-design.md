# 실물 도크 조립 설계 — 기구·전장·태그·인수 (DNC)

- 작성: 2026-09-20. 상태: Draft (자재·공구 대기). 관련: D-28, DNC-001~007,
  `dock/README.md` (ROSY-DOCK-001), `2026-09-02-docking-station-design.md`
- 목적: bench 1기分の 도크 실물을 조립·통전·플래시하고, DNC-007 태그 검출의
  물리 상대와 `teach-by-docking`까지 닫는다.

## 1. 자재 (1기분)

- ESP32 보드 1 (펌웨어 `dock/firmware/rosy_dock/rosy_dock.ino`)
- 접점: 바닥 접점 한 쌍 + 로봇 측 접점. **무부하 맨접점에 통전 금지** —
  리밋스위치 눌림 확인 후 접점 인가가 펌웨어 첫 의무다 (ADC 프로브 폐기)
- 전원: 2S 팩 대응 출력 (과전압 8.7V·과전류 3.0A 폴드백 임계 준수)
- 태그: ArUco `DICT_4X4_50`, ID 7, 한 변 100mm, 무광 인쇄. 도크 정면 수직면,
  바닥에서 태그 중심까지 높이 기록 (상대포즈 solvePnP의 외참조 — 실측값으로
  `dock_types` 항목에 함께 적는다)
- Wi-Fi: STA 자격증명은 NVS에 직접 — 소스·문서에 자격증명 없음
  (`test_dock_contract.py`가 빌드를 깨뜨린다)

## 2. 순서

| 문 | 작업 | 통과 조건 |
|---|---|---|
| D0 플래시 | ESP32에 스케치 플래시 + NVS Wi-Fi | 부팅 로그, `/status` 200 |
| D1 무부하 | 리밋 해제 상태 통전 시도 | 출력 0V (미체결 인터록) |
| D2 부하 | 더미 로드(또는 로봇 정지 상태 접촉) | `load_present=true`, 전류 0.05A 이상에서 `charging=true` |
| D3 태그 | 태그 부착 + 카메라 정면 0.3~1.0m 촬영 | `ArucoDockDetector` range 오차 ±2cm (합성 기준값과 대조) |
| D4 티치 | 로봇을 도크에 밀어넣고 teach | `docks.json` 포즈 기록, `map_id` 일치 (DNC-005) |
| D5 왕복 | 스테이징→획득→접근→착좌 3회 | 3/3 `CHARGING` (충전 2소스 확인, DNC-006). 실패는 `DOCK_FAILED` 종착, 자동 재시도 없음 |

## 3. 안전 수칙

- 맨접점 통전 금지는 사람이 지키는 게 아니라 펌웨어가 지킨다 — D1이 깨지면
  조립 중단, 펌웨어 수정 후 D0부터
- 충전 확인은 2소스(도크 전류 + 팩 전압 비하락). 도크 `charging:true` 단독으로
  D-27 셧다운을 억제하지 않는다
- 언도킹은 오도메트리 후진 only — 센서를 보지 않는다 (DNC-004)

## 4. 산출물

- `docks.json` (기종: detector=aruco, tag 제원 + 실측 높이)
- 문별 사진·`/status` 로그·충전 2소스 기록
- 실패 로그 (접촉 불량·태그 오검출 — 재현 조건 포함)
