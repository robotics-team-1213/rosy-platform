# D-598 후속 구현의 입력과 소비 경계

2026-10-16. D-775 구현 뒤의 후속 설계다. 주행 계약이나 현장 수용을 변경하지 않는다.
[실측 입력 점검](../validation/measured-camera-lifecycle-2026-10-16/evidence-inventory.md)의
미확보 항목을 선행 조건으로 유지한다.

## 소유자와 입력

| 단계 | 소유자 | 입력과 결과 |
|---|---|---|
| 영상에서 관측 생성 | Vision | 승인된 실측 렌즈와 검증된 카메라 자세·마커 높이/offset으로 관측 생성. D-775 바닥 미리보기 승인만으로 sighting을 만들지 않음 |
| 현재 자세와 오차 projection | World `state/projections/map_pose.py` | sighting·핀 앵커와 같은 robot/odom epoch의 변화량. 단일 MapPose 결과와 근거 revision 보존 |
| 신원 연속성 | Fleet `identity.py`/tracking | 마커와 odom 예측으로 단일 blob만 대응. 모호·합체·가림이면 이름 해제. `CARRIED`는 약한 신원 근거 |
| 감속·지시 admission | Fleet trip 실행 소유자 | World 자세·오차와 Fleet 신원을 함께 소비. 약한 관측으로 시작·재출발·LOCALIZED 복구를 허가하지 않음 |
| 통행권과 점유 | Fleet traffic | 오차 증가를 점유 여유로 반영. 신원/위치 소실은 UNKNOWN 점유로 취급 |
| 최종 장치 명령 | CORE | 기존 command/safety 경계와 최종 검사 유지 |

D-598 본문의 옛 Fleet MapPose 소유 표기는 후속 구현 ADR에서 D-630·D-752에 맞춘다.
기존 `source="bridged"`는 odom 계산의 출처이며 새 `state="BRIDGED"`가 아니다.
상태 enum·오차 필드·속도 제한·traffic 소비를 하나의 구현 계약으로 정하기 전에는
공개 API에 이 값을 추가하거나 기존 출처를 새 상태로 재해석하지 않는다.

## 오차와 admission

D-598의 5/10 cm 경계와 0.05 m/s 제한은 현행 서비스에 적용하지 않은 제안값이다.
후속 구현은 앵커 오차, 누적 이동 거리의 오차, 누적 회전의 불확실성으로 인한 옆 오차를
분리해 보존한다. 계수는 로봇·속도·지도 축척·설치 revision별 독립 p90/검증 잔차로 구한다.
중앙값이나 합성 재생 일치를 안전 오차 상한으로 쓰지 않는다. 근거가 없는 계수는
`unmeasured`로 남기며 주행 한도를 늘리지 않는다.

`CARRIED`는 신원이 이어진 상태이고 위치 앵커가 아니다. 마커/핀만 첫 앵커와 복구를
만들 수 있다. LED는 신원을 확인하며 바닥 좌표의 정확도를 증명하지 않는다.
모호한 대응, odom epoch 변경·역행·점프·노후 입력, 지도/교정 변경은 약한 연결을 끊는다.
약한 입력은 기존 추정을 반박하고 상태를 내릴 수 있지만 상태를 올릴 수 없다.

오차 기반 BRIDGED를 적용할 때 Fleet은 새 trip 시작과 통행권 연장·기준 갱신을 거절하고,
이미 열린 trip에만 제한 속도를 적용한다. 오차 한도 초과 또는 신원 상실은 새 지시 차단과
기존 정지 경로로 이어진다. 실제 감속 명령 전달 지연과 정지 거리까지 같은 시험에서
검증해야 한다. Traffic의 기존 거리 불확실성 항을 새 오차와 중복 합산하거나 제거하기 전에
블록 길이·진입/퇴거·UNKNOWN 점유를 재계산한다.

## 재생 자료와 구현을 여는 조건

후속 replay는 단일 시각 축에 원본 frame digest/seq/수신 시각, source session·촬영 signature,
map/교정/processor revision, robot별 odom stamp/epoch, 마커·핀·LED의 실제 readback,
독립 측량 정답과 그 불확실성을 연결한다. 비밀 토큰과 원본 경로는 공개 fixture에서 뺀다.
자료 분할은 주행 세션 단위로 하며 계수 추정과 독립 검증에 같은 세션을 재사용하지 않는다.

| 필요한 근거 | 현재 판정 | 통과 기준 |
|---|---|---|
| D-636 실제 표적과 독립 바닥 측량 | 미확보 | 원본 계보, 고정 촬영 조건, 중앙/가장자리 오차 검토 |
| 높은 마커와 카메라 자세/장착 offset | 미검증 | 바닥과 별도로 독립 위치·방향 오차 측정 |
| D-587·D-593·D-596 현재 현장 readback | 역사/소스 근거만 있음 | 같은 설치·지도 revision에서 마커·핀·LED 각각 확인 |
| 지도/매트 축척과 두 로봇의 속도별 odom | 미확보 | 거리·회전 계수, 정지/회전/직선과 마커 공백 분포 측정 |
| 모호성/정지/traffic 재생 | 준비 대상 | 교차·합체·반환 마커·누락/역행·오래된 입력에서 이름 바뀜 0, 권한 확대 0 |

현장 P0 없이 P1/P2의 운영 admission을 활성화하지 않는다. 이 문서는 입력과 책임을
확정하는 준비 결과이며 D-598 구현 완료나 주행 수용 증거가 아니다.
