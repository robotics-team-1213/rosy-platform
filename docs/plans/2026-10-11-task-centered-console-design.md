# Fleet 관제 작업면 (D-651)

## Scope and mode

`operations/ui/console/index.html`, Console의 지도 배치·로봇 선택·작업 입력. Operate 모드이며 공통 역할 토큰과 네 문서의 공통 머리를 따른다. API와 CORE 권한을 바꾸지 않는다.

## Audience and job

현장 운영자는 로봇 선택 → 목적지·작업 배정 → 진행·문제 확인 순서로 일한다. 보기 전용 사용자는 같은 근거를 읽되 명령을 보내지 않는다.

## Direction

하나의 지도 작업면과 선택한 로봇 작업면. 지도에 작은 번호·위치·신호만 남기고 상세 장소·교통·관측과 표시 옵션은 접는다. 새 디자인 시스템을 만들지 않고 기존 운영 UI의 간격·상태·아이콘·명령 컴포넌트를 사용한다.

## First viewport

넓은 화면에서는 문서 내비게이션 옆에 지도와 개입·로봇 작업 영역이 선다. 지도 머리는 제목과 보기 방식만 가진다. 지도 안에 설명 상자가 바닥을 덮지 않는다. 개입 큐와 전체 취소는 작업 탭 위에 있고 로봇 선택과 배정은 같은 영역에서 이어진다. 좁은 화면은 개입·지도·작업을 한 문서에서 읽고 가로 스크롤을 만들지 않는다.

## Signature interaction

로봇 목록이나 선택 상자에서 로봇을 고르면 상세 작업면만 그 로봇으로 바뀐다. 선택은 명령을 보내지 않는다. 이전 로봇의 지도 지정과 미확정 명령은 취소된다. 작업 종류는 경로·한 바퀴·반복 중 하나씩 입력하며 폴링 중 입력과 포커스를 유지한다.

## Proof and constraints

실제 `map_v2_fleet`와 승인 교정 계보를 유지한다. 관측 만료는 좌표를 미확인으로 바꾸고 프레임 크기를 바꾸지 않는다. 오프라인·안전·교정 근거와 비활성 명령의 이유는 숨기지 않는다. 원격 Chromium의 선택·확인·결과 흐름과 배포된 현장 화면을 검증한다. 실물 이동·AprilGrid 측량 데이터는 아직 없어 물리 정확도를 승인하지 않는다.
