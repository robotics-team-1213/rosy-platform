# 영상 공간 연속 차선 주행 구현 계획

**Goal:** 기존 between 검출기를 그대로 사용해 Fleet 운영자가 버튼 갱신 없이 저속 차선 주행을 시작하고 취소한다.

**Architecture:** 영상 조향에는 지면 거리나 카메라 외부 보정을 요구하지 않는다. CORE는 관측의 검출 방식과 신선도를 확인하고 LiDAR 및 기존 IR·장애물·비상정지 관문을 유지한다. NOMINAL 기반 keep의 운전자 확인 조건은 그대로다.

1. CORE에 between 관측 출처와 OFF 중 읽기 전용 준비 상태를 추가한다. 후보·레거시·NOMINAL 관측은 자동으로 승격하지 않는다.
2. 기존 모드 API의 명시적 autonomous 요청을 추가하고 시작·틱·명령 반영에서 증거를 확인한다. 연속 모드는 전진 0.04 m/s 이하이며 로컬 복구 기동은 하지 않는다.
3. Fleet 이름 있는 운영자 경로에서 CAMERA_LINE을 요청하며 기존 감사 DB와 중지 경로를 유지한다.
4. 원격 회귀 시험과 독립 안전 리뷰 후 커밋·착지한다. 배포에는 서명 릴리스 검증이 필요하다.
5. API 실물 연속 주행은 별도 검증이다. 녹화를 먼저 시작하고 두 로봇의 API 상태·속도·DB 사건 시각을 영상과 대조한다. 소스 시험은 현장 수용을 대신하지 않는다.
