## 관찰과 방향

기존 화면은 객체 사진이 지나치게 커서 클래스/승인 작업이 첫 화면 아래로 밀린다. 학습 목록은 큰 등록 폼과 기술 보고서가 앞에 있어 연결한 작업을 찾기 어렵고 검색/주의 작업 모아보기가 없다. 두 화면의 상태와 다음 행동이 같은 언어·배치로 보이지 않는다.

기존 동작을 유지하는 작은 CSS 수정, 학습 앱 전용 새 화면, 공용 작업 목록 부품+학습 앱 적용을 비교했다. 재사용 가능한 공용 목록/상태/도구막대 부품을 추가하고 학습 앱에서 먼저 검증하는 방식을 택한다. 기존 로봇/Fleet 표면에 새 배치를 강제하지 않는다.

## 디자인 원칙과 작업

1. 상태 → 해야 할 일 → 행동 순서. 승인/거절/미확인을 색만으로 구분하지 않는다.
2. 실제 작업이 첫 화면에 보인다. 새 작업 연결은 필요할 때 여는 보조 패널로 옮긴다.
3. 읽는 정보와 상세 증거를 분리한다. 운영자 한국어 상태·핵심 이유가 먼저, SHA/기술 JSON은 상세에 둔다.
4. 공용 컴포넌트는 재사용하고, 선택한 사진/검색/필터는 새로고침 뒤에도 이어진다.
5. 마우스·키보드·터치에서 같은 작업을 마친다. 모바일 가로 넘침·버튼 사유·취소·오류 복구를 확인한다.

학습: 작업 목록 행, 검색, 종류/확인 필요 필터, 발견 가능한 빈 상태와 필터 초기화, 등록 패널 자동 포커스와 성공 후 닫기, 실패 이유·다음 작업·연결 해제의 명확한 배치.
검수: 사진 thumbnail/검수 상태 목록, 이전/다음/다음 대기 이동, 사진+박스 편집기 두 영역, 승인 행동 접근성, source frame 깊은 링크와 필터 유지. 숫자/마우스/touch 기하·Esc 취소·autosave/version conflict는 유지한다.
공용: 토큰 기반 도구막대/작업행/읽힘 범위와 안전한 텍스트 DOM 생성 helper. DESIGN.md의 낡은 경로를 정정하고 위 원칙·사용 조건을 기록한다.
