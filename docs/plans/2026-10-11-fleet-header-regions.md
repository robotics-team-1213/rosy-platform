# Fleet 헤더 영역 계획

```text
넓은 화면
┌ 제품·현장 ─────┬ 연결·권한 ─────────┬ 알림·설정 ┬ 비상정지 ┐
└───────────────┴───────────────────┴───────────┴──────────┘
  접속·테마 상세: 설정을 열었거나 접속이 필요한 경우에만 표시
  문서 탐색 │ 지도·작업 본문 │ 상태·영상·알림 문맥 패널
  푸터: 시각·진단

좁은 화면
┌ 제품·현장 ────────────────────────┬ 비상정지 ┐
├ 연결·권한 ────────────────────────┼ 알림·설정┤
└──────────────────────────────────┴──────────┘
```

1. 관제·설치·지도·Cell의 같은 정적 헤더에 네 그룹을 적용한다.
2. 공용 CSS가 그룹 배치를 소유하고 알림 컨트롤러는 조작 그룹에만 버튼을 넣는다.
3. 기존 계약 시험의 배치 기준을 갱신하고 원격 브라우저에서 여섯 폭과 접속 흐름을 검증한다.
4. 공식 착지·푸시·CI·서명 설치를 수행하고 설치본을 직접 확인한다.
