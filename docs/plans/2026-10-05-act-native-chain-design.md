# ACT result to the same isolated native execution

The guarded input port and synthetic native parent chain are separate evidence.
This test-only composition computes once after the original parent attempt is
bound, outside the session and stop serializers. The Driver passes that same
candidate into existing final admission. It does not recapture a source, rewrite
queued provenance, issue an operating grant or create a production scheduler.

Alternatives were a default runtime model loader or independent offline replay
joined to an earlier native receipt. The former changes installation and writer
authority; the latter cannot prove one execution. The explicit isolated caller
retains the common DTO and pure learning computation boundaries.

Cold model construction precedes original active lease/grant issuance. Synthetic
RGB gets one original camera receipt timestamp before binding the runtime. It
can legitimately become stale during parent setup or inference. The unchanged
2-second source/action, 12-second lease, 15-second grant and 10-ms poll remain
decisive; failure cannot trigger clock reset, refreshed capture or implicit retry.

closure, UNKNOWN then terminal API receipt, sealed Episode and offline Fleet,
and internal SQLite receiver duplicate/restart. HOST callbacks and a fixed
fixture clock do not prove native transport or performance. Explicit domain199

numerical output and original result/candidate in a separate inference sidecar.
