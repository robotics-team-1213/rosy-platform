# Human-AI Review UX Implementation Plan

**Goal:** AI 초안·검사 상태와 사람 검수 주체를 실제 저장된 정보대로 표시하고, 초안 조회의 잘못된 집계를 수정한다.
**Architecture:** 기존 SQLite, 검수 revision, 초안 후보와 VLM 피드백 API를 재사용한다. 기존 편집·승인 조건은 유지한다. 생성 작업의 신규 실행 계약과 영역별 AI 지적은 별도 후속 단계다.
**Tech Stack:** Python stdlib/SQLite, ES modules, shared ui components, Chromium, remote pytest.

## 근거

357장 복사 자료에서 10개 화면을 확인했다. 작업대의 후보 76장은 실제 새 후보가 아닌 현재 마스크를 포함했다. 작업대 링크로 사진 5에 진입했을 때 후보 0개, AI 의견 없음, 과거 승인자 미기록이었다. 운영 배포와 실제 AI 실행의 검증은 아니다.

## 실행 순서

1. `test/learning/perception/test_review_app.py`: 사람이 채운 마스크를 새 AI 후보로 세지 않는 HTTP 회귀 시험과 actor 없는 후속 이벤트의 오귀속 방지 시험을 추가한다. 커밋 후 canonical remote pytest로 실패를 확인한다.
2. `review_app.py`, `review_masks.py`: 선택 가능한 후보만 candidates/첫 후보에 포함한다. 익명 이벤트가 직전 사용자의 이름을 상속하지 않게 한다.
3. `review_app_web/{history.js,index.html,pixels.html,app.js,pixels.js,learning.js,app.css}`: 상단 검수 주체·최근 이력 링크, 시간순 이력, AI 상태·모델·문제 종류·최신성·다시 조회, 명확한 빈 후보 상태와 초안 비교 동선을 연결한다. 미기록 주체는 추정하지 않는다.
4. 원격 서버/픽셀/계정 관련 회귀 시험과 JS 동작 시험을 수행한다. 복사 자료 Chromium 10화면과 작업대→검수→이력/AI 상태 동선을 재확인한다. 원격 시험 로그를 known_failures와 비교한다.
5. 결과를 이 문서에 기록하고 명시 경로만 커밋한다. 사용자 기존 승인 범위에서 `python tools/land.py --tests auto`로 로컬 main에 착지한다. push/운영 배포는 이번 작업에 포함하지 않는다.

## 수용 기준

- 현재 마스크만 있고 새 후보가 없으면 선택 가능한 초안 0장이고 초안 링크로 잘못 안내하지 않는다.
- 객체/픽셀의 최근 행위자와 현재 승인 상태를 구분한다. 익명 이벤트와 과거 미기록 이벤트는 검수자 미상으로 표시한다.
- AI 미실행·오류·판단 보류·응답 없음·오래된 결과가 정상 판정으로 표시되지 않는다. 제공된 모델과 issue를 조회할 수 있다.
- 새 사진을 여는 동안 이전 사진의 검수자/AI 상태가 남지 않는다. 초안 미리보기는 현재 저장 결과를 변경하지 않는다.
- 데스크톱/모바일에서 검수 주체와 AI 상태를 발견할 수 있고, 키보드로 이력·AI 다시 조회 동작에 접근할 수 있다.

## 후속 구현

AI 초안 생성/재검사 실행기 연결, 영역별 문제와 사람 처리 사유, 전체 이력 페이지 조회·승인본 비교, 담당자 배정은 별도 계약·저장 구조가 필요하다. 이번의 ‘다시 조회’를 모델 재실행으로 표현하지 않는다. 학습 완료 정확도 시험은 사람 승인 정답과 고정 평가 자료 확보 후 진행한다.

## 실행 결과

- 1~3 구현: 후보 집계 수정, 상단 최근 작업자/현재 승인자 및 이력 링크, 시간순 이력, AI 상태·모델·문제 근거·저장된 의견 다시 조회, 새 후보 없음 안내.
- 익명 객체 이벤트가 직전 last_actor를 상속하지 않게 수정했다. 독립 코드 리뷰에서 발견한 빈 필터/조회 오류의 이전 사진 정보 잔류도 수정하고 브라우저 회귀 시나리오를 추가했다.
- 검증: 원격 관련 pytest 72 passed, known_failures NEW 0; node 상태 분기 2 passed; 357장 복사 자료 Chromium 10화면 통과. 보류/오래됨 UI는 합성 응답 시험이며 실 모델 실행 증거가 아니다.
- AI 작업 신규 실행, 전체 이력/승인본 비교 및 운영 배포는 후속 범위로 남는다. 이 변경이 실 학습 완료나 운영 수용을 뜻하지 않는다.
