# 현장 지도 표시 안정화

사용자 요청: 신호등 설명이 바닥 영상과 차선을 가리고, 좌표 표시가 나타나거나 사라질 때 지도의 크기가 변한다.

지도에는 차선·위치·정지선과 작은 가상 신호 표시만 둔다. 신호 이름·입구·상태 및 점유·대기 설명은 지도 아래 교통 상태 목록으로 옮긴다. 기존 교통 상태와 색상 토큰을 사용하고, 운행·신호 제어 권한은 바꾸지 않는다. 지도 위의 큰 설명 상자와 영상 위에 겹치는 상세 패널은 사용하지 않는다.

지도 프레임은 화면 크기로 정하고 영상 해상도·관측 행 수로 정하지 않는다. 좌표와 교통 상태는 높이가 고정된 별도 영역에서 스크롤한다. 관측이 만료되면 좌표값은 지우고 대기 행을 표시한다. 데스크톱에서는 두 열, 모바일에서는 한 열로 배치한다.

높이가 충분한 데스크톱에서는 고정된 상세 영역과 실제 조작부를 제외한 남은 높이를 지도가 채운다. 작은 화면에서는 화면 크기로 지도 높이를 정한다. 관측 유무는 높이에 영향을 주지 않고, 큰 화면에서도 지도 열이 넘치지 않는다.

검증: 신호 표시가 Canvas에 문장을 그리지 않는 Node 시험, 실제 Chromium에서 관측→익명→만료 및 지연 응답 전환 중 지도 프레임 크기 유지, 모바일 가로 넘침 확인. 서명 배포 후 실제 map_v2_fleet 지도와 카메라 원본·평면 보기에서 재확인한다. 로봇 연결 및 교정 실측 정확도는 별도 증거다.

추가 요청: 아이콘과 맥락 중심으로 평면을 보존한다. 장소는 작은 점과 짧은 번호로 표시하고 이름·좌표는 같은 번호의 장소 목록으로 옮긴다. D-651의 작업 중심 재구성에 따라 지도 옆 내부 상세 열을 없애고 지도 아래 접힌 장소·교통·관측 좌표로 합친다. 펼친 내용은 고정 높이 안에서 스크롤하므로 관측 만료가 지도 크기를 바꾸지 않는다. 지도 치수·source는 표시 옵션에서 확인하고 교정 어긋남의 원인·오차·조치는 접힘 밖에 유지한다.
