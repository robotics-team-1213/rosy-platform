# Conversation semantic evidence admission

D-728 requires an independent conversation admission, rather than D-720 status
admission. The present broker accepts an arbitrary manifest file hash as semantic
evidence; that is insufficient to establish that any evaluation passed.

Keep the protected broker, root-owned source manifest, fixed model digest and
proposal-only authority. Validate the actual protected evaluation payload against
a frozen, source-owned corpus: exact original questions and context, complete
unique cases, strict answers, expected kinds and exact positive command targets.
Reject missing, failed, duplicated or changed cases and changed profile/policy.
No model self-rating, receipt delivery or device outcome enters this admission.

The Model PC independently evaluates retained AI PC inference outputs. A protected
administrator-reviewed installation must bind that evaluation to the installed
source/profile/policy; a passing unit fixture is not model or runtime acceptance.
Keep runtime activation off until actual evaluation and protected installation
have been verified. GLM reviewer, cost admission and physical acceptance remain
separate gates.

Execution: commit negative broker tests; run them remotely and compare known
failures; implement the bounded payload validator and frozen cases; test valid
proof plus tampering remotely; improve the fixed inference instructions; run the
actual fixed-model cases and independent evaluation; review source before merge.
Affected owners: AI PC broker/inference, deployment evidence, Fleet broker tests.
No new command endpoint, model provider, dependency or credential handling.
