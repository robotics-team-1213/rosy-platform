# 녹화 작업과 Fleet 사건 검토 연결

기존 별도 결합 CLI를 녹화 작업의 체크포인트로 호출한다. Fleet에 다시 접속하는 수집기나
trainer 라벨 확장은 인증·평가 계약까지 넓어지므로 이 연결에서는 필요하지 않다.

- 입력: 선택 설정 `incidents`의 비공개 Fleet export와 raw 녹화의 기존 stuck 마커.
- 처리: catalog 다음에 기존 `incident_feedback.bind()`로 세션별 연결. 없는 마커는 명시.
- 출력: 이름·메모를 제거한 `incident-feedback.json`, 준비 완료 결과의 경로, 해시 영수증.
- 오류: 잘못된 사건·마커와 변경된 입력 또는 산출물은 라벨링·작업 재개 전에 거부.
- 경계: 학습 화소·평가 정답·모델 승인에는 영향을 주지 않는다. 영상 해석은 별도 관문.
- 확인: raw/video 혼합 작업, 사람 정보 제거, trainer 격리, 마커 변경 후 재개 거부,
  마커가 없어도 잘못된 export 거부. 시험 PC에서 기존 녹화·피드백 테스트와 함께 실행.

호스트 fixture 통과는 실제 녹화 수집이나 사람 검토, 재학습 효과의 증거가 아니다.
