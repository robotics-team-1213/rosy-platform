# ROSY 플랫폼 브랜드 구현

로봇 얼굴은 하드웨어 역할과 혼동되고 장미 꽃은 작은 관제 아이콘에서 복잡하다. 경로 R 심볼은 플랫폼 이름과 이동·판단의 연결을 함께 표현하고 단색에서도 식별할 수 있어 선택했다.

1. 생성 견본과 정확한 프롬프트를 보존하고, 평면 SVG 정본과 플랫폼 타일을 만든다.
2. 기존 토큰과 `ui-brand`를 사용해 Fleet 네 문서, Robot, Pilot, 공용 template의 헤더에 같은 심볼을 표시한다. 역할별 앱 아이콘은 유지한다.
3. 공용 allowlist·설치 목록·styleguide에 연결한다. 작은 심볼, 두 테마, 접근성 이름, 좁은 헤더와 비상 정지 접근을 원격 브라우저로 검증한다.
4. 관련 회귀와 `known_failures`를 비교하고 공식 착지·푸시·CI·서명 설치를 진행한다. 설치본 증거와 native/실물 수용의 한계를 기록한다.
