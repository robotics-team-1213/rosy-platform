# 정차한 기체의 위치 확정이 곧 풀리면 상대 기체의 관측 근거를 확인한다

42번을 옮긴 뒤 이전 위치 후보의 점수는 0.951로 남았다. 현재 라이다 스캔을 그 후보에 다시 대입하자 벽을 관통하는 빔 때문에 점수가 0이 됐다. 새 스캔 세 개를 각각 전역 검색한 결과는 같은 격자점으로 모였고, 정차 상태에서 위치 추정기만 다시 시작하자 새 후보도 그 점에서 1 cm 이내였다.

새 후보를 승인한 뒤에도 기존 Fleet은 2.5초 만에 `fleet_monitor`로 42번의 위치 확정을 취소했다. 당시 천장 카메라 비교 기능은 꺼져 있었다. 현장 데이터를 재생하자 미확정 상태인 45·46번이 보낸 단일 라이다 반사점이 각각 42번의 180도 대칭 후보에서 0.167 m와 0.248 m 떨어진 곳에 투영됐다. 실제 후보 근처에는 해당 반사점이 없었다. 당시 이벤트에 관측자 ID가 없어 개별 취소를 특정 기체에 귀속할 수는 없다.

Fleet #833은 상대 기체의 후보를 뒷받침하는 독립 관측을 확인한 뒤 다른 기체의 위치 판정에 사용한다. 서명 릴리스 배포 후 최신 스캔과 일치하는 후보를 다시 확정했을 때 42번은 96초 뒤에도 `LOCALIZED`였고 45번도 사람 확인 요청이 해제됐다. 같은 시점에 46번은 세 스캔 모두 최상위 후보에서 72~77개 빔이 벽을 관통했고 미확정으로 남았다.

재발 시 현재 스캔을 보관된 후보에 다시 대입하고, 새 전역 검색 결과와 대조한다. 확정 직후와 다음 모니터 주기들의 상태 전이를 함께 기록한다. 다른 기체가 보낸 관측으로 취소됐다면 발신 기체가 어떤 근거로 자기 위치를 정했는지 확인한다. 이 절차가 확인하는 범위는 로봇 격자 안의 위치다. 현장 목적지 주행은 활성 현장 지도와 로봇 격자의 승인된 정합을 별도로 검사한다.
