# D-654 ROSY 플랫폼은 경로 R 심볼을 공용 브랜드 자산으로 사용한다

**Status:** Accepted (2026-10-11)

### Context

사용자는 반복 조작의 중복 라벨을 제거한 뒤 ROSY 자체의 현대적인 플랫폼 아이콘과 브랜드 표현을 요청했다. 기존 D-277의 장미색, D-370의 서로 다른 앱 역할 아이콘, D-377/D-487의 제품 이름과 D-641의 정보 위계는 계속 유효하다. 생성 이미지의 견본은 방향을 설명하며 실제 UI나 설치 증거가 아니다.

### Decision

1. 플랫폼 심볼은 한 경로가 돌아 나와 전진하는 **R** 형태다. 관측·판단·실행의 연결을 표현한다. 장미 꽃, 로봇 얼굴, 기어 등의 도상보다 작은 크기의 식별과 제품 확장에 적합한 기하를 선택한다. 워드마크와 심볼은 제품 정체성이고 조작 버튼의 아이콘과 분리한다.
2. 정본은 `shared/web/brand/mark.svg`이다. 플랫폼 앱 타일은 같은 기하를 참조하는 `platform.svg`이다. UI는 공용 `ui-brand`의 워드마크 앞에 이 정본을 CSS mask로 표시한다. 서버별 모양·색 복사와 화면별 SVG 변형을 만들지 않는다. 색과 글자 크기는 기존 토큰을 따른다.
3. UI의 심볼은 워드마크의 일부로 `--brand-rose`를 사용한다. 어두운 테마와 밝은 테마의 기존 값, 단색 silhouette, 16/24/48px 식별을 검증한다. 그라데이션·광택·입체 효과를 실제 자산에 넣지 않는다. 장미색은 상태·위험·AI 승인 여부를 뜻하지 않는다.
4. Fleet, Robot, Pilot, Cam의 역할 아이콘과 런처 아이콘은 D-370의 고유 silhouette를 유지한다. 공통 플랫폼 브랜드가 역할 차이를 지우지 않는다. 기존 이름, favicon, 앱 패키지 식별자와 권한을 유지하며 플랫폼 타일은 플랫폼 자체를 나타내는 자산으로 제공한다.
5. 브랜드 링크의 접근성 이름과 목적지는 기존 계약을 유지한다. 심볼은 장식이고 새로운 focus 대상이 아니다. 좁은 헤더에서 제품 이름·접속·알림·비상 정지가 겹치지 않는지 실제 브라우저로 검사한다. 색만으로 앱·선택·실패를 구분하지 않는다.
6. 생성 프롬프트와 견본, 원격 회귀, 실제 화면, CI, 서명 설치, native 앱 수용은 구분한다. 공용 자산은 allowlist와 CMake 설치 목록에 등록하며 기존 서버의 경로 방어를 유지한다.

### Consequences

독립 SVG 이미지에서는 외부 SVG 참조가 제한될 수 있어 플랫폼 타일은 정본 기하를 포함하는 파생 자산이다. 시험이 두 path의 동일성과 기존 토큰 색을 확인한다. 화면은 정본 mask만 참조한다.

Fleet·Robot·Pilot 웹 표면과 공용 template은 한 `ui-brand` 규칙으로 같은 플랫폼 심볼을 사용한다. 이 변경은 명령 API나 CORE의 최종 제어 권한을 바꾸지 않는다. native 앱의 실제 설치나 실물 주행을 웹 브랜드 검증으로 주장하지 않는다.
