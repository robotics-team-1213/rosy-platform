## D-632 Fleet 알림 창구와 읽음의 의미

**날짜:** 2026-10-11
**상태:** 구현

### 결정

사용자는 개입·알림·메시지를 플랫폼의 알림 창에서 확인하도록 요청했다. D-629의 지도와 오른쪽 상태 구조를 유지하며 기존 현재 개입 큐와 관제 이벤트 로그를 하나의 알림 진입점으로 연결한다.

1. Fleet 관제·설치·보정·현장 지도·Cell의 공통 머리에 일반 48px 알림 버튼을 둔다. 다른 문서에서는 관제의 알림 탭으로 이동한다. 알림은 조회이므로 로봇 조작 권한과 분리한다.
2. 오른쪽 알림 탭은 현재 필요한 개입 요약과 최근 관제 메시지를 보여준다. 메시지는 기존 요청 결과와 연결 상태 로그를 재사용하고, 사건 당시의 상세 증거·사람 검토·내보내기는 기록·근거 탭에 남긴다.
3. 읽지 않은 새 메시지와 새 개입을 표시한다. 같은 개입의 반복 폴링은 새 알림이 아니다. 알림을 열어 읽음으로 바꾸는 것은 브라우저 표시 상태이며, 개입 해소·확인 승인·CORE 정지 해제·로봇 명령을 뜻하지 않는다.
4. 현재 개입 큐와 비상 정지는 알림 탭 밖에 유지한다. 알림 요약에서 해당 큐로 이동하며 실행 버튼과 명령 경로를 복제하지 않는다. 팝업을 강제로 띄워 지도 조작이나 비상 정지를 가리지 않는다.
5. 새 서버 알림 API·대화 상대·전송·영속 보관을 만들지 않는다. 이번 창구는 Fleet 운영 알림이며, 실제 제공하지 않는 사람 간 채팅이나 서버 간 받은편지함으로 표시하지 않는다.

### 검증

원격 Chromium에서 네 문서의 진입점, 키보드 이동, 읽음 후 동일 상태 재폴링 시 카운트 유지, 새 메시지 증가, 큐 복귀와 무명령 조회를 확인한다. 두 테마의 데스크톱·320px 모바일에서 알림과 비상 정지 모두 48px·가로 넘침을 확인한다. 배포와 실물 동작은 별도 증거다.
