## D-268 Fleet 자동 작업은 sighting이 아닌 별도 수용된 정책 증거만 사용한다

**Status:** Proposed (2026-09-26). 자동 이동 승인이나 현장 수용을 뜻하지 않는다.

연결 결정: D-18, D-33, D-55, D-59, D-81, D-118, D-136, D-170, D-177, D-257, D-267.

**Context:** D-257 sighting은 관제 화면의 표시·대조용이며 로봇 위치 추정, 정책 또는 최종 `cmd_vel` 입력이 아니다. Proposed D-267에는 검증된 영상 결과로 미리 등록한 작업을 시작하는 자동 경로가 포함돼 있다. D-268은 D-267의 그 자동 입력 경계를 좁힌다. 두 경계를 같은 데이터 종류로 취급하면 D-257을 위반하거나 자동 경로를 검증할 수 없다.

**Decision (제안):**

1. `sighting`은 D-257대로 표시·대조에만 쓴다. 자동 작업은 sighting endpoint를 직접 구독하거나 sighting을 정책 입력으로 사용하지 않는다.
2. 자동 작업에는 별도 타입의 정책 적격 증거 계약을 둔다. 그 계약은 출처·대상 자산, 캡처/수신 시각, map·보정·모델 revision, 결과 유효기간과 작업 종류를 검증할 수 있어야 한다. 구체적인 필드와 경로는 API Reference와 공유 schema를 함께 설계·변경하기 전에는 확정하지 않는다(D-18).
3. 정책 적격 증거는 등록된 출처와 허용 대상/증거 종류에 서버 측으로 묶인 폐기 가능한 자격 증명으로 제출한다. 서버가 출처 identity를 자격 증명에서 결정하며 클라이언트가 제출한 `source_id`를 신뢰하지 않는다. 재생, 다른 출처/자산 위조, 만료·폐기 자격 증명은 거부하고 행위 주체와 증거 revision을 감사 기록에 남긴다.
4. 각 개별 자동 판정 입력은 캡처에서 Fleet 수신까지 300 ms 이하여야 한다(D-257). 시계 오차가 판정을 보증하지 못하거나 필요한 좌표·지도·보정·출처·모델 revision이 일치하지 않으면 증거를 정책 입력에서 제외한다. stale·누락·불일치·처리 지연·worker 중단은 자동 실행 대신 명시적 거절/보류 상태가 된다.
5. 개별 신선도 통과만으로 자동화를 승인하지 않는다. 현장 시험 전에 작업 종류별 정답 데이터, 허용 검출 오류/오탐 기준, 필요한 표본 규모와 신선 증거 가용성 기준을 사전 등록한다. 입회한 DEVICE/FIELD 결과가 그 기준을 통과하고 자동·수동 중지와 재조회 경로가 검증된 경우에만 해당 작업 조건을 활성화한다. 수치 기준은 acceptance plan에서 정하며 이 제안에서 임의로 만들지 않는다.
6. 운영자 요청은 `operator` 권한으로 별도 출처를 기록하고, 자동 요청과 같은 작업·로봇 상태 검증기와 감사/추적 경로를 통과한다. 자동 조건의 등록·수정·활성화는 별도의 `policy-admin` 권한으로 제한한다. 뷰어는 상태와 거절 사유를 읽을 수 있지만 명령이나 정책을 바꾸지 못한다.
7. Fleet은 CORE 명령 수락과 작업 완료를 구분한다. 명령 또는 영상 작업 결과가 불명확하면 `UNKNOWN`/HOLD에서 재조회한다. 자동 재전송이나 집기 재시도는 허용하지 않으며, 로봇 로컬 action이 명시적으로 안전한 재시도 가능 상태를 반환한 경우에만 재시도한다. 물체 소유, arm, gripper 상태가 불명확하면 D-55에 따라 운영자 복구 전까지 HOLD한다.
8. 정책 증거 경로는 robot DDS나 `/cmd_vel`을 열지 않는다. 이동은 CORE의 기존 외부 계약으로 요청한다. 조작은 D-55의 장치 수용을 마친 로봇 로컬 manipulation action만 호출한다.

**Alternatives:**

- *D-257 sighting을 자동 정책에 직접 사용* — D-257의 표시·대조 전용 경계와 충돌한다.
- *검출 점수만으로 작업 실행* — 좌표·보정·출처·시각 신선도와 실기 오탐 성능을 보증하지 않는다.
- *현장 수용 전에 수치 기준을 임의로 정함* — 작업 위험과 데이터 분포가 확정되지 않은 상태에서 근거 없는 합격선을 만들게 된다.

**Validation / Transition:** Proposed 동안 정책 적격 증거의 외부 endpoint와 자동 실행 설정을 열지 않는다. D-267이 먼저 Accepted가 되더라도 이 ADR의 승인은 자동 입력을 여는 별도 선행조건이다. API Reference/schema, 정책·권한 검증, 정답 데이터 기반 LOCAL 시험, 30분 이상 현장 스트림의 end-to-end age/가용성 측정, 사전 승인한 검출·오탐 기준의 입회 DEVICE/FIELD 수용이 끝난 뒤 이 ADR을 Accepted로 전환한다. 하나라도 미통과·불명확이면 automatic source는 비활성으로 유지한다. 집기 활성화는 별도의 D-55 장치 수용 결과를 추가로 요구한다.
