## D-909 Fleet 절차 문서의 경량 헤더와 배치 역할

**Status:** Accepted (2026-10-28)

## Context

사용자는 D-906 뒤 남은 화면도 같은 방식으로 수정하고 레이아웃을 재점검하도록 요청했다. 계정 관리·내 계정·로그인·정책·학습 진입의 브랜드/테마 헤더는 설명만 다른 사본이며 문서 배치도 별도다. 긴 유효 호스트명과 계정 식별자를 넣은 실제 Chromium 회귀에서 가로 넘침을 재현했다. 학습 단계는 번호·제목·익명 설명이2열 격자의3개 항목으로 나뉘었다.

## Decision

1. D-906의 정적 컴파일러를 재사용한다. `fleet-document-header.html.inc`는 고정5문서의 경량 헤더 정본이며 문서 이름은 고정 매핑으로 치환한다. 기존4문서의 관제 헤더·탐색과 구분한다. Learning 서버가 치환하는 `{{focus}}`·호스트 슬롯은 건드리지 않는다. 첫 HTTP 응답부터 완성된 정적 마크업을 제공한다.
2. Fleet 소유 `fleet-document.css`가 이5문서의16px inset·grid·묶음 간격·최소 폭·긴 값 줄바꿈·container를 소유한다. 각 문서는 인증·검토·호스트 선택의 목적에 맞는 최대 폭을 유지한다. 기존 `ui-shell`, `ui-readout`, `.ui-page-heading`, `ui-actions`를 소비한다. 계정의 긴 버튼은 문서 폭 안에서 줄바꿈하고 전체 식별자는 숨기지 않는다.
3. 아래 사용 중인 역할의 값은 `shared/web/tokens.css` 한 곳에 둔다. 갤러리는 계산된 값을 읽는다. 의미가 다른 기존 치수는 값이 같아도 합치지 않는다.

| 역할 | 값 | 소비 |
|---|---|---|
| `--content-auth-max` | 32rem | 로그인·계정 관리·내 계정의 문서 폭 |
| `--content-learning-max` | 48rem | 학습 호스트 선택의 문서 폭 |
| ~~`--content-policy-max`~~ | — | D-926 2로 정책 화면이 작업 셸로 옮겨 삭제(2026-10-30) |
| `--content-policy-form-max` | 36rem | 정책 제안 입력의 폭 |
| `--block-policy-evidence-max` | 12rem | 스크롤 가능한 정책 근거 높이 |
| `--measure-login-identity` | 10rem | 로그인 부품의 신원 요약 폭 |

4. Learning 호스트 값은 `dl.ui-readout`의 의미·긴 값 줄바꿈·칸 기반 한 열 전환을 쓴다. 각 단계 제목과 설명은 같은 항목으로 묶는다. 카드 최소 폭과 제목/상태 줄바꿈을 허용한다.

| 기존 결정 | 관계 |
|---|---|
| D-427 | 기존 applications/fleet와 shared/web 소유를 유지한다. 새 런타임/최상위 폴더 없음 |
| D-429 | 공통 치수·부품과 화면 배치 경계를 유지한다. 실행 owner를 바꾸지 않음 |
| D-430 | 명령·권한·안전 판단을 변경하지 않는다. Robot/Pilot 운전석의 데이터/조작 기하를 이 문서 배치로 바꾸지 않음 |
| D-624·D-639·D-741·D-906 | 역할 토큰·공용 부품·첫 응답 정적 chrome·화면별 필요한 컨트롤 경계를 유지 |

## Consequences

정본 편집 뒤 `python applications/fleet/web/shared/fleet_components.py`로 산출물을 갱신하며 `--check`가9문서의 드리프트를 거절한다. 새 시트는 기존 자산 등록에 추가하며 CSP·URL·인증 API를 유지한다. 인증 문서/정책의 기존12px inset은16px로 맞추고 Learning의 별도 바깥 여백·간격을 공통 절차 리듬에 맞춘다.

이 결정은 설계 수용이다.320/390/480/768/1440 및 밝게/어둡게, 긴 값·권한·로그인·계정 변경·정책 승인과 패키지 산출물은 별도로 검증한다. 전체 제품·실물·현장 UI 수용을 의미하지 않는다.

> 2026-10-30 D-926 2: 학습 정책 승인(`work/policy.html`)은 실물 실행 창을 여는 화면이라 가벼운 문서 머리 대신 작업 화면과 같은 셸(비상 정지·계정·레일·작업 하위 탐색)을 쓴다. 가벼운 문서는 로그인·내 계정·계정 관리·학습 넷이다.
