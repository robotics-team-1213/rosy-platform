# D-940 중복 정의 게이트와 의도 중복 등록부를 둔다

**Status:** Accepted (2026-11-01). 사용자의 "바로 처리" 지시로 등록·구현한다. 원격 시험·착지·CI 결과는 이 문서가 아니라 착지 기록과 `docs/logs.md`가 증거를 가진다.

### Context

2026-10-31 중복 조사와 [2026-10-20 감사](../assessments/2026-10-20-duplication-and-placement-audit.md)에서 같은 로직이 다른 파트에 조용히 새로 쓰이는 사례를 확인했다. learning `content_sha` stand-in은 정본(`learning/registry/perception/store.py`)이 main에 착지한 뒤에도 살아 있었고, OMX demonstration 검증 헬퍼는 contracts 정본과 한쪽만 진화해 드리프트가 이미 생겼다. 기존 구조 시험은 소유(`platform_parts.yaml`)·위치·import 방향을 검사하지만 "같은 정의가 두 파트에 동일하게 존재" 자체는 보지 못한다. 감사의 SHA256 묶음은 사람이 손으로 만들어 재실행 예산이 없었다.

### Decision

1. `test/architecture/test_duplicate_definitions.py`가 tracked `.py`의 최상위 함수·클래스를 AST dump(줄번호 제외)로 정규화해, 서로 다른 두 파트 이상에 동일하게 존재하는 정의를 그룹으로 모은다. AST dump 160자 미만의 소형 정의와 `test/` 디렉터리의 패키지 지역 시험 미러는 범위 밖이다(아래 구멍).
2. 그룹은 `test/architecture/known_duplicates.txt`에 `<경로>+<경로>|<이름>  <갈래> <사유>` 한 행으로 등록하고 양방향 집합 동치(P5)로 검사한다. 미등록 신규 그룹과 사라진 행 둘 다 빨간불이다. 행은 줄어들기만 한다.
3. 갈래는 네 가지다. ① 정본 소비 전환 후보(이미 contracts에 정본이 있다) ② 소유 범위 내 통합 후보 ③ 보호된 의도 중복(배포 경계·문서화된 미러, 드리프트 시험을 함께 둔다) ④ 이름 분리·관습 고정(같은 이름의 다른 불변식, 합치지 않는다). 전역 utils 패키지 신설과 관습이 다른 정의의 강제 통합은 하지 않는다(D-841 기각안 유지).
4. 등록된 사본의 한쪽만 고치면 해당 행이 stale로 빨간불이 되어, 갱신이 의도적 판단임을 강제한다. 이는 "설치 복사본은 쓰는 순간 자기 비교를 둔다" 교훈(2026-10-26 solutions)의 구조 시험 버전이다.
5. 이 게이트의 추가는 mutation 증명(지켜야 할 것을 망가뜨려 빨간불 확인·복구 초록불 확인)을 거쳐 착지한다. ③·④ 행의 드리프트·경계 시험과 ①·② 전환은 케이스별 후속 착지다.

### 기존 결정과의 관계

| 결정 | 관계 |
|---|---|
| D-427 | 파트 경계를 그대로 두고, 파트 **간** 동일 정의만 본다. 같은 파트 안의 배치는 기존 규칙 그대로 |
| D-429 | API root·owner 규칙은 그대로다. 이 게이트는 import 방향이 아니라 정의 복제를 본다 |
| D-430 | safety 태그 경로 이동이 아니므로 Safety-Review 대상 아니다 |
| D-841 | 공용 모듈 재사용 원칙을 등록부 갈래로 계승한다. 전역 utils·전면 통합 기각안을 다시 뒤집지 않는다 |
| D-738 | "같은 입력·같은 출력은 한 기능 폴더" 규칙의 함수 단위 보완. 권한이 다른 폴더를 합치는 규칙은 그대로다 |
| D-766 | size 래칫과 같은 운영 문화(동결 목록은 내려가기만, 스크립트로 재생성)를 따른다 |

### Alternatives

- 모든 중복을 전역 패키지로 통합: D-841이 독립 배포 결합 이유로 기각한 안을 반복한다.
- 동명 정의 탐지까지 확장: `main`·`wrap` 같은 이름이 시험·CLI까지 홍수를 이뤄 게이트 신뢰가 사라진다. 이름 충돌은 어휘표와 리뷰가 담당한다.
- 감사 재실행만: 신규 복제를 합류 시점에 못 막는다. 주간 `structure_report` 확장은 별도 후속으로 유지한다.

### Consequences and verification

초기 등록부는 2026-11-01 첫 스캔의 47 그룹이다(peerCrypto 7행, `_in_checkout` 11파일 1행, deploy 미러·wrap 관습 군집 등). 새 그룹은 갈래 판정과 사유 없이는 머지되지 못한다. 게이트는 CI 루트 `test/` 샤드에 코드 추가 없이 편입되고, pre-push FAST_SUITES 추가는 실제 실패 사례가 쌓인 뒤에만 논의한다(`tools/hooks/AGENTS.md` 규정). 구멍은 시험 docstring에 적었다: 한 토큰이라도 이미 갈라진 포크·소형 헬퍼·동명이음·메서드는 못 본다.

원격 시험과 mutation 증명, 착지는 이 ADR의 수용 조건이 아니라 착지 파이프라인의 몫이다(`tools/land.py`, D-584).
