# D-961 공용 작업 이동과 작업·인증 화면 구성

**Status:** Accepted (2026-11-02, 사용자 승인 통합 설계). D-359·D-741·D-926의 값·상태·안전 계약을 유지한다.

## 문제

실제 Learning 로그인은 주 동작이 21px 일반 링크이고 보조 동작은 48px 단추였다. 앱마다 이동 링크 외형과 본문 폭·여백을 다시 선언하면 같은 문제가 재발한다. 기존 공용 조합 부품을 제품 화면에서 일관되게 사용해야 한다.

## 결정

1. `component-controls.css`에 네이티브 `a.ui-action-link`를 둔다. `data-kind="primary"` 또는 `quiet`를 명시하며 기존 버튼 의미 토큰과 48px 바닥·포커스를 사용한다. 실제 이동은 `href`가 소유한다. JS 클릭 핸들러로 링크를 버튼처럼 만들지 않는다.
2. 같은 시트의 `.ui-task-page`는 기존 작업 폭·간격 토큰으로 본문을 배치한다. `.ui-auth-page`는 기존 인증 폭을 적용한다. 캔버스·지도·영상 중심 화면에 인증 구성을 강제하지 않는다.
3. 사용하는 문서는 `components.css` 다음 기존 `/common/component-controls.css`를 로드한다. 기존 허용 목록·설치 경로를 재사용하고 새 팔레트·런타임·프레임워크를 만들지 않는다. 공통 부품의 모양은 앱 CSS에서 다시 칠하지 않는다.
4. 인증 전용 구성과 로그인 후 계정 작업의 탐색을 구분한다. 인증 진입은 main의 h1 하나와 다음 행동으로 시작한다. 이 구성에서는 D-945의 Learning 제목을 경로 줄에 두는 규칙을 대체하며, 로그인 후 탐색·본문 폭은 계정 owner가 복원한다. 일반 작업 문서의 경로 줄 계약은 유지한다. Account와 앱 로그인은 제목·앱바·안내·복귀의 제품 맥락을 맞추되 인증·권한·반환 대상 검증은 각 owner가 유지한다.
5. 원격 Chromium에서 지원 테마·320/1366px·큰 글자·48px 조작·포커스·Enter 이동을 검증한다. gallery와 Robot styleguide에 같은 이동 조작 견본을 제공한다. 소스·브라우저·운영 배포의 수용은 별도다.
6. Fleet 문서 레일은 기존 `doc-tabs` 식별자를 유지하며 공용 `ui-rail`·`ui-rail-nav`·`ui-rail-item`을 사용한다. D-501·D-906의 Fleet 전용 레일 외형은 공용 app-shell 표현으로 대체하고, 영역 순서·선택 의미·하위 탐색·정지 자리는 유지한다. 일반 작업 본문은 `ui-task-page`를 소비하고 지도·운전 관제의 전용 배치는 유지한다.
7. 레일은 모든 폭에서 아이콘 아래 이름을 둔다. 좁은 화면은 레일을 가로로 놓되 이름을 옆에 붙여 불필요하게 넓히지 않는다. 공용 높이 바닥은 48px이며, Fleet은 기존 `--size-rail-item`(56px)을 배치 치수로 소비한다. Robot의 320×568 상단 20% 예산과 Fleet의 56px 조작을 함께 보존하고 320px에서도 다섯 영역을 찾을 수 있게 한다. 외형은 공용, 역할별 자리 치수는 소비자가 소유한다.
8. Monitoring은 공용 워드마크·테마 조작·작업 본문을 사용하고 표시 제목을 `Rosy Monitoring — 시스템 상태`로 맞춘다. 서비스·wheel·인증·관측 API 신원은 유지한다. 독립 번들은 고정 허용 목록으로 공용 조합 시트와 `brand/mark.svg`를 원본 그대로 포함한다. 이 자산 구성을 위해 하위 경로를 보존하며 디렉터리를 자동 공개하지 않는다.
9. 네이티브 header가 없는 앱바는 화면 소유자가 `role="banner"`를 명시한다. 이미 native header를 쓰는 Fleet에는 중복 banner를 만들지 않는다. Games의 경기 제목은 접근성 트리에 남기고 전용 경기 배치는 유지한다. Pilot의 본문 건너뛰기는 실제 main 포커스로 이어진다.

## 기존 결정과 관계

| 결정 | 관계 |
|---|---|
| D-359·D-624·D-629 | 기존 의미 토큰·대비·48px 조작을 소비하며 값을 바꾸지 않는다 |
| D-741·D-926 | 기존 셸의 자리와 읽는 순서를 작업·인증 구성으로 연결한다 |
| D-427 | 소스 part·설치 소유자를 유지한다 |
| D-429 | 공용 시각 부품이 도메인 API·원장·권한 owner가 되지 않는다 |
| D-430 | 정지·hold-to-drive·최종 실행 권한·위험 확인은 유지한다 |

## 검증과 복구

`shared/web/test/test_action_links_browser.py`는 네이티브 역할과 키보드 이동 및 실제 렌더를 검증한다. 앱별 적용은 각 owner의 인증·작업 회귀로 확인한다. 되돌릴 때 해당 앱의 구성 적용을 독립적으로 되돌릴 수 있으며 인증 서비스 설정·데이터는 변경하지 않는다.
