## D-417 관제 콘솔 밀도 정리 — 카메라 컴팩트 모드·대형 요약 구조화·열 균형

**Status:** Accepted (2026-10-02, 사용자 지시 — "이어서해줄래").

이은 결정: [D-280](D-280-calm-intelligence-product-design-philosophy.md) · [D-415](D-415-console-operational-visibility.md) · [D-416](D-416-console-debug-affordances.md).

### Context

운용 문서 계측: 카메라 섹션이 382px를 차지하지만 소스가 없으면 "인증 대기" 하나다.
대형 요약이 여러 정보를 "—"로 이어 붙인 한 덩어리 텍스트다. 좌열(큐 273 + 지도 583 =
856px)이 우열(로스터 907 + 대형 322 + 신호등 40 + 로그 ≈ 1400px)보다 훨씬 짧다.

### Decision

1. **카메라 컴팩트 모드** — 소스가 선택되지 않았거나 인증 전이면 카메라 섹션이
   한 줄 상태 바(아이콘 + 상태 라벨)로 접힌다. 소스가 선택되고 프레임이 오면
   전체 프리뷰가 펼친다.

2. **대형 요약 구조화** — RUNNING/HOLDING일 때 formation-detail이 dl 격자
   (리더·모양·간격·릴레이 Hz)로 그려진다. 진단 패널과 같은 .diag-readout 규격.

3. **열 균형** — 로그 패널(d#log-panel)을 좌열 지도 아래로 옮겨 좌우 높이를 맞춘다.
   우열은 로스터 + 대형 + 신호등(+진단)으로 줄어든다.
