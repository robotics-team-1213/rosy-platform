## D-1027 Fleet 좁은 관제 화면의 읽기 순서: 예외, 지도, 로봇 상세

**Status:** Accepted (2026-11-14)

### 배경

사용자가 ROSY UI 콘셉트([2026-11-14-rosy-ui-concept.md](../superpowers/plans/2026-11-14-rosy-ui-concept.md))와 화면별 읽는 순서 명세([2026-11-14-rosy-ui-screen-specs.md](../superpowers/plans/2026-11-14-rosy-ui-screen-specs.md))를 승인했다("이대로 구현"). 콘셉트 깊이 규칙 6은 390px 화면의 L1을 지도와 예외 목록으로 두고, 명세 1절의 390 순서는 머리, 내비 한 겹, 예외 한 줄, 지도 칸, 선택 로봇 패널, 로봇 행이다.

### 결정

1. [D-892](D-892-fleet-mobile-operator-priority.md) 결정 1의 좁은 화면 순서 **현재 개입 → 관제 상세 탭 → 지도**를 **현재 개입 → 지도 → 관제 상세(로봇·작업) → 발행 허용 띠**로 대체한다.
2. D-892 결정 2~4(선택 전 요약, CSS와 DOM 순서 일치, 폭 변경 중 노드·입력·탭·포커스 보존, 비상 정지·권한 계약)는 유지한다. D-629의 넓은 화면 2:1 배치와 48px 조작 규격도 유지한다.
3. 좁은 화면 첫 화면에서 지도가 보이는 것이 이 순서의 시험 기준이다. 로봇 선택기와 선택 로봇 패널은 지도 아래에 있다.
4. 인증·승인·장치 명령·상태의 의미를 바꾸지 않는다. 전체 주행 취소는 정지 경로가 아니며(비상 정지는 머리에서 늘 활성) 오른쪽 열 맨 아래로 내린다.

### 검증

`test/test_fleet_console_browser_part3.py`의 단일 열 순서 시험은 queues-panel, 지도, console-context 순서와 폭 변경 중 보존을 확인한다. `test/test_fleet_ui_review_browser.py`는 320/390 폭에서 지도가 첫 화면에 있고 로봇 선택기·선택 로봇 패널이 그 뒤에 오는지 확인한다.

이 결정은 실물 장치·현장 조명·제품 전체 UI/UX 수용을 선언하지 않는다.
