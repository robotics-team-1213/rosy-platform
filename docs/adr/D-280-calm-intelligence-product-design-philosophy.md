## D-280 ROSY 제품 디자인 철학은 차분한 지능에 은은한 따뜻함이다

**Status:** Accepted (2026-09-26). 제품 전체의 디자인 판단 기준이다. 구현·장치·현장 수용 판정은 포함하지 않는다.

잇는 결정: [D-254](D-254-design-philosophy-and-token-inventory.md) · [D-277](D-277-rosy-brand-colour-tokens.md) · [D-278](D-278-role-based-surface-ux-and-palette-review.md) · [interface concept 16](../architecture/16_ROSY_Interface_Design_Principles.md).

**Context:**

concept 16은 화면별 질문, 정직한 증거, 색의 의미, 행동의 위계를 정한다. D-254는 토큰과 부품의 전집을, D-277은 ROSY 이름의 장미색 사용 범위를, D-278은 역할별 웹 화면을 정한다. 그러나 웹·Fleet·로봇 얼굴·설치 경험·문서가 함께 어떤 제품 성격을 전달해야 하는지는 하나의 문장으로 정해져 있지 않았다. 사용자는 절제되고 신뢰할 수 있으면서 현대적인 제품을 원하며, 따뜻함은 은은한 포인트로 두고 로봇 얼굴에만 조금 더 허용하기로 했다.

**Decision:**

ROSY의 제품 성격은 **차분한 지능에 은은한 따뜻함**이다.

> ROSY는 상황을 정확히 이해하도록 돕고, 다음 행동을 침착하게 안내하는 로봇 플랫폼이다.

1. **아는 만큼 말한다.** 상태의 출처와 신선도, 기능의 실제 가용성, 검증 범위를 정확히 드러낸다. 알 수 없는 상태를 정상으로 그리지 않고, 제품 소개도 미검증 능력을 약속하지 않는다.
2. **중요한 것이 먼저 보인다.** 안전, 현재 상태, 다음 행동의 순서를 분명히 한다. 위험하거나 되돌리기 어려운 행동은 일상 명령과 다른 위계로 다룬다.
3. **복잡함을 사람이 다룰 수 있게 만든다.** 첫눈에는 지금 필요한 판단을 돕고, 원인·설정·진단은 필요할 때 깊게 볼 수 있게 한다. 막힌 상태는 이유와 그 사용자의 권한에 맞는 다음 단계를 알려준다.
4. **따뜻함은 작은 곳에 둔다.** ROSY 이름의 장미색, 짧고 배려 있는 문장, 로봇 얼굴의 간결한 표정으로 성격을 표현한다. 운용 화면은 차분하게 유지한다. 위험·주의·포커스·작업 데이터의 색과 의미는 기존 계약을 따른다.
5. **현대성은 정교한 품질로 만든다.** 정보 위계, 글자와 숫자의 읽힘, 여백, 면의 높낮이, 조작 대상의 크기, 상태 변화의 명료함을 일관되게 다듬는다. 장식성 움직임은 D-220의 정지 계약을 따른다. 접점마다 같은 화면을 복제하지 않고 같은 성격을 각 매체에 맞게 표현한다.

| 접점 | 먼저 답할 질문 | 적용 방향 |
|---|---|---|
| 로봇 운용 화면 | 지금 움직여도 되는가? | 상태·근거·가능한 행동을 분리하고 안전 조작을 고정한다. |
| Fleet | 어느 로봇에 주의가 필요한가? | 예외와 원인을 먼저 보여주며 미확인을 정상으로 표시하지 않는다. |
| 게임 호스트 | 경기장·공·로봇·골이 보이는가? | 경기 가시성에 집중하고 공만 따뜻한 초점색으로 둔다. HOLD·손실은 글로 알린다. |
| 로봇 얼굴 | 다음에 무엇을 할 것인가? | 멀리서 읽히는 의도와 간결한 표정에 따뜻함을 조금 더 담는다. |
| 설치·정비 | 무엇을 확인·조치·재확인해야 하는가? | 실제 수행 가능한 복구 단계와 검증 순서를 제시한다. |
| 로봇 상태 신호 | 로봇이 준비·주의·실패 중 무엇인가? | 부팅음·LED·LCD·운용 요약은 같은 확인된 상태를 표현한다(D-260 제안 계약 수용 후). |
| 문서·제품 소개 | 무엇이 가능하고 어디까지 검증됐는가? | 적용 범위와 증거 수준을 명시한다. |

Control 진단 화면은 concept 16의 별도 표면이지만 현재 PARKED다. D-266 조건을 만족해 계약에 편입하기 전까지 제품 전체 평가에서는 PARKED로 기록하고 UI 변경 범위에 포함하지 않는다.

**Alternatives:**

- 정밀한 산업 장비의 인상만 전면에 두면 전문성은 강하지만 처음 접하는 사람에게 거리감이 생긴다.
- 친근한 동반자 성격을 모든 접점에 강하게 적용하면 운용·안전 판단의 위계가 흐려진다.
- 현재의 개별 화면 규칙만 유지하면 공통 제품 성격을 설명하고 새 접점의 디자인을 판단할 기준이 부족하다.

**Consequences:**

새 화면, 로봇 표현, 설치 흐름, 제품 문서를 검토할 때 실제 근거와 권한에 맞는지, 중요한 상태와 다음 행동이 먼저 보이는지, 위험 행동이 구분되는지, 색과 움직임이 의미를 흐리지 않는지, 같은 제품의 성격으로 읽히는지를 확인한다. 이 ADR은 concept 16과 D-254/D-277/D-278의 구체적인 계약을 바꾸지 않는다. 사진·일러스트·하드웨어 마감, 얼굴의 표정 어휘와 상황별 범위, 접점별 대표 검증 장면은 후속 설계에서 결정한다.

**Validation:**

- 사용자가 제품 전체 범위, `차분한 지능`, 은은한 따뜻함, 로봇 얼굴의 약간 더 큰 표현 자유를 순서대로 확인했다.
- 이 문서와 기존 concept 16, D-254, D-277, D-278의 의미·안전 경계를 대조한다.
- 이 결정만으로 SOURCE/LOCAL/ROS-SIM/ARTIFACT/DEVICE/FIELD gate를 올리지 않는다. 접점별 디자인과 실기 증거는 별도로 검증한다.
