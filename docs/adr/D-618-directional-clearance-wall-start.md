## D-618 좁은 출발 위치는 이동 방향의 차체 여유로 판단하고 벽 앞에서는 제한 후진으로 복구한다

**Status:** Accepted (2026-10-10, 사용자 결정: 현재 위치에서도 동작하도록 조건을 조정하고 ADR로 남긴다).

### Problem

D-574의 모든 방향 회전 여유 + 5 cm 조건은 직선 이동에도 적용되면, 옆벽이 가깝지만 이동 경로가 열린 로봇을 시작하지 못하게 한다. 전방 영상에 벽만 보이면 차선 인식은 실패하므로 단순히 차선 모드를 다시 켜도 해결되지 않는다.

### Decision

1. D-574 2항의 일률적인 전방위 출발 거리를 대체한다. 직선 전진·후진은 기존 `RobotBody.translation_gap`으로 해당 방향의 몸체 통과 띠를 판단한다. 측면·반대 방향의 가까운 벽만으로 직선 이동을 거절하지 않는다. 제자리 회전에는 기존 회전 여유가 필요하다.
2. 벽 앞에서 차선을 잃었으면 현장 입회 아래 기존 CORE 수동 제어로 제한 후진한 뒤 차선 추종을 다시 검사한다. 후진은 단계마다 0.03 m/s, 최대 2 s, 최대 두 번이다. 신선한 LiDAR, 후방 사각 판정, 후진 거리 + 기존 몸체 정지 거리를 확인한다. 후진 뒤에도 벽을 보면 회전 여유를 다시 검사해 0.3 rad/s, 최대 2 s의 방향 조정을 한 번만 허용한다. 막힌 후진이나 회전을 보내지 않는다. 단계 뒤 센서·영상·정지를 다시 읽으며 무제한 재시도하지 않는다.
3. CORE 최종 명령 소유, 충돌 정지, 비상정지, teleop watchdog, 차선 hold lease, lease 소유권, 횡단보도 보호는 유지한다. 새 API나 센서 성공값, 임의 self-mask를 만들지 않는다. 차선 없는 벽을 정상 차선으로 간주하지 않는다.
4. 구현은 기존 `tools/capture/edge_drive.py`의 `advisory`, `cmd_nudge`, 제한 `cmd_drive`를 재사용한다. 현장 실행 전에 방향별 여유를 확인한다. 5초 차선 시험은 자동 재무장 없이 끝내고 OFF/IDLE 및 속도를 확인한다. 현재 두 로봇의 0.08 m/s 순항(기존 0.04의 2배)을 유지한다.
5. 모델 PC의 도구·몸체 시험, 실제 장치 명령 응답, 오돔 변위, 현장 물리 확인은 별도 증거로 남긴다. 후진 성공이나 명령 수락만으로 차선 주행 성공이라고 하지 않는다.
6. 코너에서 차선이 없으면 로봇의 관측·막힘을 Fleet으로 넘긴다. D-577/D-610의 상황 판단 서비스가 전방 영상·Rosy Cam·센서·맥락을 읽어 제안하고 Fleet이 검증해 기존 CORE 명령을 보낸다. 로봇의 선 인식 실패를 코너 부재로 해석하지 않는다. 규칙 제안과 영상 모델 제안을 구분하고 설치된 모델·heartbeat·제안·Fleet 판정·CORE 회신·후속 자세를 확인해야 이 연결을 완료했다고 한다. 영상 모델이 없는 상태에서 규칙 제안을 영상 판단으로 표시하지 않는다.

### Verification (2026-10-10)

사례 조회와 실행 등록은 분리한다. 열린 lane-stuck은 AI-first 등록 없이도 `ai_observer`가 조회할 수 있다. `fleet.ai_first.robots`는 이번 시험에서 비워 두고 D-610의 활성화 수용 조건을 우회하지 않는다. 제안 접수·실행은 기존 D-577 등록과 센서 검사에 따른다. 지원하지 않는 `REALIGN`을 영상 모델 선택지에서 제거한다. 요청 ID·증거·접수·최종 판정·CORE 결과 규약과 상황별 예시는 API Reference에 둔다.

- AI PC 소유자가 이번 영상 판단 시험을 승인했다. 실제 Qwen 프로필 `qwen3-vl:8b-instruct@0533d74300e4:d610-v1`, heartbeat `present`, 두 로봇의 Fleet resolver/acting 등록을 API로 확인했다. 이는 모델 적재·연결 증거이며 아직 코너 판단·명령 수락 증거는 아니다.
- 사례 조회·영상 선택지·역할·제안 접수/만료·기존 실행 검사 원격 계약 시험 97개 통과, NEW 0. 시험 모델 응답은 실제 Qwen 판단과 구분한다.

- 기존 도구·몸체 정지·막힘 복구 원격 시험 170개 통과, NEW 0.
- 현장 입회 아래 rosy_41 제한 후진 두 단계의 오돔 변위 약 0.122 m, 회전 약 0.594 rad. 차체 전방 여유는 약 0.017 m에서 0.175 m로 증가했다. 이후 차선 시험은 `camera_line_not_visible` / `camera_reselection_required`로 끝났다. 이는 복구 이동 증거이며 차선 주행 성공은 아니다.
- rosy_40은 후진 띠 여유 0, CORE 차선 시험도 `obstacle_ahead` / 차체 여유 0으로 정지했다. 시험 종료 후 두 대 모두 OFF/IDLE, 속도 0을 확인했다.
- 현장 Fleet의 이전 D-577 경로에는 규칙 기반 제안·판정·CORE 수락 기록이 있다. 최신 `fleet.stuck` / 영상 case 경로는 설치되지 않았고 상황 서비스 `model_profiles`는 비었다. signed candidate 설치와 영상 모델 판단·후속 명령 증거는 미확인이다.
