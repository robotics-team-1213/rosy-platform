## D-651 작업 중심 Fleet 지도와 선택 로봇 작업면

**Status:** Accepted (2026-10-11, 사용자 구현·배포 요청)

### Context

관제의 주 흐름은 로봇 선택 → 목적지·작업 배정 → 진행·문제 확인이다. 모든 로봇의 상세 명령과 카메라를 반복해 쌓고 지도 안에 장소명·좌표·신호 설명을 넣으면 지도와 작업의 맥락을 잃는다.

### Decision

1. 지도 작업면과 선택한 로봇 작업면 두 영역을 둔다. 로봇 목록은 선택과 연결·안전·진행 요약을 보여준다. 상세 근거와 기존 명령은 선택한 로봇 작업면에 유지한다. UI 선택은 목적지 지정 준비와 다른 상태이며 명령을 보내지 않는다. 선택 변경은 이전 로봇의 지정 준비와 확인 중 명령을 취소한다.
2. 목적지·작업은 기존 경로·한 바퀴·반복 운행 API를 사용하며 작업 종류별 입력을 하나씩 보여준다. CORE 확인·운영자 권한·연결·안전 조건·결과 읽기를 유지한다. 진행 중 목적지 변경은 기존 취소와 새 배정을 사용한다.
3. 지도에는 번호·아이콘·차선과 위치만 남긴다. 장소·교통·관측 좌표는 접힌 보조 정보로 옮기고 표시 옵션과 기술 계보도 접는다. 교정 불일치 경고는 접힌 정보 밖에 둔다. 관측 만료는 미확인으로 바꾸며 지도 크기와 활성 지도 계보는 유지한다.
4. 개입 큐와 전체 주행 취소는 탭 밖에 유지한다. 카메라 비교·대형·신호 조작은 운영 도구에서 연다. 공통 머리와 비상 정지 권한 계약은 유지한다.
5. D-540의 전 로봇 상세 확장 요구를 이 표면에서 요약 근거와 선택 작업면으로 대체한다. 오프라인·안전·교정 문제를 요약과 개입 큐에서 숨기지 않는다. 좁은 화면은 개입 → 지도 → 선택·배정 순서로 한 문서에서 읽는다.

### Consequences

표시와 선택은 보기 전용 사용자도 가능하지만 명령 권한은 바뀌지 않는다. 브라우저의 선택·배정·확인·결과 흐름, 화면 크기와 관측 만료, 배포된 실제 지도는 별도로 검증한다. 실제 로봇 이동과 교정의 측량 정확도는 화면 검증으로 대신하지 않는다.
