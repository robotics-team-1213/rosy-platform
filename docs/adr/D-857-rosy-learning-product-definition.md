## D-857 Rosy Learning 제품 정의 — 네 역할, 센터 하나, 5단계 메뉴, 정답 두 단계

**Status:** Accepted (2026-10-24, 사용자 결정 6건). 정의·범위·메뉴·정답 규칙을 정한다. 코드·배포·인스턴스 퇴역은 각 조각의 커밋과 운영 기록에서 따로 수용한다. 로봇 실행·배포 권한은 바꾸지 않는다.

### Context

Rosy Learning의 사용자·범위·화면이 문서마다 달랐다(`app-responsibilities.md`는 검수만, D-745는 학습 작업 제어까지). 한 바퀴를 끝까지 돈 학습 도메인이 없고, 모델 PC에 Learning 인스턴스가 여섯 개 있다. 조사와 기준안은 [제품 지도](../plans/2026-10-24-rosy-learning-product-map.md)에 있다.

### Decision

1. **정의와 사용자.** Rosy Learning은 로봇이 겪은 일을 정답으로 바꾸고, 그 정답으로 만든 모델 후보가 나아졌다는 증거를 쌓아 승인권자에게 넘기는 모델 PC의 학습 센터다. 사용자는 검수자·학습 담당·평가·승인 담당·관리자 네 역할이다. 범위는 수집 → 정답 → 데이터셋 → 학습 → 평가 → 승격 기록이다. 로봇 실행·배포·실행 권한 변경은 범위 밖이다(D-745, D-793 유지).
2. **센터 하나.** 사람이 들어가는 Learning은 모델 PC의 보호된 센터 인스턴스(Fleet `/console/learning` 진입) 하나다. v13 검수 인스턴스와 OMX 학습 후보 인스턴스는 기능과 자료를 센터로 옮긴 뒤 퇴역한다. 재설계 미리보기는 미리보기로만 남는다. 기록 없는 나머지 인스턴스는 소유자를 확인해 퇴역하거나 기록한다. 평가 정답 작업 공간(D-475)은 별도 state로 돌되, 들어가는 문은 센터의 「평가·승격」 메뉴다.
3. **5단계 메뉴.** 메뉴는 루프의 단계다: **홈 / 자료 / 정답 / 학습 / 평가·승격**. 도메인(Pinky 차로·객체·OMX·SIM·VLM·판단 모델)은 메뉴가 아니라 각 메뉴의 필터다. 홈은 도메인마다 단계 상태와 다음 할 일 하나를 보인다. 계정·저장 공간은 상단 설정으로 간다.
4. **정답 두 단계.**
   - **임시 정답:** 여러 모델이 같은 답을 내거나 토론으로 합의한 답. 화면에 「임시」로 표시한다. 학습 자료·질문 보정·실험에 쓴다. 승인이 아니다(D-514 §5, D-853 §3 유지).
   - **확정 정답:** 사람이 단 답, 또는 사람이 임시 정답을 「맞음」으로 확인하거나 고친 답. 승격 평가와 PromotionRecord(D-449) 증거에는 확정 정답만 쓴다.
5. **사람 확인은 작게.** 사람은 두 가지만 본다. (a) 도메인의 사진 종류마다 작은 고정 평가셋, (b) 모델끼리 갈렸거나 확신이 낮은 건. 확인은 한 장씩 처음부터 다는 것이 아니라 「맞음 / 고침」이다. 시작값(운영하며 조정): 고정 평가셋 사진 종류당 30장(그 사진의 모든 질문을 한 번에, 한 번 정하면 고정), 사람 확인 대기 도메인당 최대 50건, 임시 정답의 무작위 점검 도메인당 주 10건. 점검 오류율이 10%를 넘으면 그 질문의 임시 정답 생성을 멈추고 질문·모델을 다시 본다. 대기가 한도를 넘으면 새 임시 정답을 쌓지 않는다.
6. **VLM 판단 정답.** VLM 질문 정답은 별도 평가 state에 둔다(D-853 §4). 임시 정답을 허용하고, 위 4·5를 따른다.

조사한 Proposed 20건 가운데 대체되는 것은 없다. 아래 넷은 이 ADR이 해당 절을 고친다. 본문은 그대로 두고 각 파일 끝에 개정 메모를 단다.

| ADR | 바뀌는 절 |

| D-449 | PromotionRecord 증거는 확정 정답 평가만 |
| D-792 | §1.4 화면 목록 → 5단계 메뉴, §1.3 `rosy-review-v13.service` 퇴역(이 ADR은 아직 로컬 기록이며, 게시될 때 개정 메모를 함께 단다) |
| D-834 | SIM 화면 위치 → 「학습」 메뉴(아직 로컬 기록, 위와 같음) |
| D-853 | §2 「정답은 사람만」 → 임시·확정 두 단계(§3 「지표는 승인이 아님」 유지) |

D-475·D-514·D-793은 그대로 유지하며 이 ADR의 전제다.

### Consequences

- `app-responsibilities.md`의 Learning 행은 이 정의로 고친다.
- 메뉴 개편, 홈의 도메인별 단계 표시, 임시·확정 정답 표시와 확인 대기열은 별도 구현 조각이다.
- 인스턴스 퇴역은 자료 이전·백업·사용자 공지 뒤에만 한다. 자동 동기화는 만들지 않는다.
