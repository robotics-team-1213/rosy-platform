## D-1075 ROSY World 오프라인 시연과 Isaac 상태 관측

**Status:** Accepted (2026-11-23, 사용자 결정). RTX 4080·RAM 32GB 현장 수용과 Isaac Live 채택은 별도로 판정한다.

### Context

철거와 노트북 반납 뒤에도 보관한 현장 지도, CAD, OMX 셀과 상태 기록을 열어야 한다. 현장 Fleet과 Isaac Sim은 준비 시점과 가동 조건이 다르다. 브라우저에서 두 서비스에 직접 연결하는 구성은 두 서비스의 연결 상태에 시연 시작을 의존시킨다.

### Decision

1. **앱과 배포 단위.** ROSY Platform의 [`applications/world/`](../../applications/world/README.md)에 독립 앱을 둔다. 공용 Three.js와 정적 웹 파일을 ZIP으로 배포하고 로컬 HTTP로 연다. 번들은 지도·셀·보관 자료를 자체 포함한다. 원본 현장 자료는 인계 폴더에서 관리하고, 빌드에 쓰인 자료의 해시와 출처를 매니페스트로 기록한다.
2. **실제 자료.** Fleet 활성 지도는 파일로 확보해 번들 빌드의 입력으로 사용한다. 웹 지도에서 상태를 재생할 때 기록의 좌표계와 지도 버전을 대조한다. 현장 실측으로 정합을 확인하기 전에는 보관 배치임을 표시하고 CAD를 별도 보기로 제공한다.
3. **Isaac 상태.** 같은 장비의 격리된 로컬 ROS 2 Jazzy 도메인에서 관측기가 `/clock`, `/sim/joint_states`, `/sim/object_tf`를 구독한다. 관측 JSON을 로컬 HTTP로 제공하고 브라우저는 이를 읽어 관절 값과 물체 자세를 표시한다. 연결이 끊기면 상태 패널에 표시하고 지도와 셀 보기는 계속 사용한다. 현장 상태와 제어 권한은 기존 Fleet·World·CORE 경로가 소유한다.
4. **보관 CAD 설계 배치.** 현장 STL과 공통 상판 모서리로 R08 모델을 정합하고 계산에 쓰지 않은 모서리로 확인한다. 지도 버전·원본 CAD·셀 모델 해시가 일치할 때 설계 배치 버튼을 제공한다. 최신 현장 정합 상태는 화면에 미확인으로 표시한다.

### Consequences

- 철거 전에 현장 자료를 확보하고, 복사한 파일의 해시와 열림을 확인한다. 시연 준비는 검증된 ZIP으로 진행할 수 있다.
- Isaac Live를 채택하려면 대상 4080에서 보관 배치와 일치하는 A/B 장면으로 60초 연속 수신, 화면 대조, 팔 베이스와 화물 지지 상태, 일시정지·끊김·재시작, RAM·VRAM 피크와 시뮬레이션 속도를 확인한다. 채택 기준을 충족할 때까지 보관 렌더와 사진을 사용한다.
- 실험실에서 Chromium을 통한 오프라인 표시와 실제 Isaac 상태 전송을 확인했다. 대상 장비와 최신 현장 자료의 검증은 현장 인계 체크리스트에서 관리한다.
