## D-1085 기체 지도를 같은 래스터 틀의 새 파일로 바꾸면 Fleet이 지도 결속을 스스로 다시 승인한다

**Status:** Accepted (2026-11-28, 사용자 지시 "지도가 이건 자동으로 되고 있어야지. 그건 바로 처리해야 하는데?" — 관제 화면에서 rosy_45가 지도 교체 뒤 `map_frame`으로 멈춘 것을 보고). 구현은 이 ADR과 같은 PR이다. 실물 수용은 남았다.

| 결정 | 관계 |
|---|---|
| [D-1022](D-1022-robot-map-binding.md) | 개정한다. "옛 결속을 조용히 다시 쓰지 않는다"는 그대로다. "다시 승인은 사람이 한다"는 아래 증명이 모두 맞는 경우에 한해 Fleet이 대신한다. 증명이 하나라도 틀리면 지금처럼 운영자가 승인한다. |
| [D-1010](D-1010-site-goal-frame-binding.md) | 지킨다. 결속 없이 현장 좌표 목표를 보내지 않는다. 자동 승인도 같은 저장소 승인 경로와 같은 hold-out 판정(0.05 m)을 지난다. |
| D-972 충전 칸 도크 | 도크의 틀 표식은 따로 따라간다(도크 reframe, 같은 날 PR #1166). |
| 천장 카메라 보정 | 바꾸지 않는다. 북쪽 칸 구역의 카메라 오차(4~7 cm)가 hold-out 0.05 m를 넘으면 자동 승인은 거절되고 운영자 승인으로 남는다. |

### Context

- 2026-11-27·28 현장에서 세 기체의 점유 지도를 현장 좌표로 그린 파일(rule05a → rule06, 원점·해상도·크기 동일, 칸 뒤 허상 셀 11개 제거)로 바꿨다. 기체가 보고하는 `map_grid_id`가 바뀌어 결속이 `MAP_BINDING_GRID_CHANGED`가 됐고, 모든 운행이 `map_frame`으로 멈췄다. 운영자가 기체마다 손으로 다시 승인해야 했다.
- 결속은 기체 지도 틀을 현장 틀로 옮기는 변환이다. 기체 지도 틀은 지도 래스터의 원점·해상도·크기로 정해진다. 그 값이 같고 셀 몇 개만 다르면 틀은 같다.
- 벽 맞춤으로 "같은 틀"을 증명하는 첫 안은 독립 검토에서 기각됐다. 5 cm 원점 이동이 허용 오차(0.06 m) 안에 들어갔고, 180도 뒤집힘은 북쪽으로 치우친 카메라 한 점에만 기댔다.

### Decision

1. **결속과 함께 지도 서명을 저장한다.** 서명은 원점(x, y, yaw), 해상도, 폭, 높이, 셀마다의 종류(점유·빈칸·모름)다. 승인할 때 저장하고, 서명이 없는 기존 결속은 기체의 현재 grid id가 결속의 grid id와 같을 때 한 번 읽어 저장한다. 서명이 없으면 자동 승인은 없다(`GRID_SIGNATURE_MISSING`).
2. **자동 승인 조건은 래스터 동일성이다.** 새 지도의 원점·해상도가 저장된 값과 1e-6 안에서 같고, 폭·높이가 같고, 종류가 달라진 셀이 max(12, 저장된 지도 점유 셀의 2 %) 이하일 때만 같은 틀로 본다(현장 사례 11개). 어긋나면 `GRID_FRAME_CHANGED` 또는 `GRID_CELLS_CHANGED`다.
3. **대칭 지도는 자동 승인하지 않는다.** 저장된 지도가 자기 자신의 180도 회전이나 좌우·상하 거울상과 같은 셀 예산 안이면 뒤집힌 지도를 구분할 수 없으므로 거절한다(`GRID_SYMMETRIC`).
4. **기체는 서 있어야 한다.** LOCALIZED, IDLE, 신선한 0 속도, 목표 없음. 현장 지도 판은 결속과 같아야 한다. 2 s 안의 천장 카메라 자세가 저장소의 기존 hold-out 판정(0.05 m)을 지나야 한다.
5. **변환은 옛 것 그대로다.** 옛 결속의 짝을 새 grid id로 다시 승인한다. 승인자는 `fleet:auto-rebind`이고 증명 수치를 감사 사건(`map_binding_auto_rebind`)으로 남긴다. 새 지도의 서명을 새 결속에 저장한다.
6. **운행은 출발 전에 한 번 시도한다.** `MAP_BINDING_GRID_CHANGED`를 만난 운행은 목표를 보내기 전에 자동 승인을 한 번 시도하고, 거절되면 지금처럼 `map_frame`으로 멈춘다. 기체마다 10 s에 한 번만 시도한다.
7. **끌 수 있다.** 현장 설정 `fleet.trip.map_auto_rebind`(기본 켬). 마지막 시도 결과는 결속 조회의 `auto_rebind`에 나온다.

### Consequences

- 같은 틀의 지도 교체 뒤 운영자 승인 없이 운행이 이어진다. 원점이 한 셀이라도 움직이거나 크기가 바뀐 지도, 대칭 지도, 카메라 근거가 없는 경우는 운영자 승인으로 남는다.
- CORE의 지도 응답에는 grid id가 없다. 지도를 읽기 전후의 grid id가 같은지만 확인한다(최선 노력). 지도 응답에 grid id를 싣는 것은 후속이다.
- 유휴 기체는 다음 운행의 첫 틱에 다시 결속된다. 그 전까지 결속 조회는 불일치로 보인다.
- 독립 검토 두 번(첫 안 기각, 래스터 동일성 안 조건부 승인 후 반영). 실물에서는 아직 돌리지 않았다.
