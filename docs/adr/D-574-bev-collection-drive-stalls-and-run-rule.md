## D-574 지도 라벨 수집 주행은 사람이 몰고, 에이전트 주행은 출발 조건과 막힘 원인을 먼저 지운다

**Status:** Accepted (2026-10-09, 사용자 결정 "그 부분을 ADR로 기록하고 교훈까지 기록"). D-563 3항(천장 BEV 녹화)의 수집 주행에 적용한다.

### Problem

2026-10-09 21:25–21:41, 8kcn(`rosy_60`, 릴리스 063, 천장 마커 id 40)으로 D-563 수집 주행을 시작했다. 천장 녹화(모델 PC `v13-ceiling-rec`, 약 3 fps)와 로봇 녹화(`rosy_rec.sh`)는 돌았지만, 15분 동안 로봇은 거의 움직이지 않았다. 막힌 순서는 다음과 같다.

1. **로봇에 꽂힌 충전 케이블.** 흰 케이블이 로봇에 꽂혀 몸체 바로 앞에 있었다. LiDAR는 이를 5 cm 장애물로 봤고, CORE `CAMERA_LINE`은 `obstacle_ahead`(gap 0.054–0.057 m)로 바로 멈췄다. 케이블이 로봇과 함께 움직여 teleop도 6.8 cm에서 멈췄다. 현장에서 케이블을 뽑았다.
2. **벽에 붙은 출발 위치.** 케이블을 뽑으며 로봇이 아래 벽 약 5 cm 앞에 놓였다. 가장 가까운 LiDAR 점이 9.1 cm(왼쪽 앞 62–72°)에 2분 넘게 머물렀다. 에이전트는 이를 사람 손으로 보고 "15 cm 비면 출발"을 기다렸다.
3. **스크립트 가드의 mm 단위 거절.** 공유 `RobotBody` 가드(`guard.py`)는 전진 3.2 cm < 3.3 cm, 회전 9.1 cm < 9.3 cm, 후진 3.6–3.9 cm < 4.0 cm로 2–4 mm 차이에 매번 거절했다.
4. **가드 해제 시도의 차단.** 사용자가 "다 해제하고 처리해"라고 했다. 가드 없는 teleop 스크립트는 Claude Code 자동 모드 분류기가 안전 약화로 막았다. 이 해제는 사용자가 권한 규칙을 직접 추가해야만 가능하다.
5. **장치 차선 추종이 수집에 맞지 않음.** 가드를 지키는 후진 원호로 벽에서 떨어진 뒤 CORE `CAMERA_LINE`을 여섯 번 돌렸다. 매번 3–6 s 안에 `camera_line_not_visible` → `stuck_back_off` → `LOST(camera_reselection_required)`로 끝났다. 장치의 선 추종기는 흰 선 하나를 쫓으며(D-378 E1), 벽을 보거나 선이 화면 밖이면 멈춘다. 경기장의 모든 도로를 지나야 하는 수집에는 맞지 않는다.

### Decision

1. **수집 주행의 기본은 사람 운전이다**(D-378 4항 재확인). 지도 라벨 수집은 현장 사람이 Pilot(태블릿·폰)으로 경기장의 모든 도로를 한 번 이상 지나며 몬다. 에이전트는 그동안 천장 녹화, 로봇 녹화, 시각 동기, 진행 확인(천장 BEV로 지나간 도로 표시)만 맡는다. 라벨은 운전 주체와 무관하게 지도와 자세로 나오므로, 사람이 몰아도 자동화가 깨지지 않는다.
2. **에이전트가 몰 때는 출발 전 조건을 먼저 확인한다.** 하나라도 아니면 주행 대신 그 원인을 먼저 푼다.
   - 로봇에 꽂힌 케이블이 없다.
   - D-618 개정(2026-10-10): 직선 이동은 그 방향의 차체 통과 띠와 제동 여유로 판단한다. 전방위 회전 여유 + 5 cm를 직선 출발 조건으로 쓰지 않는다. 벽 앞에서 차선을 잃으면 후방 여유를 확인한 제한 후진으로 먼저 복구한다. 제자리 회전에는 기존 회전 여유가 필요하다.
   - 로봇이 도로 가운데 근처에서 도로 방향을 본다(천장 BEV와 전방 카메라로 확인).
   - CD 업데이트를 보류했다(D-553 카나리아).
3. **오래 멈추면 원인을 본다.** 같은 거리 값이 1분 넘게 그대로면 움직이는 사람·물체가 아니라 고정물이다. 기다리지 말고 천장 BEV와 전방 카메라로 확인한 뒤 빼낸다.
4. **안전 장치의 범위.** CORE의 몸체 정지는 끄지 않는다. 스크립트 가드를 끄거나 느슨하게 하는 것은 사용자가 Claude Code 권한 규칙으로 명시해야만 한다. 에이전트가 우회하지 않는다. 가드의 mm 단위 거절이 반복되면 임계를 고치지 말고 출발 위치를 바꾼다.
5. **장치 `CAMERA_LINE`은 수집 주행 수단으로 쓰지 않는다.** 직선 구간 확인용으로만 쓴다. 수집용 자율 주행은 D-563 라벨로 학습한 drivable 모델이 R0 재생·R1 그림자를 통과한 뒤(D-378 1항) 따로 정한다.

### Consequences

- 이 사건의 녹화(로봇 `20261009T122832Z_rosy-pinky-8kcn`, 천장 `v13-map-labels-d209f530/ceiling`)는 정지 구간이 대부분이라, 라벨 파이프라인의 실제 자료 시험(시각 동기·마커 방향·투영)에만 쓴다.
