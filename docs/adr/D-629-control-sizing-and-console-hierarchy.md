## D-629 공통 조작 규격과 관제 정보 위계

**날짜:** 2026-10-11
**상태:** 구현

### 결정

사용자는 Fleet 캡처에서 서로 다른 버튼 크기와 지도·현재 대응·사건 기록의 동일한 강조를 지적했다. D-280의 현장 관제 목적과 D-624의 역할 토큰·공용 부품 우선 규칙을 유지하며 D-359의 일반 조작 크기 사다리를 다음과 같이 정정한다.

1. 일반 버튼·필드·선택·체크 누름 면은 48px를 공유한다. 기존 주 조작을 줄이지 않고 보조 조작을 맞춘다. 기존 `size` 속성과 두 토큰 이름은 호환성을 위해 유지한다. 최소 높이로 정의해 긴 문구와 비활성 사유는 더 높아질 수 있다. 폭은 같은 좌우 여백과 실제 라벨 길이로 결정한다.
2. 일반 버튼은 라벨 글자·행 높이·좌우 여백을 공유한다. 종류는 채움·상태·동작 의미를 구분하며 크기로 새로운 버튼 종류를 만들지 않는다. 아이콘 전용은 같은 누름 면의 정사각형이다.
3. 비상 정지·불가역 실행도 같은 48px·14px 라벨·좌우 12px 여백을 쓴다. 위험 채움과 아이콘·보이는 동사로 구분한다. 비활성·포커스·확인·CORE 권한 계약은 유지한다. 사용자의 2026-10-11 추가 지시에 따라 58px 크기 예외를 철회한다.
4. 넓은 화면의 왼쪽 2/3은 지도, 오른쪽 1/3은 상태·대응이다. 현재 개입 큐는 탭 밖 맨 위에 항상 두고, 그 아래 `로봇 상태`를 기본으로 `기록·근거`와 `운영 도구`를 나눈다. 탭 전환으로 지도나 현재 개입이 사라지지 않는다. 좁은 화면은 개입 → 지도 → 같은 탭 순서이며 DOM·시각 순서가 일치한다. 탭은 키보드로 선택할 수 있고 기존 모듈과 인증·조작 핸들러는 마운트 상태를 유지한다.
5. 기본 로봇 상태 탭에서는 사건 기록을 숨긴다. 기록·근거 탭을 열면 조회 상태·건수·오류와 목록을 바로 보여준다. 개별 사건만 펼쳐 기존 출처·사람 검토·내보내기를 사용한다. 기록의 로봇·원인과 시작 시각을 분리하고 중립 구분선을 사용해 현재 경보와 경쟁하지 않는다.
6. 정보 위계의 이유와 공통 규격을 DESIGN.md와 기존 컴포넌트 갤러리에 둔다. 별도 팔레트·컴포넌트 라이브러리·API·명령 경로를 만들지 않는다.

### 검증

원격 Chromium에서 두 테마의 모든 버튼 종류·필드·긴 비활성 사유·48px 비상 정지를 확인한다. 실제 소스 관제의 데스크톱·모바일에서 기록 접힘·조회 오류·펼치기·검토 저장·내보내기, DOM 순서·포커스·가로 넘침·첫 화면 비상 정지를 확인한다. 서버 배포와 실물 주행은 별도 증거다.
