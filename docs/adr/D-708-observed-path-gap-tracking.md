## D-708 관측한 차선 형상을 오돔으로 옮겨 제한된 공백을 잇는다

**Status:** Accepted (2026-10-12, 사용자 후속 방향 승인; SOURCE 구현과 원격 시험 범위)

### Context

D-615의 중심점 방위각은 차선 접선이 아니며 `drivable_centre`는 곡선도 포함한다. 같은 입력의 A/B 시험에서 기존 직선 가설은 반경 1 m 곡선의 관측 소실 뒤 각속도 0으로 전진했다. 조사와 반례는 [기록](../plans/2026-10-12-straight-curve-observation-research.md)에 있다.

### Decision

- `way_target`이 이미 계산한 연속 차선 중심점을 가까운 곳부터 유효한 관측 구간까지만 보관한다. 빈 행 너머나 관측 구간 밖을 연결하지 않는다. 방위각이나 이전 명령 곡률로 차선 형상을 만들지 않는다.
- 독립 관측 3회·접선 방향 12도 조건을 유지하고, 저장 형상을 관측 당시 odom 좌표로 옮긴다. 평행한 직선의 횡오프셋이 접선을 바꾸지 않으며 곡선은 관측한 꺾임을 유지한다.
- 공백에서 현재 odom pose를 사용해 저장 형상을 몸 좌표로 변환한다. 경로 투영점부터 관측 경로를 따라 0.10 m 앞의 목표를 고르고 기존 pursuit 조향 계산을 재사용한다. 구간이 끝났거나 목표가 뒤에 있으면 중단한다.
- 마지막 독립 관측 이후 누적 odom 이동거리, 보관한 구간의 남은 길이, 0.25 m, 2.5 s 중 먼저 소진되는 조건에서 중단한다. 같은 추론 프레임의 재사용은 이 시각과 예산을 갱신하지 않는다.
- 최신 turn/pivot/off-line/crosswalk/straddle/closed/경계 너머/경로 이탈 거절과 비정상 pose·시계 역행은 즉시 가설을 버린다. 카메라 품질·신선도·추론 실패·CORE 장애물 및 권한 게이트는 계속 적용한다.
- Isaac은 명시적인 `odom_expected_path` 출처로만 이 출력을 받아들이고 RL 상태·학습 갱신에서는 제외한다. 새 CORE 모드나 API, bridge 활성화, 실물 주행은 추가하지 않는다.

### Validation

직선 횡오프셋 접선 불변, 좌우 곡선 보존, 같은 프레임 재사용, 시간·누적거리·끝단 소진, pose 점프·역행·비정상 수치, 금지 전략 우선권, 행 공백, Isaac RL 제외 및 실제 CORE 조향을 원격 시험한다. 실제 Isaac 재실행·ROS/Fleet 통합·실물 수용은 별도 판정이다.

### 기존 결정과 관계

D-615의 공백 유지 구현을 관측 형상과 실제 관측 시각 기준으로 확장한다. D-476 bridge와 D-597 테이프 복귀 금지를 유지한다. CORE 단일 최종 명령 권한은 바꾸지 않는다.
