## D-384 도로 상태 추정기와 도로 주행 행동 — 선이 사라져도 예상 도로를 잇고, 모르면 오른쪽

**Status:** Proposed (2026-10-01). 차선 유지 소유 세션(rosy-bc) 검토 전 초안이다.

잇는 결정:

- **D-364:** 차선 유지는 선 따라가기가 아니라 차로 지키기다. 인식 변경은 재생 벤치가 먼저다.
- **D-378:** 자율 사다리는 R0 재생 → R1 섀도 → R2 누르고 있을 때만 주행이다. 신호 정책은 꺼 둔다.
- **D-344:** 보조 자율이다. 장애물 정지(§11), IR 이탈 가드(§12), 회전율 상한(§13)을 둔다.
- **D-369:** 최종 `/cmd_vel`은 CORE 하나다.
- **D-356·D-373:** 학습 섀도 증거다.
- **D-379:** LiDAR 벽 라벨이다.

**Context:**

1. **선이 사라지면 곧바로 멈춘다.** 실물 경로(`keep`)는 선이 안 보이는 프레임에서 예측 없이 HOLD하고, 3 s 뒤 CORE가 LOST로 잠근다.
   - 주행기록계로 선을 기억하는 것은 `centre` 모드의 `_LineMemory`(최대 0.40 m)뿐이다.
   - 상태 필터(칼만·히스토그램·입자)와 곡률 모델은 없다. `LaneTracker`는 런타임에서 쓰이지 않는다.
2. **갈 방향을 모를 때의 규칙이 없다.**
   - 한 경계만 보이고 좌우가 애매하면(`|y| < 3 cm`) 직전 방향을 이어받는다.
   - 교차로에서는 갈림길을 고르지 못하고 멈춘다(실물 장치).
3. **장애물은 거리 문턱으로 멈추고 기다리는 것뿐이다.**
   - 추종 간격, 충돌까지 시간(TTC), Fleet 보고 뒤 재경로가 없다.
   - 교차로 양보와 횡단보도 규칙도 없다.
4. **실측 편향이 있다.**
   - 카메라 피치가 명목 8°가 아니라 ≈11.8°다.
   - LiDAR 방향 오프셋이 180°와 190°로 다르다.
   - 주행기록계는 요 ±3 %, 직진 거리 1–8 % 오차가 있다. IMU는 출력이 없다.
   - 보정이 들어가기 전의 사전 정보는 치우친다.
5. **신호와 정지선 검출이 약하다.** 초록 오판이 72 %, 정지선 검출이 29 %다(D-378).

**Decision:**

1. **도로 상태 추정기를 둔다(ROS-free 모듈 + 섀도 노드).**
   - **상태:** `x = [d, φ, κ, w]`와 공분산 P.
     - `d`: 내 차로 중앙에서의 옆 오프셋, 왼쪽이 +.
     - `φ`: 방향 오차.
     - `κ`: 도로 곡률.
     - `w`: 겉보기 차로 폭. 사전값은 지도 차로 폭이다. `w / w_map`이 조감도 옆 방향 배율 오차, 곧 피치 편향을 흡수한다.
   - **예측:** 주행기록계 매 걸음(`ds = v·dt`, `dθ = ω·dt`)마다 한다.
     - `d ← d + ds·sin φ`
     - `φ ← φ + dθ − κ·ds`
     - `κ`는 지도 곡률이 있으면 그쪽으로 끌리고, 없으면 무작위 보행이다.
     - 공정 잡음은 실측 오차에 맞춘다: `Q_d = (0.08·ds)²`, `Q_φ = (0.03·|dθ|)² + (0.02·ds)²`.
   - **측정:** 근거리(`x ≤ 0.33 m`)만 쓴다.
     - **규칙 경계:** `LaneKeeper.last` 경계.
       - `y_R = −w/2 − d − xφ + κx²/2`, `y_L = +w/2 − d − xφ + κx²/2`
       - 방향은 `ψ = −φ + κx`
       - 소유 세션이 붙인 좌우 표시는 참고일 뿐이고, 어느 경계인지는 게이트가 정한다.
     - **학습 섀도:** 1차원 `d` 측정이다.
       - 불확실도는 `σ = 0.03 / max(confidence, 0.2)`이다.
       - `wall_fraction > 0.3`이면 쓰지 않는다.
       - 추론이 늦으므로 `stamp`에서 지금까지의 주행기록계 변화로 옮겨 적용한다.
     - **IR 센서:** `x ≈ 0`의 선이다(`σ = 0.005 m`). 어느 선인지 모호하므로 게이트를 거친다.
     - **LiDAR 벽:** 측정이 아니라 **거부권**이다. 투영한 벽에서 0.05 m, 10° 안에 있는 카메라 경계는 벽으로 표시하고 버린다. LiDAR 방향 보정 전까지 넓게 잡는다.
     - **정지선:** 지도 위 종방향 위치 `s`를 재설정한다. 정지선 사이 거리 비로 주행기록계 배율도 추정한다.
   - **게이트:** 차례로 적용한다.
     1. 벽 거부
     2. 경계별 `NIS < 9.21`(2-D, 99 %)
     3. 한 프레임 옆 점프 `|Δy| > 0.04 m`면 거부(0.1 m/s, 8 fps면 한 프레임에 1.25 cm 이동)
     4. 쌍이면 `|y_L − y_R − w| < 0.04 m`이고 `|ψ_L − ψ_R| < 12°`
     5. 규칙과 학습이 서로 어긋나고 둘 다 게이트를 못 넘으면 어느 것도 쓰지 않는다.
   - **다중 가설:** 최대 3개다. 각 가설은 후보 선마다 오른쪽/왼쪽/잡음 표지를 붙이고, 로그 우도 + 잡음 벌점 + 지도 사전으로 점수를 낸다. 1위가 `ΔlogL > 2`로 앞서면 그것을 쓴다. 비등하면 결정 2를 적용한다.
   - **출력:** `perception/road_state`(String JSON). 내용은 `d, φ, κ, w`, P 대각, 단계, 가설 id, 거부 사유별 수(벽, NIS, 점프, 폭)다. **명령을 내지 않는다.**

2. **모르면 오른쪽이다(대한민국 우측통행의 동점 규칙).**
   - 이것은 차선 유지 규칙이 아니다. 기준은 늘 내 차로의 중앙이다. 선택지가 비등할 때만 쓴다.
   - **순서:** 명시된 경로·목표 방향(Fleet) > 목표 없는 교차로에서는 우회전 > 비등한 후보 중 가장 오른쪽.
     - 우회전은 대향 차로를 가로지르지 않는다.
     - 가장 오른쪽을 고르는 것은 게이트와 벽 거부를 통과한 후보 안에서만이다. 벽이 "오른쪽이라서" 이기는 일은 없다.
   - **한 경계만 보일 때:** 오른쪽 경계 가설이 게이트를 통과하면 오른쪽으로 추적한다. 실패할 때만 왼쪽으로 본다. `LaneKeeper`의 애매 구간(`|y| < 3 cm`) 동점 처리도 이 규칙으로 바꾸도록 소유 세션에 제안한다.
   - 이 규칙은 양보, 정지, 장애물 판단을 이기지 못한다.

3. **선을 잃었을 때 단계적으로 저하한다.**
   - 기준은 마지막으로 받아들인 측정 이후 주행기록계 거리 `s_lost`와 P다. 거리는 배율 오차를 덮으려고 1.08배 해서 쓴다.

   | 단계 | 조건 | 행동 |
   |---|---|---|
   | TRACK | 최근 2 프레임 안에 측정 수용 | 정상 |
   | COAST | `s_lost < 0.10 m`, `σ_d < 0.03 m` | 예측과 지도 곡률로 정상 속도 |
   | SLOW | `s_lost < 0.25 m`, `σ_d < 0.05 m`, `σ_φ < 10°` | 속도 50 %, 게이트 1.5배 |
   | STOP | 그 밖, 또는 벽만 보이는 프레임 3연속 | 멈추고 재획득 |

   - 이 예산은 기존 `lane_bev` 기억 한도(0.40 m) 안이다. 추정기는 그 기억을 사전으로 참조하고 중복 구현하지 않는다.
   - **재획득:**
     - 게이트를 2배로 넓히고 가장 오른쪽 비벽 후보부터 가설을 시작한다.
     - 3 프레임 연속 일관(쌍, 또는 한쪽 + IR 일치)일 때만 TRACK으로 돌아간다.
     - 2 s 안에 후보가 없으면 멈춘 채 보고한다.

4. **도로 주행 행동은 결정적 상태 기계 하나다(속도 상한과 경로 선택만 낸다).**
   - **출력:** 속도 상한과 경로 선택뿐이다. 최종 명령은 CORE가 기존 게이트로 자른다. 전이는 `(상태, 입력, 시계)`의 순수 함수라 재생과 섀도에서 그대로 돈다. 오래됐거나(`> 0.3 s`) 없는 입력은 속도 0이다.
   - **상태:** `LANE_FOLLOW`, `FOLLOW`(앞 로봇 추종), `HOLD`, `APPROACH`, `STOP_AT_LINE`, `YIELD_CHECK`, `CREEP`, `CROSS`, `FAULT`.
   - **차로 안 장애물:**
     - 경로 복도(차로 폭 − 여유, 길이는 속도 비례) 안의 물체에 대해 멈추고 기다린다. **추월하지 않는다.** 도로교통법도 교차로·횡단보도의 앞지르기를 금한다.
     - 앞 로봇이 움직이면 간격 `d0 + τ·v`를 둔다(`d0 = 0.25 m`, `τ = 1.5 s`, 최소 0.8 s, ISO 15622).
     - `t_blocked = 10 s`를 넘으면 Fleet에 BLOCKED를 보고한다. 재경로는 Fleet이 한다.
   - **교차로:** 신호와 정지선 검출이 게이트를 통과하기 전에는 **모든 교차로가 일단정지**다.
     - 교차로 위치는 카메라 정지선이 아니라 Fleet 지도·경로와 LiDAR 기하로 안다.
     - 절차:
       1. 접근 0.6 m에서 0.05 m/s로 감속한다.
       2. 선 앞 0.15–0.22 m에서 1.0 s 정지한다.
       3. 양보를 확인한다.
       4. 0.03 m/s로 서행하며 1.0 s 확인한 뒤 통과한다.
     - 양보(도로교통법 제26조):
       1. 이미 교차로에 들어간 차
       2. 넓은 도로
       3. 동시 도착(`t_tie = 0.5 s`)이면 오른쪽 차
       4. 좌회전은 직진·우회전에 양보
     - 횡단보도(제27조): 보행자가 있거나 건너려 하면 멈춘다. 시간 초과로 무시하지 않는다.
     - 로봇끼리는 Fleet이 정지선 도착 시각을 찍어 먼저 온 순서로 통과하고, 동시면 오른쪽 우선이다. 4방향 동점은 Fleet이 정한다.
     - 초록 신호는 나중에 게이트를 통과한 뒤에만 기다림을 줄일 수 있다. 빨강이나 모름은 절대 진입을 허락하지 않는다.
   - **회전:** 교차로 회전은 지도 기하로 미리 계산한 호를 pure pursuit으로 따라간다. 회전 중에는 `w`, `κ`를 고정하고 목표 갈래 차로에 대한 게이트만 받는다. 호 길이 × 1.3 안에 목표 차로를 못 잡으면 멈춘다.

5. **소유와 도입 순서.**
   - **이 결정이 새로 두는 것(이 세션):**
     - `perception/road_state.py`: 추정기, ROS-free
     - `road_state_node.py`: 섀도 발행
     - `road_behaviour.py`: 상태 기계, ROS-free
     - 재생 하네스
   - **제안만 하는 것(차선 유지 세션 소유):** `lane_keep*.py`, `lane.py`, `line_observer`의 차선 모드, `core_features/line_follow/*`, `tools/lane_replay.py`의 변경. 인터페이스를 제안하고, 들일지는 소유 세션이 정한다.
   - **R0:** `lane_replay`의 실주행·텔레옵 세션으로 재생한다. 지표는 다음과 같다.
     - 기존 `on_line` / `on_paint` / `none` / `jump`
     - NIS 분포, COAST 비율, 벽 오수용, `d` 점프
     - 모름 상황에서 오른쪽 선택률
   - **R1:** 장치에서 섀도로 돈다. 명령은 없다.
   - **R2:** 누르고 있을 때만 주행한다. 이때 `LaneKeeper` 오차를 전방 거리 `L`에서의 `−(d + L·φ)/half`로 바꾸는 것은 소유 세션의 결정이다.
   - **보정 선행:** 카메라 피치와 LiDAR 방향 보정(진행 중인 브랜치)이 들어가기 전에는 R1까지만 간다.

**Consequences:**

- 선이 잠깐 사라지거나(가림, 반사), 벽이 선처럼 보이거나, 교차로가 모호해도 로봇이 예상 도로를 따라 조금 더 가고, 그다음 안전하게 멈춘다.
- 오른쪽 우선은 모를 때만 쓰는 동점 규칙이라 경로 지시와 양보를 해치지 않는다.
- 모든 교차로 일단정지 때문에 흐름은 느려진다. 신호와 정지선 검출이 게이트를 통과하면 줄인다.
- 숫자 문턱은 0.1 m/s, 8 fps에 맞춘 제안값이며 R0 재생으로 조정한다.

**Validation:**

- ROS-free 단위 시험:
  - 예측·갱신 수식, 게이트별 거부
  - 가설 동점에서 오른쪽 선택
  - 저하 단계 전이
  - 상태 기계 전이표
  - 오래된 입력 → 0
- R0 재생 지표와 합격 기준은 소유 세션과 합의해 D-378 표에 더한다.
- 장치 R1 섀도 기록이 있어야 R2를 논의한다.
