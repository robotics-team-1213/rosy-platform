## D-379 학습 데이터는 실물 세션 카탈로그로 모으고, 라벨은 규칙보다 믿을 만한 출처(주행 궤적·지도 투영·측정 신호)로 자동으로 달며, 이 PC 저장소를 정본으로 Google Drive 에 사본을 둔다

**Status:** Accepted (2026-09-30, 사용자 결정). D-356(학습 루프)의 수집·데이터셋·게시 단계를 구체화한다.

### Context

- 사용자 목표(2026-09-30): 학습으로 먼저 푼다 — **차선·주행 영역 분할**, **정지선·횡단보도·신호등 검출**. 라벨링은 **자동 라벨만**.
  저장은 **로컬 + 원격** 인데 Hugging Face 가입이 안 돼 **Google Drive 나 내부 저장소**로 한다.
- 실물 녹화 재생(D-378): 현재 규칙 인식은 실물에서 신호 GREEN 72 % 오검출, 정지선 29 %, 실물 `line` 차선은 직진에서 +0.30
  치우침. 규칙 출력을 그대로 라벨로 쓰면 모델이 그 오류를 배운다.
- 원본 세션은 약 1.7 MB/s(raw bgr8 mcap). `feat/teleop-video-compress` 가 H.264/H.265 변환과 프레임별 부가 데이터(명령·자세)
  sidecar 를 만든다. 옛 teleop mp4 는 `data/teleop/learning/`.
- D-356 은 HF private 저장소와 40-hex 커밋 고정을 전제했다 — 이 결정이 대체한다(아래 4항).

### Decision

1. **세션 카탈로그**: 모든 실물 세션(원본 mcap, 압축 영상, sidecar, 추출 프레임, 라벨, 데이터셋 소속)을
   `data/perception/catalog.jsonl` 한 곳에 적는다. 세션마다 운전 주체(사람/로직), 장면 태그(직진·곡선·교차로·정지선·횡단보도·
   신호·벽·장애물), 길이, 파일 sha256, 오류 참조(D-378 표)를 둔다. `data/` 는 공개 저장소에 올리지 않는다.
2. **자동 라벨 출처(신뢰 순)**:
   - **주행 궤적 → 주행 가능 영역**: 사람이 몬 구간에서 몇 초 뒤의 실제 자세들을 공칭 지면 모델(D-364 §3)로 앞 프레임에
     투영해 "로봇이 실제로 지나간 바닥 띠"를 라벨로 단다. 규칙이 필요 없다.
   - **지도 투영 → 차선·정지선·횡단보도**: 실물 트랙 지도(260919 STL, `map_v2_fleet`)의 칠해진 선을, 로봇의 지도 자세
     (오도메트리 + 천장 카메라 자세 D-257 보정)로 카메라 영상에 투영한다. 지도 자세가 없는 세션은 이 라벨을 비운다.
   - **측정 신호 → 신호등 상태**: 천장 관측기(D-337)의 그 시각 측정 색. 램프가 영상에 보이는 프레임에만.
   - **규칙은 보조**: 규칙(keep v2, road.py) 라벨은 위 출처와 일치하는 곳만 쓴다. 출처끼리 어긋난 프레임은 학습에서 빼고
     카탈로그에 "불일치"로 남긴다.
   각 라벨에 출처·버전·신뢰도를 함께 저장한다.
3. **평가 세트**: 학습은 자동 라벨만 쓴다(사용자 결정). 모델이 좋아졌는지 재는 **고정 평가 세트**는 따로 두고,
   세션 단위로 분리하며 학습 세트와 겹치지 않는다. 평가 라벨도 자동이되 가장 믿을 출처(지도 투영·궤적)만 쓴다.
4. **저장·게시**: 이 PC `data/perception/` 가 정본(원본·압축·라벨·데이터셋). 데이터셋·모델은 **sha256 매니페스트**
   (`manifest.json`: 파일 목록·해시·출처 세션·라벨 버전)로 고정한다. 원격 사본은 Google Drive 폴더(Colab 이 마운트)로,
   올리기는 수동 또는 동기화 도구로 한다. 게시 도구는 백엔드를 바꿀 수 있게(로컬 폴더 / Drive 폴더 경로) 하고 HF 전제를 뺀다.
   모델 인수(intake, D-356)는 HF 커밋 대신 매니페스트 해시를 기준으로 한다.
5. **순서**: (a) 카탈로그 + 궤적 라벨 + 로컬 데이터셋 빌드(오늘 세션으로) → (b) Drive 게시 백엔드·Colab 안내 갱신 →
   (c) 지도 투영(지도 자세 정합 필요) → (d) 측정 신호 라벨(관측기 배치 뒤).

### Alternatives

- **규칙 출력만으로 자동 라벨.** 거부. 실물 규칙 오검출을 그대로 학습한다(D-378 수치).
- **사람 교정 라벨.** 사용자 결정으로 하지 않는다. 필요해지면 평가 세트에만 도입을 다시 논의한다.
- **HF Hub.** 가입 불가.

### Consequences

- 사람 운전 세션이 많을수록 궤적 라벨이 늘어난다(D-378 4항: 데이터는 사람 운전이 기본).
- 지도 투영은 지도 자세 정합이 먼저라 정지선·횡단보도 라벨은 (c) 전까지 적다.
- D-356 의 HF 관련 도구·안내는 이 결정에 맞춰 바꾼다.

### Validation

- 오늘 세션(`20260930T124745Z`)으로 카탈로그·궤적 라벨·데이터셋 매니페스트를 만들고, 궤적 라벨을 프레임에 겹친 확인 그림을
  공개 저장소 밖에 남긴다. 도구 시험은 `tools/perception/test/`.
