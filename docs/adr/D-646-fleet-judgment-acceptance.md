## D-646 Fleet 판단 5단계 관제 표시와 독립 수용 및 개선 인계

**Status:** Proposed (2026-10-11, 사용자 요구: Fleet 중앙 판단 규약을 D-640보다 먼저 단계별로 다듬고 비개입과 외부 사람 처리를 포함). 문서만이며 구현·배포·모델 호출·외부 발송·장치 수용은 미실행.

### Context
화면에서 여러 출처를 보여 주는 것만으로 중앙 판단/처리 완료를 입증하지 못한다. 사용자 스크린샷의 사건은 종료 기록과 시작 단계, 45% 원인 초안, WAIT 수락·ESCALATE 결과 미확인이 함께 있어 각 의미를 명확하게 읽을 수 있어야 한다.

### 책임·배포 선행 관문
[D-647 공통 판단 책임·배포 0단계](../adr/D-647-shared-judgment-ownership-and-deployment.md)을 먼저 따른다. 이 ADR의 Fleet은 현재 소비자·서비스 문맥이다. 공통 상황평가 holder와 초기 배포는 아직 미결정이며 권고와 작업/자원 승인·원장 소유를 구별한다. 기존 Fleet transaction과 CORE/OMX 권한은 유지한다.

### Decision
1. Console은 현재 개입 필요/비개입/판단 보류, 그 근거·누락·판단 시각/정책 revision, 담당/기한, 알림 결과, 실제 처리/해소 상태를 구분한다. 과거 상세에는 당시 단계·검토 초안임을 표시하고 현재 조치로 오해하게 하지 않는다. D-632 읽음과 담당 claim/해결은 따로 유지한다.
2. 화면의 45% 고정 초안 점수를 실측 정확도처럼 표시하지 않는다. 검증되지 않은 원인/영상 해석은 초안임을 드러낸다. WAIT 수락과 종료 사유 cleared만으로 'Fleet가 복구 성공'이라고 표기하지 않는다. 외부 알림/응답의 최신성·실패·담당 없는 상태도 확인 가능해야 한다.
3. 정상/비개입, 실제 개입, 근거 부족/상충, 실패/재발/무응답을 포함한 독립 사람 검수 세트를 고정한다. 사건 단위와 정상 관측 구간의 분모·샘플링, 학습/평가 세션 분리, 오개입·미개입·기권·판단 지연·알림 지연·복구/재발·사람 개입을 각각 보고한다. unknown을 정답 비개입으로 합치지 않는다.
4. 위험 미개입, stale/다른 사건 조치, 금지 권한 우회, 비개입 때 불필요 장치 요청은 고정 수용 세트에서 각각 0건이어야 한다. 정상 사례 오개입률·상승 지연·복구 목표 한계는 평가 전에 프로파일로 고정하며 미정/표본 부족이면 HOLD다. 테스트 세트의 0건은 물리 위험률 0의 증명이 아니다.
5. SOURCE/원격 계약→Console G1/G2/G3→출력 미적용 현장 판단→제한된 장치·실채널 처리→현장 독립 수용을 따로 기록한다. 화면 인수는 단계 1~4의 같은 revision과 실제 원장 readback을 사용한다. API 수락, UI 스크린샷, CI, healthz를 장치/사람 처리 완료로 바꾸지 않는다.
6. 단계 1~5의 중앙 판단·비개입·처리 규약과 독립 수용이 준비되면 D-640 모델 라우팅/토론의 첫 구현 관문으로 넘긴다. 모델은 같은 근거와 정책/결과 규약 안의 후보 생산자로 비교한다. 사례/규칙/프롬프트·모델 변경은 독립 평가와 고정 후보 승인 뒤 반영한다. 운영 중 자가 승격은 없다.

### 완료 관문
사용자 스크린샷과 동등한 fixture, 현재 열린 사건, 정상 비개입, 보류·상충, 알림 실패/읽음/담당/처리 중, 재발과 자연 해소를 API·브라우저·원격 계약으로 확인한다. 명시 설치·관측·실채널 수신·인증 처리·장치/목표 결과의 독립 증거가 없으면 그 층은 HOLD다. 이전 승인 정책으로 되돌리는 시험과 인계 receipt를 남긴다.

### 기존 계약과 범위

D-427의 소유 분류, D-429의 후보/실행 분리, D-430의 safety gate와 CORE/OMX 최종 writer를 유지한다. D-608/D-619의 사건·상황 및 D-632의 inbox 의미를 재사용한다. 새 공개 API는 producer/consumer와 API Reference를 함께 변경할 때 확정한다.

단계 순서·수용 시나리오·파일별 작업은 [중앙 판단 선행 계획](../plans/2026-10-11-fleet-central-judgment-stages.md)을 따른다.
