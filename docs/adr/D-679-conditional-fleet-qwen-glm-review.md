# D-679: Fleet·Qwen 불일치와 제한된 GLM 재평가

- Status: Accepted
- Date: 2026-10-12
- Related: D-640, D-652, D-660, D-672

## Context

Qwen은 무료 기본 추론 경로다. OpenCode는 기존 GLM 연결을 통한 두 번째 검토에 사용한다. 모든 Qwen 호출을 OpenCode로 우회시키지 않는다. Fleet의 규칙 판단과 Qwen의 의견이 다를 때도 같은 사건의 근거로 GLM에 재평가를 요청해야 한다.

## Decision

Fleet은 검증된 사건·상태 revision·정책·관측 시각·근거와 자신의 판단을 소유한다. Decision은 Qwen 의견의 바인딩을 검증하고 비교하며 조건부 검토를 소유한다. AI PC 실행 모듈은 OpenCode 격리, 선택된 인증, 접속 제한과 프로세스 종료를 소유한다. CORE의 최종 명령 권한은 유지한다.

정상 상태는 `NOT_NEEDED`이며 모델을 호출하지 않는다. 기권·만료·다른 사건·위험 판단은 `HOLD`이며 GLM으로 안전 제한을 해제하지 않는다. 유효한 Qwen 의견이 Fleet 기준과 일치하면 기본 추론에서 종료한다. 현재 사건에 바인딩된 Fleet 기준과 Qwen의 판단이 다르거나, Qwen 응답의 형식·사건 바인딩이 잘못되거나, 충돌·관측 부족 이의가 있으면 GLM 검토를 최대 한 번 요청한다. 비용·호출 결과를 확인하지 못했거나 시간 제한을 넘었으면 자동 재시도하지 않는다.

GLM은 같은 사건의 원래 근거와 명시된 Fleet 판단을 검토한다. 검증되지 않은 Qwen 응답을 사실 또는 정답으로 전달하지 않는다. GLM 재평가 완료는 `HOLD`이며 실행 가능한 후보로 자동 승격하지 않는다. 모델 간 일치도는 독립 정답 검수와 현장 성공을 대신하지 않는다.

기존 Fleet DB 원장에 정책 식별자를 기록한다. 기존 토론 결과를 조건부 재평가 결과로 재사용하거나 그 반대의 재사용을 시도하면 `EVALUATION_POLICY_CHANGED/HOLD`다. 같은 사건의 재호출로 예산을 새로 만들지 않는다. 중단·재시작으로 결과가 불명확하면 UNKNOWN/HOLD를 유지한다.

사용자가 지정한 기존 연결의 모델 ID는 `zai-coding-plan/glm-5.3-flash`다. 이를 다른 모델 ID로 치환하지 않는다. 첫 실제 검증은 **합성 사건 1건·1회, 최대 1,024 출력 토큰(추론 포함), 30초, 자동 재시도 없음**이다. 인증은 호스트의 고정 목적 게이트웨이만 사용하며 모델 namespace에는 전달하지 않는다. 호스트 전체 네트워크·HOME·OpenCode 전역 설정을 공유하지 않는다. 고정 TLS 목적지, 하나의 로컬 소켓, 제한된 요청과 응답만 허용한다. 토큰 사용량과 Coding Plan 실제 비용은 구분하며 확인하지 못한 비용을 0으로 기록하지 않는다.

## Verification

1. 원격 합성 시험: 일치·불일치·응답 오류·위험·정상·기권·만료·비용 불명·취소·원장 정책 변경을 검증한다.
2. 호스트 경계 시험: 기존 offline 호스트 PASS와 CLI 실행 PASS를 유지한다. 이는 온라인 제공자 수용이 아니다.
3. 고정 게이트웨이 시험: 잘못된 목적지·도구·모델·출력 한도·소켓 사용자·인증 권한을 실제 호출 없이 거부한다.
4. 실제 제공자 시험: 승인된 한 번의 합성 요청을 OpenCode로 실행하고 종료 코드·원장·응답 바인딩·토큰·자식 종료를 읽어 확인한다. 실패하거나 결과가 불명이면 같은 요청을 자동 재발송하지 않는다.
5. 독립 평가와 Pinky 현장 수용: 팀의 정답 검수 후 정확도·지연 한계를 확정한다. 배포·자동 활성화·물리 조치는 별도 증거가 필요하다.
