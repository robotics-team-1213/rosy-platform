# 요청형 촬영 조명과 현재 사진 저장

조명은 기본 꺼짐이다. 어두운 환경이어도 요청 없이 점등하지 않는다. `촬영 조명 요청`을 누르면 그 요청 안에서만 저조도를 판단한다. 조명을 지원하는 렌즈에서 어두움이 2초 이어지면 LED를 켜되, 요청 시점부터 최대 30초 후 요청과 조명을 모두 종료한다. 어둠이 계속돼도 새 요청 없이 재점등하지 않는다. 중복 요청은 제한 시간을 연장하지 않는다.

`조명 요청 취소`로 즉시 종료한다. 발열 제한 중에는 요청을 받지 않고, 진행 중 과열되면 취소한다. 식은 뒤에도 자동 재개하지 않는다. 렌즈 교체·송출 종료·재시작도 요청을 취소하며 항상 꺼짐으로 시작한다. 꺼짐을 확인하지 못하면 카메라를 해제하고 송출을 종료한다. 화면의 조명 상태는 명령의 성공 응답이 아닌 실제 CameraX 상태다. 화면 절전 중에도 송출과 요청 종료 타이머는 유지된다.

일부 휴대폰은 초광각에서 조명을 지원하지 않는다. 필요한 경우 연결 설정의 화각에서 `기본 (1×)`을 선택한다. 렌즈 변경은 관측 영역을 바꾸므로 고정 카메라 보정을 다시 확인한다. 앱은 자동으로 렌즈를 바꾸지 않는다. LED가 닿지 않는 먼 장면이나 가려진 렌즈는 주변 조명·설치 상태를 확인한다.

`현재 사진 저장`은 송출 중인 최근 JPEG를 앱 내부에 저장한다. 고해상도 별도 정지 사진 촬영은 아니다. 3초 넘게 새 JPEG가 없으면 실패로 표시한다. 저장 시 회전을 적용하고 최근 20장을 유지한다. `저장한 사진 공유`에서 Android 공유 대상을 사용자가 고른다. 사진은 자동으로 외부에 보내지 않는다.

운용 진단은 인증된 ADB 대상에서 다음과 같이 읽는다. 출력은 상태 boolean만 포함하며 이 명령은 촬영·점등을 요청하지 않는다.

```sh
adb -s <verified-device> shell dumpsys activity service io.github.livsbittt.rosy.cam/.service.StreamService
```

관제 PC의 원격 화면 깨우기는 기존 `rosy-cam-screen wake`를 사용한다. 화면 깨우기와 사진 저장은 별도 조작이다.

관제 PC의 자체 키로 이미 페어링한 전화에는 `rosy-cam-screen light-request`로
한 번 요청하고 `rosy-cam-screen light-cancel`로 취소한다. 조회는
`rosy-cam-screen light-status`이며 화면을 깨우지 않는다. 실제 `torch_on`과
요청 수락 `light_requested`는 별도다. 명령은 실제 장치 식별자와 앱 UI를 검사하고,
보안 잠금을 우회하거나 송출을 자동 시작하지 않는다. GUI 촬영 명령 API는 추가하지 않았다.
