# 자동 조명과 현재 사진 저장

송출 화면의 자동 조명은 기본 활성화된다. 조명을 지원하는 렌즈에서 어두움이 2초 이어지면 LED를 켜고 최대 30초 후 끈다. 10초 쉬고 다시 어두운 상태가 관측되면 재점등한다. 화면 절전 중에도 송출과 조명 판단은 계속된다.

`자동 조명 끄기`로 해제하고 `자동 조명 켜기`로 다시 활성화한다. 발열 제한 중에는 점등하지 않는다. 렌즈 교체·송출 종료 때도 끄며, 꺼짐을 확인하지 못하면 카메라를 해제하고 송출을 종료한다. 화면의 조명 상태는 명령의 성공 응답이 아닌 실제 CameraX 상태다.

일부 휴대폰은 초광각에서 조명을 지원하지 않는다. 필요한 경우 연결 설정의 화각에서 `기본 (1×)`을 선택한다. 렌즈 변경은 관측 영역을 바꾸므로 고정 카메라 보정을 다시 확인한다. 앱은 자동으로 렌즈를 바꾸지 않는다. LED가 닿지 않는 먼 장면이나 가려진 렌즈는 주변 조명·설치 상태를 확인한다.

`현재 사진 저장`은 송출 중인 최근 JPEG를 앱 내부에 저장한다. 고해상도 별도 정지 사진 촬영은 아니다. 3초 넘게 새 JPEG가 없으면 실패로 표시한다. 저장 시 회전을 적용하고 최근 20장을 유지한다. `저장한 사진 공유`에서 Android 공유 대상을 사용자가 고른다. 사진은 자동으로 외부에 보내지 않는다.

운용 진단은 인증된 ADB 대상에서 다음과 같이 읽는다. 출력은 상태 boolean만 포함하며 이 명령은 촬영·점등을 요청하지 않는다.

```sh
adb -s <verified-device> shell dumpsys activity service io.github.livsbittt.rosy.cam/.service.StreamService
```

관제 PC의 원격 화면 깨우기는 기존 `rosy-cam-screen wake`를 사용한다. 화면 깨우기와 사진 저장은 별도 조작이다.
