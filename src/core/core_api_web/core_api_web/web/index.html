    LOCAL YAML

    신원 적용

    API 토큰

    ADMIN

    토큰은 해시로만 저장됩니다. 전문은 만들 때 한 번 보여주고 다시 볼 수 없습니다. 사용 중인 토큰과 마지막 관리자 토큰은 삭제할 수 없습니다.

    • 관리자로 연결하면 토큰 목록을 표시합니다.
    토큰 추가

    웨이포인트

    LOCAL JSON

    현재 자세를 이름과 함께 저장합니다. __home__ 은 복귀 지점입니다. 값은 ~/.rosy/waypoints.json 에 남습니다.

    현재 위치 저장
    • 연결 후 웨이포인트를 표시합니다.

    FLEET_HOLD

    이 저장소에는 플릿 서버가 없습니다. 로봇 outbound WebSocket은 열리지 않으며 추종·대형 명령도 연결되어 있지 않습니다. 여러 대를 한 화면에서 묶거나 대형을 바꾸는 설정은 여기서 할 수 없습니다.
