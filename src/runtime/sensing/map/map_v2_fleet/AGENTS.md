# map_v2_fleet

## Purpose

Bundle for the 260919 road track (2.81 x 1.26 m): lane paint on a dark floor plus a perimeter wall ring. It holds the CAD source, a deterministic Gazebo world generator, the Nav2 perimeter map, and the human-owned lane network rules with the graph generated from them. Read `README.md` first for regeneration, run commands, and known limits. Sim and calibration-reference asset only: it never publishes `/cmd_vel` (CORE does).

## For AI Agents

### Working In This Directory

- Do not hand-edit generated files (`lane_graph.yaml`, `worlds/`, `meshes/`, `textures/`, `maps/`). Edit `lane_rules.yaml` or the scripts, regenerate, and diff; output must stay byte-deterministic.
- The STL geometry is a measured snapshot. Do not reshape walls or paint to make a planner pass.
- After `world_to_map.py` on Windows, convert the map yaml from CRLF to LF (`.gitattributes` expects LF).
- Reference square coordinates are image-derived (about 3 cm); tape measurement is pending.

### Testing Requirements

Consumers are tested from `src/runtime/sensing/test/` (`test_lane_graph.py`, `test_map_v2_fleet_dock_marker.py`, and the lane/localization scenario tests that load this bundle). Mostly ROS-free:

```bash
python3 -m pytest src/runtime/sensing/test/test_lane_graph.py src/runtime/sensing/test/test_map_v2_fleet_dock_marker.py -q
```

Full sim runs need Gazebo and ROS 2 on Linux (`gz_sim` launch).

### Common Patterns

- Frame is ROS map/odom in metres, world centred; STL transform is R_x(+90 deg), mm to m.
