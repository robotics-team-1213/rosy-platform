      저장 현황을 확인하는 중입니다.

      등록한 폴더만 집계합니다. 자료 크기는 학습 승인 여부와 별개이며, 폴더별 할당량은 공유 블록·백업 전체의 실제 사용량과 다를 수 있습니다.

      전송 전 공간 점검

      모든 로컬 사본이 선택한 목적지 볼륨을 사용한다는 추정입니다. 공간을 예약하거나 전송하지 않습니다.

      원격 보관과 로컬 사본

      등록 위치 안의 상대 폴더를 입력하세요. 완료된 자료 목록과 파일 해시를 확인한 뒤, 공간이 있는 허용된 저장소에 배정합니다.

      보관 작업 등록
      캐시 공간 확보

      검증한 로컬 사본 정리

      원격 원본은 남습니다. 원격 계정의 접근 권한을 잃으면 복원할 수 있으리라 보장할 수 없으며, 원격 단일 사본은 독립 백업을 대신하지 않습니다.

      확인한 로컬 사본 정리 취소
      기존 결과 폴더 연결

      이미 실행한 작업의 결과를 연결합니다. 목록은 자동 저장되며 원본 파일을 수정하지 않습니다.

      연결 저장
      지원 기능과 다음 작업

      자료 등록과 픽셀 검수는 이 앱에서 이어갑니다. 연결된 소유 학습 실행기는 시작·중지·재시도할 수 있습니다. 기존 CLI 작업 결과도 여기서 확인합니다. CVAT 서버 연결과 정책 승격은 별도입니다.
