      저장 현황 다시 확인

      전송 전 공간 점검

      모든 로컬 사본이 선택한 목적지 볼륨을 사용한다는 추정입니다. 공간을 예약하거나 전송하지 않습니다.

      공간 사전 점검

      원격 보관과 로컬 사본

      등록 위치 안의 상대 폴더를 입력하세요. 완료된 자료 목록과 파일 해시를 확인한 뒤, 공간이 있는 허용된 저장소에 배정합니다.

      보관 작업 등록
      캐시 공간 확보

      검증한 로컬 사본 정리

      원격 원본은 남습니다. 원격 계정의 접근 권한을 잃으면 복원할 수 있으리라 보장할 수 없으며, 원격 단일 사본은 독립 백업을 대신하지 않습니다.

      확인한 로컬 사본 정리 취소

      기존 원격 버전 확인

      HF 저장소에서 이 작업의 커밋을 찾고 전체 버전 ID를 입력하세요. 새 업로드 없이 기존 버전의 모든 파일을 검증합니다.

      기존 버전 검증닫기

      기존 결과 폴더 연결

      이미 실행한 작업의 결과를 연결합니다. 목록은 자동 저장되며 원본 파일을 수정하지 않습니다.

      연결 저장

      지원 기능과 다음 작업

      자료 등록과 픽셀 검수는 이 앱에서 이어갑니다. 연결된 소유 학습 실행기는 시작·중지·재시도할 수 있습니다. 기존 CLI 작업 결과도 여기서 확인합니다. CVAT 서버 연결과 정책 승격은 별도입니다.

      실행·평가 결과

      실행·평가 결과

      로봇별 지원과 전문가 도구

      행동 정책 학습은 OMX 로봇암의 ACT 시범·교정 학습과 HIL-SERL 경험 학습을 지원하며, 다른 로봇의 정책 학습과 현장 실행은 아직 연결되지 않았습니다.

      OMX 로봇암 과제·팔·카메라 정하기 · 기존 시범 검수·데이터 선택 · 학습 진행 확인 · 같은 조건의 결과 비교

      학습 실행기 연결 안내

      이 작업대의 소유 학습 실행기를 연결하면 데이터셋 확인과 학습을 여기서 시작할 수 있습니다. 운영 담당자에게 이 작업대의 실행기 연결을 요청하세요.

      연결된 실행기는 승인 자료의 최신 결정, 학습·평가 데이터 분리와 시도 한도를 확인합니다.
