작업공간을 확인하는 중…

클래스는 이 프로젝트의 현재 작업공간 전체에 적용됩니다. 선택한 자료 폴더를 포함한 모든 폴더가 같은 클래스셋을 사용합니다.

기존 클래스는 표시 이름과 색상만 수정할 수 있습니다. 기존 번호·정본 이름·역할·의미는 유지됩니다. 새 클래스는 사용하지 않은 번호로 추가합니다.

클래스 추가나 픽셀 색상 변경 후에는 다른 탭의 미저장 작업도 최신 클래스와 검수 버전을 다시 불러와야 합니다. 제외·검수 대기 상태는 유지됩니다.
