3 · 시범·교정 수집


기본 조작기는 리더 팔입니다. 게임패드는 선택 가능한 입력 방식으로 준비하며, 작업 팔과 조작기를 구분합니다.


  1. 과제와 장치 설정에서 작업 팔·관절 순서·단위, 카메라의 소속과 배치를 저장합니다.
  2. 상단·손목·측면 시야에 물체와 그리퍼가 보이는지 확인합니다. 카메라를 옮겼다면 배치와 촬영 기준을 다시 확인합니다.
  3. 한 시도마다 영상·관절 상태·실제로 적용한 행동을 같은 기록에 남깁니다. 교정 입력과 개입 시점, 성공·실패·종료·초기화도 함께 기록해야 합니다.
  4. 기록을 연결하고 다음 메뉴에서 프레임·결과를 검수합니다. 영상 파일만으로는 행동을 배우는 데이터가 되지 않습니다.


현장 수집·교정 제어는 아직 연결되지 않았습니다
이 화면에서 팔을 움직이거나 수집을 시작할 수 없습니다. 장치 연결·교정과 제어 전환을 검증한 뒤 현장 수집 기능을 연결해야 합니다. 이미 수집한 자료는 OMX 시연 준비 결과 폴더로 연결한 뒤 검수할 수 있습니다.
카메라 촬영 기준 확인기존 OMX 시연 폴더 연결등록 자료 검수


OMX LeRobot 녹화는 모델 PC에서 시연 준비를 마친 폴더를 연결하고, 4단계에서 검수·변환합니다. Pinky Pilot의 MCAP 녹화(.tar)는 모델 PC 수신·영상 변환 후 자료 등록에서 검수하며 OMX 시연 입력과 구분합니다. 변환 완료 카드에서 학습 또는 HF 보관 준비로 이어갈 수 있습니다.


녹화 자료를 준비해서 연결하는 방법
  1. OMX 리더·작업 팔 녹화는 종료된 수집 폴더와 촬영 기준을 모델 PC 운영자에게 전달합니다. 운영자는 고정된 LeRobot 환경에서 learning/curation/omx/collection_pipeline.py prepare-native로 새 준비 폴더를 만듭니다. 입력과 옵션은 같은 명령의 --help에서 확인합니다.
  2. 준비 결과의 intake-receipt.json, inspection.json, decisions.json을 보존한 폴더를 위의 “기존 OMX 시연 폴더 연결”에서 등록합니다. 원본 녹화 대신 준비 폴더를 선택합니다.
  3. 4단계에서 프레임·결과를 확인하고 검수를 저장한 뒤, 변환에 쓸 저장 검수 버전을 선택합니다. 완료 카드에서 학습 또는 고정 버전의 HF 보관 준비를 선택합니다.
  4. Pinky의 .tar는 OMX 준비 명령에 넣지 않습니다. 모델 PC에서 원본 수신·해시 확인·영상 변환을 마친 뒤 Learning의 자료 등록에서 객체·픽셀 검수를 이어갑니다. 자동 수신 여부는 운영자가 마지막 수신 결과로 확인합니다.

5 · 성공 판정·초기화


HIL-SERL에는 매 시도의 보상·종료와 다음 시도의 시작 상태가 필요합니다. ACT의 시범 검수와 구분해 준비하세요.


  • 성공: 지정한 물체를 집어 과제에서 정한 높이·시간 동안 유지하는지 확인합니다.
  • 실패: 빈 그리퍼 상승, 물체 가림, 들었다가 낙하, 시간 초과를 성공으로 잘못 판정하지 않는지 확인합니다.
  • 초기화: 팔과 물체를 정한 시작 상태로 되돌리는 방법과 사람의 소요 시간을 기록합니다.


자동 성공 판정기·현장 초기화는 아직 연결되지 않았습니다
현재는 데이터 검수에서 사람이 확인한 시도 결과를 저장할 수 있습니다. 자동 판정기를 학습·검증하고 현장 보상·종료·초기화에 연결하는 단계가 남아 있습니다.
