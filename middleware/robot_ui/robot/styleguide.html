ROSY UI 어휘

공용 부품의 얼굴과 동작을 확인하는 어휘 갤러리입니다(D-92, D-129). 제품은 이 페이지를 import하지 않습니다. 어휘 변경은 이 견본에도 함께 반영합니다.

색상 역할

색상은 바탕·글자·경계·상태·데이터·브랜드로 나눕니다. 모든 견본은 같은 공용 토큰을 사용합니다.

공용 컴포넌트 모음

버튼·입력·상태·증거·읽기·작업 선택은 공용 부품이 모양을 소유합니다. 화면은 배치와 실제 동작을 소유합니다. 이 갤러리의 동작은 장비 명령을 보내지 않습니다.

입력·목록·상세·복구의 상호작용 견본 열기 — 폼 검증, 검색·선택, 페이지 이동, 미저장 편집, 결과 확인을 같은 공용 부품으로 조합합니다. 합성 자료이며 제품 적용·실물 수용과 구분합니다.
